# CHG-20260930-070：内容池交互对齐前端交互规范

- Status: PLANNED
- Level: `S`
- 依据基线：`docs/standards/前端交互规范.md`（稳定规范）；业务闭环不变——内容池发现、筛选、转素材与忽略的业务事实以 M3 闭环（`delivery/milestones/M3-content-discovery-v2.md`）与既有代码为准，本 CHG 只对齐交互层。
- Current repository: `wt-media-cloud`
- 激活条件：`CHG-20260930-069` 关闭归档后激活（`delivery/active` 同一时间只允许一个活跃 CHG）。

## 1. 独立结果

内容池列表按处理状态给出单一主操作，低频与危险操作收进「更多」；行操作文案与全系统统一；已转素材的行内可以直接进入对应素材详情。

## 2. 范围与边界（仅交互层，不动后端与契约）

- 「查看」统一为「详情」；详情抽屉内「查看素材」改为「素材详情」（§9.4 跨对象跳转带对象名）。
- 行操作按状态收敛（§2.3/§5.5/§16.1）：
  - `pending`（待处理）：详情 | 转素材 | 忽略（按钮 ≤5 全平铺，§5.6：超过 5 个才把低频收敛进「更多」；各状态行操作均不超过 3 个，无「更多」）；
  - `material_created`（已转素材）：详情 | 素材详情（行级入口，跳 `/material-library?material_id=`）；
  - `ignored`（已忽略）：详情 | 恢复。
- 批量操作呈现对齐 §4/§11：选中后展示「已选 N 项 + 批量操作」，未选中时隐藏；既有批量转素材/忽略/恢复与结果反馈（成功/失败数）保持。

## 3. 明确不做

- 不改 `pending/material_created/ignored` 状态机与文案（状态词以 PRD 为准，规范 §16 仅为示例）；
- 不动后端接口、契约与数据库；
- 不做标题点击进详情（标题跳来源平台落地页为 CHG-20260930-069 走查裁定，登记为与本规范 §5.3 的已裁定偏差，详情入口由常驻「详情」按钮承担）；
- 不含素材库/我的素材（由 CHG-20260930-069 任务 8 承载）。

## 4. 验收标准

- 三种处理状态各自的行操作与 §2 所列一致；「查看」字样不再出现于内容池行操作与抽屉跳转。
- 已转素材行内「素材详情」可打开对应素材（深链行为与既有抽屉内跳转一致）。
- 忽略/恢复的入口语义不变，按钮平铺；批量操作行为与反馈不变。
- 定向 Web 测试与双构建通过；真实页面留给用户走查签收。

## 5. 有序任务

1. 先改 ContentPoolPage 相关测试（行操作形态、文案、素材详情入口），确认红；
2. 实现行操作收敛与「更多」下拉、行级「素材详情」入口、抽屉「素材详情」文案；
3. 跑定向测试与双构建，启动桌面包供用户走查。

## 6. 验证与提交边界

- `web/src/modules/contentpool/` 定向 vitest 覆盖上述断言；
- 仅交互层改动，Cloud Go 代码与契约不触碰；
- 独立提交，不与其他 CHG 混杂。
