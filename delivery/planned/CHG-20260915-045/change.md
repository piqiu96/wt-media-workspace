## 顺序任务

### Task 1：核实能力与任务合同

- 工作：真实接口核实标准/短链接、详情、错误与限流；定义 Cloud-owned 查询/入池及 Cloud Agent 能力路由。
- 验收：支持与缺口有脱敏证据；不支持平台明确拒绝；供应密钥不进前端。

### Task 2：接通云端真实执行

- 工作：Cloud 管理意图、权限与结果，Cloud Agent 调用受控适配器；入池复用 A。
- 验收：本地 Agent 不误领云端发现；点击解析并入池就是入池意图，成功结果有正式 source_content。

### Task 3：完善批量与页面

- 工作：内容池入口支持逐条成功/重复/失败、保留失败重试；输入与作品身份去重。
- 验收：一条失败不回滚其他成功；重复点击不重复来源；不强加导入素材确认，不自动创建 material。

### Task 4：真实首个闭环验收

- 工作：真实链接→池列表→人工转素材→素材库；覆盖接口异常、无效作品、重复和权限拒绝。
- 验收：A+B 的外部闭环全部有证据；截图与数据库读回一致，解析成功但未持久化不得算入池成功。
