# CHG-20261126-130：B站发布与画中画全流程验收

## Change

补齐B站从成片进入单条任务、批次与计划，浏览器自动上传/填表/提交、原稿核验与可信公开结果的完整闭环。沿现有Cloud事实/调度、Agent平台能力、Desktop壳及共享Vue边界；完整规划见[plan.md](plan.md)，提供方契约先定版再更新消费者。

本轮只开放经真实验收的B站，百度完整回归；小红书保留后续阶段，不因枚举存在而开放。最终必须以129新模式产出的视频完成真实发布，并由执行工程师主动打开浏览器检查平台后台与公开作品，问题自行修复；上传或审核受理不算已公开。当前只有设计与规划，未发起真实投稿。

## Done When

- [ ] B站字段、封面规格、默认值、账号能力及条件字段有当前真实页面依据，Cloud/前端/Agent同规则，旧百度数据不被重解释。
- [ ] 单条、批次、计划复用同一发布与核验能力；同Profile跨批/跨平台互斥、一次提交、未知保护、停止/恢复与迟到结果矩阵通过。
- [ ] 129成片通过真实单条、独立批次及两批计划流程；公开作品与原账号/任务精确关联，实际公开数与目标差额读回一致。
- [ ] 编码和完整自测清单先完成，再E2E、主动浏览器逐页/平台实际走查与新安装包复核；证据可追溯到本轮ID及版本。
- [ ] PR问题修复、CI、三运行仓main及新包组合核对完成；自动审查不可用须如实记录，不冒充通过。
