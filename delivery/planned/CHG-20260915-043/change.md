## 顺序任务与验收

### Task 1：冻结验收条件与样本

- 工作：记录已通过阶段、组件版本、迁移、配置、授权样本及脱敏规范；准备管理员/高级运营/普通运营与隔离范围。
- 通过标准：版本可复现；缺接口或未通过阶段不得进入综合通过判定；不在文档保存凭据。

### Task 2：走通四入口

- 工作：执行多链接、关键词搜索、关键词策略和作者监控，覆盖人工/自动入库及最小素材库。
- 通过标准：每条操作都能关联外部作品、业务任务（适用时）、来源与素材；即时未选不入库。

### Task 3：执行权限与并发验收

- 工作：两名运营重复导入、跨游戏/组访问、忽略/转换竞争、批处理及原始 JSON 权限。
- 通过标准：唯一性与已确认共享规则同时成立；拒绝路径不泄露内容或产生副作用。

### Task 4：执行恢复和 M2 回归

- 工作：覆盖供应方失败/限流、Cloud/Agent 重启、回报丢失；回归登录、账号、窗口、代理与两端页面。
- 通过标准：故障结果可解释并恢复，M2 既有闭环无回归；缺陷回到对应阶段单独修复再回归。

### Task 5：用户走查与归档

- 工作：汇总自动化、真实数据库、真实接口、Cloud Web/Desktop 页面证据；请求用户最终验收结论。
- 通过标准：全部退出条件有 PASS 证据且用户确认后才标 M3 DONE；稳定规则回写基线，按仓库分别提交。
