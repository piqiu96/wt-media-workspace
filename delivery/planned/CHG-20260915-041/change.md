## 顺序任务与验收

### Task 1：明确周期与恢复合同

- 工作：定义时区、next_run、计划时间唯一键、错过周期处理、租约与业务状态映射及检查点。
- 通过标准：启用/停用/编辑/手动执行/重新启用矩阵可验证；方案不依赖内存锁保证唯一。

### Task 2：交付真实定时闭环

- 工作：调度仅创建任务，Cloud Agent 查询；前端显示运行方式、下次时间和真实任务。
- 通过标准：启用立即执行；停用不新增周期且在途继续；手动执行不移动计划；同策略不重复排队。

### Task 3：接通自动转换与失败处理

- 工作：精准策略自动复用转换服务，普通策略进入待选；转换失败保留来源并支持只重试转换。
- 通过标准：真实作品自动入库且忽略项不复活；写入失败不显示已转素材，不重新搜索成功内容。

### Task 4：完成故障恢复与幂等统计

- 工作：验证 Cloud/Agent 重启、租约过期、限流、来源/素材提交后回报中断。
- 通过标准：不会永久执行中、重复素材或重复累计；过期执行者不能覆盖新结果；跳过周期可解释。

### Task 5：阶段验收与交付

- 工作：在持续运行的云端环境观察真实周期，进行受控故障演练。
- 通过标准：本地电脑离线不影响运行；周期、任务、来源和素材可关联取证，不能仅用 ticker 日志验收。
