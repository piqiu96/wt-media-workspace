## 顺序任务与验收

### Task 1：确认身份与覆盖策略

- 工作：真实核对作者 ID、短链接解析、分页排序、置顶/下架/补发行为及扫描上限。
- 通过标准：明确可证明的基线覆盖范围、未覆盖范围和用户提示；不支持的能力先澄清而非静默跳过。

### Task 2：交付两种初始化模式

- 工作：启用创建带快照的初始化任务；近期模式入库/待选，新增模式只持久化去重基线。
- 通过标准：新增模式初始化零 source_content/material 写入；失败可恢复且不误判初始化成功。

### Task 3：交付后续新增闭环

- 工作：复用周期调度，按作品 ID 判新、游标优化、任务内去重，进入既有来源/素材服务。
- 通过标准：使用可核对的新作品证明一次入库；改昵称不改变身份，跨入口发现仍全局唯一。

### Task 4：覆盖边界与恢复

- 工作：处理重复分页、相同发布时间、旧置顶、后补内容、分页中断、达到上限和作者切换。
- 通过标准：失败不推进完成游标；切换作者不复用旧基线；任何未覆盖范围可见而非假成功。

### Task 5：阶段验收与交付

- 工作：用授权作者或可验证平台事实演示初始化到真实新增，并补确定性边界测试。
- 通过标准：真实外部证据与自动化分开记录；不以伪造返回替代最终新增验收。
