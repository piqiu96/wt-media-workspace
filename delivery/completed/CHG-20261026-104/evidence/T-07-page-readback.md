表头 11 列，顺序与列声明一致：

```text
素材 ID | 素材 | 游戏 | 素材状态 | 文件状态 | 加入状态 | 我的使用 | 使用情况 | 发布时间 | 入库时间 | 操作
```

素材 170 行：

| 单元格 | 读回 |
| --- | --- |
| 加入状态 | 已加入 |
| 我的使用 | 已使用 |
| 使用情况 | `成片 1 · 使用 1 人` / `姓名不可见` |

- 页面所有 `button` 中没有文本为“下载”的按钮（`bodyHasDownloadButton=false`）。
- 三个筛选控件存在：加入状态、我的使用、使用情况。

## 素材库详情抽屉

`/material-library?material_id=170` 的抽屉：

- 页脚按钮只有 `去我的素材`，没有下载按钮。
- 卡片读回：`已使用`、`1 成功成片`、`1 使用人数`、`姓名不可见`。
- 文本中的“可下载”是**文件状态**取值（服务端 `video_status` 文案），不是本机下载入口；“请在「我的素材」下载”是下一步指引，也没有对应按钮。

## 我的素材 → 下载

素材 2（本次新加入，未下载过）在“我的素材”页的行：

```text
文件状态=未下载  使用状态=使用中  操作=详情 | 下载 | 放弃使用
```

点击“下载”后页面读回 Toast：

```text
已开始下载，可在下载中心查看进度
```

随后 Cloud 生成准备任务与下载任务，本机 Local Agent 完成 82,356,001 字节的原视频下载（任务与文件证据见 `T-06-download-and-worker-prep.md`）。
