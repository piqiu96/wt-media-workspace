## 实现

- 策略页面直接使用服务端 `items/total/page/page_size`；查询回第一页，翻页及 quiet 自动读取保留当前页，旧请求不覆盖新请求。
- 任务筛选和新建任务共用远程策略选择器，每次20条，明确“加载更多”；数字 ID／名称搜索不再经过本地名称二次过滤。选中策略独立调用详情，完整设置不依赖当前目录页。新建请求严格携带团队、类目、负责人、启用状态；未选负责人时不请求全目录。
- 管理员的素材行、素材详情、成片行及成片详情不允许创建本机下载；按钮禁用且提供原因，已有传输取消入口保留。公共按钮样式不会覆盖禁用外观。
- 素材库使用情况筛选归入公共高级区；我的素材采用公共字段布局与清空选择；选择列44px。按实际14px按钮文字修正公共操作列计算，策略四个按钮完整显示并预留执行 loading 空间。长负责人名称省略展示、悬停保留全文。
