## 关键设计（每条都被用例钉住）

| 函数 | 形状 | 用例 |
| --- | --- | --- |
| `ClaimNextComposeTask` | 事务内 `SELECT id ... FOR UPDATE SKIP LOCKED` + 条件 UPDATE `pending→running`（node/lease/heartbeat、`started_at` COALESCE 保首次、`attempt_count+1` 按实际开工计）；空队列与 UPDATE 脱靶都走 `errNoClaimableTask` 回滚、found=false | 3 例（成功领取/空队列回滚/脱靶回滚） |
| `RenewComposeLease` / `ReportComposeProgress` | `WHERE id AND claimed_node_id AND status='running'`——丢行的 Worker 拿到 false 必须停手 | 1 例（本人续租 true、外行 false） |
| `RequestComposeCancel` | `cancel_requested=0→1` 条件 UPDATE + 审计同事务；第二次请求零写入 | 1 例 |
| `ConfirmComposeCancel` | 仅 `cancel_requested=1 AND running AND 本人`才置 cancelled+finished_at | 形状进 SQL 断言 |
| `CommitComposeOutput` | INSERT composite_outputs + 条件 success 翻转同事务；任务行脱靶 → `ErrComposeCommitLost` 整体回滚（成片行绝无孤儿，spec §6.3） | 2 例（成功/回滚） |
| `ReleaseComposeForRetry` / `FailComposeTask` | requeue 不擦 attempt_count；终态 failed 带 error_code/message/finished_at，均限本人 running 行 | 2 例 |
| `FindExpiredComposeLeases` | 只读扫描 `running AND lease_expires_at < now` | 1 例 |
