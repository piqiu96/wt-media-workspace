## 目标

Cloud Web 与 Desktop 共用的合成策略、任务、我的成片和任务创建界面按照现有规范表达真实业务：当前对象突出，状态和下一步清楚，详情按维度定位，表单按操作顺序组织。

## 当前事实

- M4-F/G 已机器验收并归档，当前无活动 CHG；M4-H 用户真实走查尚未签收。
- 三张 M4 参考图已存放 `assets/images/ui/content-production/`，只约束布局与信息层级。
- 策略、任务、成片列表已有真实字段和操作，但任务进度仅文本显示，任务详情为长 Dialog，成片详情为长 Drawer；创建任务将已选素材放在最后。
- 运行页不拥有任务名称、任务批次、成片名称、最终视频封面或发布记录；不得使用假数据填满参考图。

## 范围

1. 三页列表按“对象 → 状态／进度 → 关联摘要 → 时间 → 操作”强化视觉顺序，保持 ID 首业务列和统一按钮规则。
2. 策略只读详情分组清晰；任务详情改为适合多个信息维度的 Drawer，显示状态、进度、执行记录、配置快照及成片关联；成片详情用预览与来源信息的明确分区或 Tab。
3. 创建任务先确认已选素材，再选策略和可覆盖参数；字段错误就近展示，提交失败保留输入。
4. 只复用现有 TDesign、设计变量和反馈组件。顺手删除修改区域的失效过程注释。

## 不做

- 不修改业务状态、权限、重试规则、任务数量、调度、数据库或 Cloud API。
- 不实现参考图中的任务合并、发布记录、成片名称或其他未交付功能。
- 不把 M4-H2 用户真实走查自动标为通过；M5 在 M4 签收后按既定闭环启动。
