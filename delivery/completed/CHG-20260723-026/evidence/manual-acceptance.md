# CHG-20260723-026 Manual Acceptance：人工验收清单

> 日期：2026-07-23

## 验收前置

- Cloud 服务可用；
- Desktop 可登录普通运营账号；
- Local Agent 可用；
- BitBrowser 可用；
- 当前电脑已完成可信绑定。

## 建议人工验收路径

### 1. Cloud Web 视角

- 使用管理员登录 Cloud Web；
- 进入“浏览器窗口”；
- 页面只展示 Cloud 已保存的窗口信息；
- 不出现“扫描本机窗口”“新建窗口”“打开窗口”“关闭窗口”等依赖本机 Agent / BitBrowser 的操作入口；
- 窗口列表能看到“授权用户”；
- 点击窗口详情，可以看到脱敏主账号、授权用户、最近同步时间。

预期：Cloud Web 是纯数据视角，不承载本机 BitBrowser 操作。

### 2. Desktop 视角：扫描与接受本地变化

- 使用普通运营登录 Desktop；
- 确认本机 Agent 状态可用、BitBrowser 可用、本机节点可信；
- 进入“浏览器窗口”；
- 点击“扫描本机窗口”；
- 查看本机扫描 Diff；
- 点击“接受本地变化”。

预期：

- Diff 未确认前不会更新 Cloud 正式窗口镜像；
- 接受后 Cloud 窗口镜像更新；
- 不覆盖授权用户、媒体账号绑定、游戏、标签、备注、Cookie 和业务状态。

### 3. Desktop 视角：恢复 Cloud 配置

- 在 Desktop 的本机扫描 Diff 中选择“恢复Cloud配置并读回验证”；
- 确认写回后重新读回；
- 查看新的 Diff 或成功提示。

预期：

- 恢复动作只在 Desktop 中出现；
- 由 Desktop 经 Tauri/Rust 调 Local Agent；
- 写回 BitBrowser 后重新读回；
- 读回不一致时不显示假成功。

### 4. 管理员窗口授权

- 使用管理员登录 Cloud Web；
- 对未被媒体账号引用的浏览器窗口点击“分配”；
- 选择一个启用中的普通运营；
- 确认分配。

预期：

- 只更新 Cloud 授权用户；
- 不操作本机 BitBrowser；
- 不修改媒体账号绑定、Cookie 或代理；
- 已被媒体账号引用的窗口不能直接分配。
