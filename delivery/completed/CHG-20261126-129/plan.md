# 广告画中画与片尾模式设计

状态以[change.md](change.md)为准。用户已确认播放规则及独立模板方案，按128→129→130执行；128已完成技术交付，本项已启动。

## 业务与页面

播放顺序：**正片前段 → 广告画中画 → 从插入点继续正片 → 现有片尾**。不加开头引导，不要求开头URL。画中画前景为广告视频，背景为正片插入点起等长画面，沿现有模糊/压暗与比例约束；广告期间仅播广告声音。广告结束后正片恢复原插入点，背景画面不消耗正片播放进度。

片尾沿现有随机切片池、约6秒切片与音乐淡出。广告位置沿现有10～15秒随机窗口、转场沿现有0.2秒默认，均按本模板实际时间线重算；短源/预算不够明确失败，不偷偷移动、循环或冻结补时。若广告自身无音轨，画中画期间静音，不混入原声；需有明确静音告知与对应测试。

策略新增/复制中从已有“合成模板”选择“广告画中画＋片尾”；说明清楚显示四段顺序。成片设置仍是组名、平台、份数、模板参数。参数只保留广告地址、正片起止、总时长上限、广告最早/最晚、广告宽度、转场，不出现开头引导字段。任务内仅开放现有类型允许的正片起止/上限，策略固定参数禁用。详情、任务快照、再次制作展示实际模板与最终参数；不出现业务无关的FFmpeg命令。

## 架构选择

| 方案 | 优点 | 代价/结论 |
| --- | --- | --- |
| 独立ad_pip_ending v1，复用现有执行底座 | 无开头参数，旧五段模板和历史任务不变，运营可直接辨认 | 增加一条注册定义；**推荐**，共用渲染/时长计算，不复制整个执行器 |
| 发布dynamic_pip_ending v2并加入模式 | 一个技术模板支持两种模式，未来扩展较集中 | 条件schema、表单、资源与时间线分支更复杂；当前只有一个明确新需求，不优先 |

不得修改已发布dynamic_pip_ending v1 schema或把开头设成空URL来绕过验证。Cloud继续负责策略/任务/Worker/FFmpeg/存储，Agent只负责下载及后续发布，Desktop复用Cloud Vue。

## 接口、模块与持久化

- Cloud provider：contracts/cloud-api/v1/content-production.openapi.yaml、business-schemas/v1/content-production.yaml、business-enums/v1/content-production.yaml；消费文档指向现有正式定义，不复制DTO。
- 复用GET /api/v1/compose-templates返回新code/version/schema/说明/默认；POST compose-strategies、copy、run-now、compose-tasks与outputs及再次制作保持现有结构。是否枚举扩展以提供方正式审查为准，不新增一套“广告合成”端点。
- Cloud executor：internal/modules/production/executor/dynamic.go及注册目录、config/compose/templates.toml和制品配置；新增四段Plan，实现Resources/Compile。只声明source/ad/ending，无intro下载与校验步骤。
- 准备资源时冻结广告与片尾摘要/时长、正片选段、随机种子、实际时间线及技术默认；重试不重新选广告或片尾，新任务才重新随机。复用租约/CAS/幂等成片入库和不可变对象位置。
- Vue：ComposeStrategyPage、strategySettings/schemaFields、任务创建/参数/详情/成片再次制作沿原组件扩展；原型production/forms同步实际模板说明，不另起工作区。
- 当前存储已支持模板code/version与JSON快照，预期无需业务新表；注册数据通过现有发布/目录入口，DDL或目录迁移如有必要必须可升级/幂等验证，不手改生产表。

## 9步实施与自测

1. 固定原型、用户播放规则及新模板参数/示例时间线；确认广告和片尾素材可读，不真实发布。
2. 定版模板schema/默认及提供方契约，核对消费者生成；旧v1保持原定义。
3. 先写四段时长/插入位置/重叠边界失败用例，包含刚好够、短源、零转场、竖屏、无音轨。
4. 注册Plan并复用资源探测/Compile/FFmpeg，补齐资源摘要和重试确定性；禁止加载intro。
5. 完整实现策略/复制/手动/立即/定时创建及任务/成片/再次制作页面；统一参数可调整与固定约束。
6. 完成参数、三种任务来源、权限、历史模板、对象引用、取消/重试/上传失败自测清单；真实FFmpeg抽帧与音轨/时长验证。
7. 再跑真实源→任务→Worker→存储→成片→下载E2E，分别核实失败不产生假成片、成功只入库一次。
8. 主动打开浏览器播放成片并听音，核对无开头、广告画中画/原声切换、正片恢复、片尾及下载文件；新安装版走查相同路径，问题直接修复后重跑。
9. PR/CI/合入main并归档，保存可回链的本轮strategy/task/output/file ID、摘要、版本与测试视频证据供130使用。

## 验收样本

最少覆盖正常有声、广告无声、竖源、短源/广告背景不足、广告URL失败、片尾池为空/无效、超时/取消、同任务安全重试、新任务随机、历史五段模板回归。真实音视频以解码/抽帧/音轨和浏览器实际视听共同判断，不只看HTTP成功。片尾与广告必须有实际可用输入，缺失如实阻断，不用静帧假装通过。
