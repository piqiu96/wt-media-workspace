# 社媒账号与公共字段人工验收清单

本清单供人工逐页确认体验；方框留空，不能用程序自测代替人工签收。依据当前 `example/proto/social-accounts`、`example/common` 和前端标准。M2-D 仍为 VERIFYING。

## 1. 社媒账号列表

- [ ] 首屏：对照原型检查标题、统计卡、筛选、行高、操作列与按钮层级。分类、标签、备注信息可扫读，窗口与登录状态可区分。
- [ ] 勾选一个/多个账号：只出现统一批量操作条；取消全选后操作条退出。不另造一组批量按钮。
- [ ] 启用/停用：开关目标正确；确认取消不改变状态，保存后再次切换仍正确，刷新后与已保存值一致。
- [ ] 筛选：一级分类切换/清空时不残留二级分类；成员、团队可搜索。清空恢复各自业务允许的全部范围，重置恢复默认列表。

## 2. 新增账号

- [ ] 点击「新增账号」：640px 自适应弹窗；按平台、业务分类、标签、运营备注顺序填写；页脚为「取消 / 保存」。没有临时名称、暂不分类、备份/审计等额外输入。
- [ ] 一级分类选择后显示二级选项，可多选；换一级后清空旧二级；不选分类也可保存台账。输入标签后回车添加，前后空格去除、重复不新增，可移除。
- [ ] 未修改直接取消：关闭。修改后取消/X/Esc：询问是否放弃；取消放弃后内容仍在，确认放弃后关闭；再次新增为新草稿。
- [ ] 保存：只提交一次，保存期间不能重复提交/关闭；成功出现已保存引导，刷新列表仍可见新账号。浏览器可稍后绑定。
- [ ] 保存失败：弹窗保留输入并显示错误，可改正/重试；不伪装成功，不要求重填全部资料。

## 3. 编辑账号与详情

- [ ] 点击某行编辑：标题「编辑账号」；分类、标签、备注与新增使用同一交互，原有值正确回填；切换一级分类不保留隐藏旧二级。
- [ ] 修改备注/标签后取消放弃：继续留在编辑页；确认放弃：再次打开仍为保存前内容。保存后列表、详情、重新打开均显示新值。
- [ ] 保存期间重复点击无重复请求；失败不关闭或清空输入。成功有「账号已保存」反馈。
- [ ] 详情为只读信息与实际动作；本人账号手动在窗口登录后可「检查并同步」。身份不一致时看到两组昵称与 UID；失败提示语义、红色反馈正确。

## 4. 批量接入：输入 → 预览 → 结果

- [ ] 输入页：平台、新窗口分组、分类、标签、运营备注、Cookie 列表易于理解；分类/标签与新增编辑一致。仅修改分类、标签或备注后退出，也可选择继续填写。
- [ ] 草稿关闭后重新接入：上一轮平台选择、分类、标签、备注、输入和预览不带入新一轮；窗口分组回到当前可用默认项。
- [ ] 校验并预览：有效/无效行、原行号可辨认。此步只校验，不创建窗口/账号；校验期间不能再次校验或关闭。没有选择分组时就地提示。
- [ ] 返回修改：保留平台、分组、分类、标签、备注及原文；修改后再次校验与新输入一致。无有效行不能确认接入。
- [ ] 使用本人明确用于验收的 Cookie 小批量确认：优先新建窗口；结果逐行呈现成功/未完成及可用动作；成功账号可从结果进入详情；列表读回与结果一致。
- [ ] 执行时点击「暂停并返回」：当前项结束后退出，记录可再打开；不在运行中普通关闭或重复执行。未完成项可以按实际状态继续处理。
- [ ] 完成结果：没有「继续接入（0）」；接入记录可查看原结果和未完成原因。打开已保存结果不因为旧批次分类/标签误弹放弃草稿提示。

## 5. 公共分类 / 团队 / 成员：逐页核对
