- 日期：2026-10-13

## 实施

- `web/src/shared/api/compose.js`：`createComposeTasks`/`listComposeTasks`/`getComposeTask`/`cancelComposeTask` 四方法，路径与 production 路由一一对应。
- `web/src/modules/compose/schemaFields.js`（新增）：schema → 表单字段描述；`ComposeStrategyPage` 改为共用导入，字段清单不出现第二份。
- `web/src/modules/compose/components/ComposeTaskCreateDialog.vue`（新增）：640px 对话框，三段（①选可用策略 ②schema 渲染可覆盖参数，全部可选、留空即用策略值 ③所选素材清单）；request_key 在对话框打开时逐素材 `crypto.randomUUID()` 生成、存续期间稳定——保存的双击/重试复用同批 key，命中服务端唯一键幂等；只把填过的字段放进 `config_override`。
- `MyMaterialsPage.vue`：勾选列（`checkProps` 对非 active 关系 disabled，PRD §5.4.5）；页头「创建合成任务」批量入口（无勾选禁用）；行内「加入合成」从跳占位页改为打开创建对话框（仍按使用状态 × 下载状态矩阵，每行 ≤3 按钮）；创建后按 `created`/`failed` 分列提示并重读列表；详情抽屉「合成」保持浏览跳转（去合成任务页）。
- `ComposeTasksPage.vue`（新增）：筛选与表格同卡 + 分页（AdminUI 规范/CHG081 定稿形态）；状态、策略筛选走服务端 query；五状态徽章 + 阶段列（pending 钉「等待源素材」，PRD §5.4.4）；取消仅出现在 pending 行且 DialogPlugin 确认，成败都重读（409 已被领取也只有重读看得出）；详情对话框按 id 重取，参数快照以 JSON 全文展示（不可变事实）。
- 路由：cloud/desktop 两端 `compose` 从 `ComingSoon.vue` 换成 `ComposeTasksPage.vue`；`routerParity.test.js` 加真实页守卫。
