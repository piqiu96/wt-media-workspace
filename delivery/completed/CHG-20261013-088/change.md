# CHG-20261013-088：M4 任务与成片查询、预览反馈补缺

- Status: IN_PROGRESS
- Level: M
- Milestone: `delivery/milestones/M4-content-production.md`
- Closure anchor: §3 M4-F
- Product: `docs/product/prd/详细文档/第五章_素材生产.md` §5.5、§5.9
- Affected repository: `wt-media-cloud`（Cloud API、MySQL、Cloud Web/Desktop 共用 Vue）

## 目标

运营能按创建日期查任务，按来源素材 ID 或名称及生成日期查成片；预览地址失败时仍能查看详情。任务详情对外返回已存的开始／结束时间，页面展示已有执行摘要。

## 当前事实

- 任务列表服务端只接收状态和策略，并限制最近 200 条；页面只筛已返回行会漏历史任务。
- 成片列表服务端只接收发布状态。成片保存素材 ID，素材名称在 `materials.title`。
- `GET /compose-tasks/{id}` 提供快照、阶段、进度、尝试次数和失败摘要；开始／结束时间存库但 JSON 隐藏。没有逐次执行记录端点，也没有人工失败重试端点。Worker 的自动重试不代表运营能重试。
- 预览失败分支调用不存在的 `feedback.toast.warning`。

## 范围与决定

1. Cloud 所有查询先应用权限，再按日期区间筛选；日期从当天本地零点到结束日期次日零点，接口传 RFC3339，结束边界排他。任务筛选在 `LIMIT 200` 前生效。
2. 成片来源输入同时匹配素材 ID（纯数字精确匹配）或素材名称（文字包含匹配）；结果仍受原有业务权限约束。
3. 修复预览错误反馈，并展示已有开始／结束时间与尝试次数。统一反馈不增加新的 `warning` Toast。
4. 不在本 CHG 新增逐次执行记录、人工重试、任务分组或新的业务状态；这些属于 M4-G。一次选多个素材仍是多个任务。

## 验收

1. 查询旧日期能返回该范围任务，不受更新任务挤出最近 200 条；越权结果不可见，非法时间拒绝。
2. 成片按素材 ID 或名称查得同一来源，日期边界正确；清空条件恢复列表。
3. 预览地址失败时详情不关闭，无不存在的 Toast 方法调用。
4. 任务详情显示实际开始／结束时间和尝试次数；人工重试入口保持未开放，M4-G 的缺口结论明确。

## Pending Questions

## 验收结论

T-01～T-03 均已完成，Cloud commit `b5cdffc`，证据见 `evidence/`。验收逐项：

1. PASS——日期区间在权限过滤后、`LIMIT 200` 前生效（SQL 断言），非法/逆序时间 400 拒绝；范围过滤沿用既有 scope-in-SQL 测试。

4. PASS——详情投影并展示开始／结束时间与执行次数；人工重试入口未新增，M4-G 服务端缺口结论已登记在里程碑「页面缺口的独立闭环」表。
