# Historical Reports

This directory holds execution and audit reports from past work. It is not a status source and is not loaded by default.

## How to use it

- Read a report only when a task explicitly names it as historical context.
- Current delivery state lives in [the Ledger](../LEDGER.md), `delivery/active/`, and `delivery/milestones/`.
- Do not rewrite the reports. If a conclusion becomes current, write it into the owning CHG, milestone, or stable fact source.
