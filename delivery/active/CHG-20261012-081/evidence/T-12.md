# T-12 AdminUI 视觉规范贯彻与策略页视觉优化

- 日期：2026-10-13
- Cloud commit：`0cb2dd9`；Workspace commit：`500584f`（规范文档与设计图入库）
- 背景：用户裁定 `docs/standards/前端视觉-AdminUI规范.md` 为 Admin 页面视觉与交互基线，要求贯彻到 M4-M5 后续执行，并对当前页面优化一版视觉。

## 实施

- 规范入库：`docs/standards/前端视觉-AdminUI规范.md` 与其引用的四张设计图 `assets/images/ui/image1-4.png` 提交进 Workspace，后续 M4-M5 任务可直接引用。
- 合成策略页对照规范逐条收敛（`ComposeStrategyPage.vue`）：
  - §2.1 筛选区：由本地 `.filter-row`/`.filter-field` 改为内容池同构的共享 `filter-bar` + `wt-filter-field`/`wt-filter-actions`（响应式网格来自 `resource-module.css`），查询（主）+ 重置（线框）固定次序。
  - §4.1 容器选择：编辑容器由 640px Dialog 换成 520px Drawer，分组「① 基础信息 / ② 模板参数」——模板参数字段随模板 schema 增长，属「复杂配置/长流程」场景。
  - §6.2 编辑场景：底部「取消（左）+ 保存（右）」；打开时对表单状态做快照，X 与「取消」走同一条关闭路径，内容有变更时弹「放弃未保存的修改？」二次提示后才关闭。
  - §5.6 就近校验：策略名称与模板参数字段的错误红字挂在字段下方（此前只有 toast）。
  - §7 详情视图：详情抽屉分区为「基础信息 / 状态信息 / 模板参数 / 时间信息」，只读场景仅保留右上角 X，无任何提交按钮。
  - 按钮文案本已合规（新增策略/详情/编辑/复制/保存/查询/重置），未动。
- 个人信息页非列表页（无筛选区/表格/操作列），本轮不在规范适用面内。
