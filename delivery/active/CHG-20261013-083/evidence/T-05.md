# T-05 API：running 取消语义与投影比对

- 日期：2026-10-14
- 实施：`service/task.go` Cancel 分支（pending 翻转不变；running 走 `RequestComposeCancel` 并以 `running + cancel_requested` 应答；终态拒绝）+ `task_handler.go` 15217 文案收窄 + openapi 409/stage 描述修订 + `wire_test.go` 新增 ComposeTask 投影⇄openapi 比对。
- 红先如实登记：running 取消语义用例先落并确认红（`running cancel error = compose task is not cancellable`），实现后转绿；投影比对测试首跑即绿，其判别力由结构保证（键集合必须与 openapi properties 完全相等，空解析会显式 Fatal）。

## 语义（每条被用例钉住）

| 行为 | 用例 |
| --- | --- |

| 投影键集合：model JSON 20 键 == openapi ComposeTask 20 properties | TestTheComposeTaskResponseMatchesTheOpenAPISchema |

## 合同同步

- openapi cancel `409` 描述从「Task is not pending」改为「Task is terminal (success, failed or cancelled)」，与 15217 语义一致（T-01 已改 description，本次补齐 responses 行）。
- openapi `stage` 描述改为 worker 有限枚举（validating_input/waiting_input/cutting/uploading/committing），替换 T-01 误写的展示字符串「等待源素材」；pending 行 stage 为空串。
- 错误码冻结名无新增（15217 复用，http_status 409 不变，content-production.yaml 未动）；执行失败是任务行上的 `error_code` 自由串，不是 HTTP 错误，与 T-01 修订一致。
