# CHG-20261120-106：M6 图片库、封面模板与快速发布补全

## Change

交付一个完整用户结果：用真实图片库/模板、手工或AI内容准备百度快速发布，保存和恢复填写，授权自动投稿，处理人工卡点与异常，核实公开作品并得到正确成功统计。2026-11-20用户确认将快速发布依赖的全部运营工具前移M6；B站、小红书后续交付。批次及计划不进入本CHG。

2026-11-20按用户最新要求，CHG101只收齐四仓已有本地代码并归档；本CHG统一承接图片库、封面模板及快速发布剩余业务闭环，不再拆分工具或按钮CHG。依赖CHG101四仓合入，启动前核对归档的合并提交。M6保持IN_PROGRESS，B站、小红书、批次和计划仍后续交付。

2026-11-21确认命名与落位：接口实体统一单数；选图使用 `POST /image-asset/select`，文案生成使用 `POST /publication/generate`，用途和类目通过请求条件表达。图片、封面模板与渲染统一归 Cloud `internal/modules/image/` 及共用前端 `web/src/modules/image/`；生成文案仍归 `publish`。英文类型使用单数名词，函数使用明确动词并遵循各语言命名惯例。提供方实现时补齐正式契约，再同步调用方；两个新名称不改变既定状态、动作、选图引用或文案审阅确认规则。具体接口与 Handler 映射见发布工程设计 §5.2。

命名同步提交 `e35098f` 仅修改 Workspace 工程设计与本记录；同步时这两个接口尚未实现。2026-11-21按用户指令执行 `wt chg start CHG-20261120-106`，四仓依赖、分支及干净工作区检查通过，开始实际代码实施。本CHG保持IMPLEMENTING，首批后端交付与剩余工作见[执行检查点](checkpoint.md)。

已交付基线与真实审核中回执继承[CHG101最终证据](../../completed/CHG-20261118-101/evidence/verification.md)；已有两条稿件沿原任务核实，不重复投稿。原型覆盖完整目标，现有页面不代表功能已全实现。公开作品、完整工具及剩余状态动作须由本CHG实际验收。

有序Tasks（同一业务闭环内的实施顺序，不是新的CHG）：

1. **图片和模板实际可用。** 实现图片上传/用途/类目/尺寸/启停/引用保护，模板制作、草稿/发布/启停/复制及全部必需规格真实渲染；快速发布采用真实输出，停用与更新不破坏已确认内容。先提供方契约与测试，再共用页面和消费验证。
2. **快速发布完整准备。** 接入素材自带图/现成图/模板方式、单条真实AI生成/审阅采用、内容确认及变化失效、成片真实缩略图；Desktop按环境/用户/模块保存续编并重启恢复，Web当前应用内暂存及明确刷新清空。保留人工稿、返回上下文和失败输入。
3. **结果与异常完整收尾。** 安全终止、原账号现场人工继续、四种核实结论、审核中补录、真实公开作品关联、同任务安全重试、安全放弃及条件复制；按PRD复查权限、revision、原attempt和资源证据。取消/终止保留占用，符合安全条件的放弃才释放。
4. **公开成功与整体验收。** 复验任务/尝试/作品一致、今日已发布按实际公开时间统计，审核中/失败/取消/放弃均不计成功；覆盖断网、重启、并发、旧响应、旧修订与返回恢复；正式页面对照固定原型基线完成Web及安装版验收，至少一条真实公开作品核对通过后由用户签收。

每Task先做必要失败验证，再最小实现、定向检查、净差异Review和最终结论更新；复杂方案只在需要时使用现有可选plan.md。多仓每仓独立PR，均引用本CHG，提供方先于消费者合并；不建立一套新的横向交付计划。

2026-11-22用户补充并确认正式应用视觉整改：运营工具（图片库／封面模板）、作品管理、内容挖掘、内容生产的列表、筛选区、详情与内嵌表格对齐现有原型、公共视觉规范及发布任务。仅修改Cloud共用Vue表现层，不调整后端、接口、业务字段、权限或状态动作；作为Task 4正式页面一致性整改执行，不代表M6整体已验收。

2026-11-23用户确认执行个人信息和桌面设置已评审方案：作为Task 4一致性整改，实施个人信息默认只读/显式编辑、统一分区标题和紧凑资料；桌面设置固定侧栏左下，页内合并下载与存储/本地日志，沿用原权限。Desktop提供历史目录读取、仅移除查找登记和受控打开的最小桥接补齐，选择目录复用原生选择器；历史继续存储于既有TOML，不新增数据库或Cloud HTTP接口，不变更Agent执行。系统配置文件路径仅只读展示，不支持修改。移除登记不得删除目录、文件或业务记录。最终入口和标题统一称“桌面设置”。正式规则见[PRD第三章](../../../docs/product/prd/详细文档/第三章_用户与账号管理.md)和[工程架构](../../../docs/engineering/architecture/社媒运营平台工程架构与分层设计_V1.md)；实测见[验证摘要](evidence/desktop-settings-account.md)。

## Done When

2026-11-21用户已裁定Q-01：新增「作品管理」菜单，与「发布管理」平级，子菜单为「作品列表」。本CHG补齐去重作品记录、任务关联、只读列表与详情，和成功统计共用可信公开事实；审核中稿件仍沿原任务处理。不扩展手工建作品、导入、效果采集或其他平台，不另拆CHG。正式规则见[作品管理](../../../docs/product/作品管理.md)。

- 图片库及封面模板完整生产能力能被快速发布实际使用；AI真实返回、可审阅采用且旧响应不覆盖人工稿；不能用演示或样例成品替代。
- 手工/AI文案与三种封面方式符合PRD；标题、图片或模板改变后只使受影响确认失效；渲染缺失、过期、溢出不允许确认。成片真实缩略图具有提供方字段和消费验证。
- Desktop保存草稿后重启恢复，Web临时填写边界明确；续编不进正式任务列表、不占用成片；创建成功清理、失败保留、结果不明先查询。
- PRD §6.4各状态动作均有真实接口和可用页面；核实/补录检查原账号、稿件、attempt与可信公开依据，关联作品去重且不覆盖旧结果。放弃安全释放占用，普通取消不释放。
- 至少一条百度公开作品的账号、视频、内容、时间、链接和任务/尝试/作品关联一致；发布成功统计只计可信公开结果，不将审核中回执算成功。
- 隔离数据库、Agent故障/补报、权限/并发/修订、前端与固定原型一致性、Web及安装版真实走查均通过；所有本地修复已独立提交、Review并进入对应main；用户签收后才关闭M6。

- 个人信息和桌面设置按已确认原型落地；保存/取消/失败输入、目录选择取消及持久化、历史登记移除不删文件、受控打开、整理部分失败、清理及日志读取均有定向验证；安装版结果与模拟测试分别记录。
