# 编辑封面预览专项重设计 · 2026-11-12

## 问题与改动

用户截图中的封面入口复用了整条发布内容预览：大图、侧栏、重复发布字段及整任务校验同时出现，视觉和任务目的不一致。

| 整改前 | 整改后 |
| --- | --- |
| 最终发布内容预览，1120px 双栏 | 独立“封面预览”960px 居中弹窗 |
| 右侧发布账号、正文、分区、声明与橙色提示 | 移除重复发布详情与整任务校验，仅展示封面相关信息 |
| 比例下拉框＋三项宽幅控制条 | B站两个展示位置直接切换；单比例展示比例标识 |
| 巨幅图片与大片空白 | 有高度上限的浅色画布，图片居中完整展示 |
| 侧栏返回＋底部关闭 | 一个“返回编辑”操作，保留标准弹窗关闭与键盘关闭 |
| 打开预览会隐式生成模板 | 模板配置未生成或已过期时显示待生成状态，回编辑显式生成 |

## 文件

- Cloud `web/example/proto/publishing-design/CoverPreview.vue`：独立封面查看界面，复用统一弹窗及视觉变量。支持适应窗口、100%真实像素滚动、比例切换、加载失败/待生成状态及窄屏布局。
- `coverPreview.js`：预览取实际比例产物，未生成或过期时不回退成旧图冒充新结果。
- `QuickPublish.vue`：只有封面缩略图使用独立封面入口，新建与编辑共用。
- `App.vue`：封面入口与整内容／来源成片预览分离。预览使用内容副本，现成图片仅在副本上按平台输出规格处理，不改动编辑内容或审核状态。
- `tests/coverPreview.test.js`：实际比例产物、过期旧图、缺少比例产物及未知平台尺寸的边界检查。

全局 MediaPreview、来源成片信息预览、任务状态及列表动作未改动。
