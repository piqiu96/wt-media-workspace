# 快速发布与编辑页追加整改 · 2026-11-12

本轮依据用户截图及最新补充直接调整现有发布任务原型。最新“使用模板单入口”要求替代原先三个并列模式按钮，底层仍兼容素材图模板与图片库图模板的既有保存值。

## 修改前后

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 封面位置 | 右侧独立栏 | 标题下方整行，左侧预览、右侧配置 |
| 封面入口 | 三个并列按钮 | 替换图片、使用模板两个选项 |
| 模板底图 | 用两个模式按钮区分 | 使用模板下，在同一“选择底图”中选素材自有图片或图片库图片 |
| 图片来源 | 本地文件上传和图片库混用 | 移除任务表单文件上传，保留素材自有图片与图片库选择 |
| 分区 | 横线及封面外框 | 通过间距、编号和标题层级组织，去除分区横线与封面外框 |
| 底部操作 | 取消／取消修改与保存并列 | 新建仅保存草稿、创建任务；编辑仅保存修改，右上角关闭退出 |

代码：Cloud `web/example/proto/publishing-design/QuickPublish.vue`。新建和编辑共用布局、平台字段及封面配置，不改变列表动作及只读详情。必填标记继续使用统一红色星号，百家号保留作品描述字段。

## 实际浏览器操作

- 打开待执行任务 1001 的编辑页：发布标题→发布封面→正文，确认仅“替换图片／使用模板”两个选项；任务表单文件上传控件为 0，两个分区上边框均为 0px。
- 使用模板→素材自有图片：显示底图、封面短语、合成模板和显式生成按钮。
- 底图改为图片库“火影忍者连招教学”，输入“实战进阶”，选择“通用动态短标题 1200×900”并点击生成：得到实际本地合成的图片数据，生成提示消失。
- 切回素材自有图片：保留短语及模板，提示重新生成；点击生成后成功。修改配置不会自动生成。
- 切回替换图片：隐藏模板字段，预览恢复所选原图。模式切换会检查图片用途，避免带入不适用的图片库选项。
- 点击右上角关闭退出编辑，未保存任务内容；重新打开仍是原任务配置。
- 打开快速发布：恢复既有草稿，共用新封面布局，底部仅保存草稿、创建任务。保留既有资源与内容校验，本轮未创建、执行或提交任务。
