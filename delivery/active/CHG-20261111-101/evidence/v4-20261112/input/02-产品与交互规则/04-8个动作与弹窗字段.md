# 操作定义／弹窗字段／提交结果

## 统一：详情
- 页面行为：跳转/打开只读任务详情；不需要操作弹窗；所有状态可进入。
- 信息区顺序：当前状态（必要步骤） → **任务摘要（独立整行平铺）** → **发布内容（独立整行）** → 执行历史（无记录则不铺空白表）。
- 可见信息：任务/平台/类目/账号/创建与更新时间；内容封面、标题、正文摘要、话题、内容版本；真实平台记录/作品链接（存在时）；失败/审核状态及执行日志解释。
- 操作右下角；「关闭」为导航 UI 而不是发布任务业务动作；没有「保存并关闭」「查看原始日志」任务级按钮。

## 统一：编辑
- 仅待执行，进入完整编辑页，不在只读详情直接编辑；禁止抽屉嵌套抽屉。
- 平台、类目、账号、资源身份（沿用已有锁定规则）以只读为主；内容字段复用新建页组件。用户改字段后保存新版本，不触发上传。
- 内容不同平台动态生成；标题带入素材且可调整；封面 3 模式和显式 AI/模板按钮。
- 「取消修改」「保存修改」；保存不改变待执行状态。

## 统一：执行
- 仅待执行；**无确认弹窗**，点击后自动校验（必填、账号可用、等级/额度、资源、平台适配）；成功进入排队中。
- 失败则就近显示具体阻断项并定位修复入口；防重复提交，后端幂等。

## 弹窗 1：取消
- 标题：「确认取消任务」。任务身份：标题、平台、账号、当前状态。展示简短后果：停止后续执行≠撤回平台投稿；资源可能仍占用。
- 唯一可填字段：`取消原因`（选填，建议下拉加“其他”备注）；无其他必填字段。
- 底部：「保留任务」「确认取消任务」（危险按钮）。
- 待执行：安全终止直接已取消；排队中：服务端撤队成功方可已取消；执行中/等待人工：仅允许能安全停止的阶段。无法证明时给明确反馈/转结果待确认，绝不能宣称已取消。

## 弹窗 2：去处理
- 标题：「处理发布异常」。显示阻塞原因、平台、账号、阶段、需要的人工操作。
- 如果真正支持会话接管，给「打开人工处理窗口」；否则说明需前往平台官方会话，不能放装饰性假按钮。
- 系统能自动检测到处理结果则自动使用；否则询问处理结果（单选，必填）：① 已完成验证、未手动投稿；② 可能已提交内容；③ 尚未完成稍后再处理。
- 按钮：「稍后处理」「确认处理结果」。① 由服务端核验后恢复**原执行尝试**，② 转结果待确认，③ 保持等待人工。
- 不收集密码、验证码、可重复提交的“再次上传”指令。

## 弹窗 3：核实结果
- 标题：「核实发布结果」；展示身份、最后阶段、已知平台证据。
- `核实结论`：4 选 1 必填——确认已发布／已提交平台审核中／确认发布失败／仍无法判断。
- A 已发布：`最终公开作品链接`原则上必填，须校验平台域名及作品身份；不得填写账号主页/投稿或审核页。仅平台确实不能取得链接且既有平台能力支持时，可使用**唯一作品 ID＋可靠成功证据**替代；需标记待补链接，并在后续作品管理中显示限制。
- B 审核中：`投稿编号或有效审核证据`必填。
- C 发布失败：`失败原因`必填、`核实依据`必填，且系统强制确认原执行已结束+没有成功发布；不能只凭备注解锁重试。
- D 无法判断：`核实备注`选填，仍保持结果待确认。
- 系统记录核实人、时间、来源、对应执行尝试、证据，后端状态校验并发和可信性。
- 操作：「取消」「保存核实结果」。不在核实弹窗中提供重试按钮。
- 成功后自动关联作品管理（按平台+作品 ID／链接唯一性去重），后续互动/采集依平台能力、关联与账号权限开启。

## 弹窗 4：重试（以最后的精简稿为准）
- **最轻量**，不再展示大块执行条件检查、绿色 checklist 或重试配置表；也不让用户编辑内容。
- 标题：「重试任务」或「确认重试」。只读：任务标题、平台/账号、上次失败原因。说明：「确认后将重新发起一次执行，任务进入排队中；历史记录保留」。
- 字段：**零填写**。按钮：「取消」「确认重试」。
- 服务端必须在提交时做严格安全检查：前尝试终止且确认未成功发布、内容有效、账号额度/资源可用、重复投稿风险排除；不过则显示阻断原因并维持发布失败。

## 统一：复制
- **只允许发布失败、已发布、已取消、已放弃**；无弹窗，进入预填的新建任务界面。
- 复制内容/平台/类目/账号候选、封面成品或关联配置；不复制任务 ID、旧状态、执行次数/历史、资源锁定。
- 新建时必须重新校验账号可用/额度与素材引用；已发布的复制需要提醒同账号内容重复发布风险。
- 不自动创建/执行旧任务副本，用户提交时生成新的待执行任务。

## 暂停
本期**不实现**，禁止出现暂停/恢复按钮、已暂停状态、仅为暂停增加后台任务编排。
