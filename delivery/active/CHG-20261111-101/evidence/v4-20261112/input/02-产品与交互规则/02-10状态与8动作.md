# 状态、定义、允许操作

| 状态 | 业务定义 | 允许的正式操作 | 当前主操作 | 特殊约束 |
|---|---|---|---|---|
| 待执行 | 任务已创建、未执行 | 详情、编辑、执行、取消 | 编辑/执行/取消 | 不含预检失败独立状态 |
| 排队中 | 已入调度队列、未真正执行 | 详情、取消（安全撤队时） | 取消 | 不允许再次执行 |
| 执行中 | 执行器正在自动发布 | 详情、取消（可安全终止时） | 取消（有条件） | 不显示重试、暂停 |
| 等待人工 | 因登录、验证等阻塞、需要人工操作 | 详情、去处理、取消（安全条件） | 去处理 | 去处理后可能恢复原尝试或结果待确认 |
| 结果待确认 | 不能证明已发布或未发布 | 详情、核实结果 | 核实结果 | 不能重试、取消、复制或释放占用 |
| 平台审核中 | 平台已接收投稿、等待审核/公开 | 详情 | 无 | 不作为已发布、不允许复制 |
| 发布失败 | 原执行已结束且确认未成功发布 | 详情、重试（满足条件）、复制 | 重试（有条件） | 按钮文案不叫安全重试 |
| 已发布 | 已确认公开发布 | 详情、复制 | 无 | 缺有效作品链接不能提供查看作品假入口 |
| 已取消 | 已确认任务安全终止 | 详情、复制 | 无 | 不代表资源已释放 |
| 已放弃 | 任务终止、资源已按既有安全规则释放 | 详情、复制 | 无 | 不允许恢复旧任务 |

## 正式操作名只有八个
`详情` `编辑` `执行` `取消` `去处理` `核实结果` `重试` `复制`。其中只有四种会弹出专门业务弹窗：取消、去处理、核实结果、重试；「暂停」本期不提供、无「已暂停」状态。

- 详情：全部状态允许，详情页只读。作品链接、失败原因、执行记录、审核信息属于详情内信息，不额外创造任务级动作。
- 编辑：仅待执行；编辑后仍是待执行。
- 执行：仅待执行；校验通过后入队；不要在创建任务后自动执行。
- 取消：待执行直接可请求；排队中必须成功撤队；执行中、等待人工仅在可安全终止时可请求。
- 去处理：仅等待人工。完成登录/验证后按执行器证据恢复原尝试或转结果待确认。
- 核实结果：仅结果待确认。必须记录人、时间、证据、结论和尝试标识。
- 重试：仅发布失败且服务端检查安全通过；使用相同任务 ID、增加尝试。
- 复制：仅发布失败、已发布、已取消、已放弃；打开预填新建页，不修改源任务。

## 状态标签 / 业务约束
- 待执行但字段不全、预检失败、账号无额度：保持待执行，不能执行，显示具体阻断原因，不新增状态。
- 排队中、执行中、等待人工、结果待确认、平台审核中：都不是明确终态，不可复制。
- 平台已接收≠已公开：平台审核中不算已发布；不能显示伪造的完成百分比。
- 结果待确认≠发布失败：只有确认执行结束且未发布，才能转发布失败；未知时严禁重试。
- 已取消≠已放弃：取消不自动释放资源；已放弃才表示资源按安全规则释放。
