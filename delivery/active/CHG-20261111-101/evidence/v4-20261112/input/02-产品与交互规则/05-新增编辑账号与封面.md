# 新增（快速发布）与编辑的字段及体验规则

## 页面结构
- 单页两区：**01 选择发布平台与账号** → **02 配置发布内容**；没有 03 预检区域。
- 页脚右下角：取消／保存草稿（若系统已有创建前草稿能力）／创建任务。创建后状态是**待执行**，不是排队中。
- 内联字段检查/平台校验即可；不要重新做三步向导或固定冗余右侧说明面板。

## 01 平台－类目－账号
1. 先选择发布平台，随后可选该平台允许的内容类目，最后选择对应类目下的可用账号。
2. 「选择账号」打开弹窗（不是巨型常驻表格），允许：搜索账号昵称/ID、按账号类目筛选、按等级筛选、仅显示可发布账号等。
3. 账号结果展示：头像/昵称、所属平台、**账号等级**、**账号类目**、**当日可发剩余额度／日上限**、可用性和不可用原因。
4. 账号等级、剩余数和限制以账号管理/API 为准，不写死；0 额度和平台/类目不匹配的账号不可选，原因可见。
5. 切换平台/类目导致已选账号无效时必须清空失效账号并给轻提示，绝不静默保留错配。

## 02 内容配置（平台字段差异）
- 从素材携带默认**标题**及**封面**，使用当前素材内容和平台规则填充默认项。可编辑的字段依据目标平台动态增减。
- 内容组件至少容纳：标题、正文/文案、话题标签、可见范围、原创声明及平台专属字段。字段类型/字数以仓库平台 schema/真实配置为准，不能靠截图杜撰。
- 「AI 填写」是独立的显式按钮；有条件时提供确认应用建议，**不能无提示覆盖运营已经修改的字段**。
- 来源素材卡展示缩略图、标题、媒体类型、时长/尺寸、来源，不作为选择平台的第 3 步。

## 封面处理——严格三种
1. **替换图片**：用户从本地或支持的现有图片资源替换为具体成品图，不自动套模板。
2. **当前素材图 + 模板加文字**：以当前素材封面图作底图，选择模板，填写「封面短语」，明确点击「生成封面」。
3. **图片库图 + 模板生成**：先选图片库图片，再选择模板，视模板要求填写「封面短语」，明确点击「生成封面」。

- 初始默认封面为素材原封面；生成与替换后的具体资源要入版本快照。
- **封面短语**是模板叠字源；模板需要文字时必填，并受模板字数约束。纯替换图不用强填。
- 不要在每次输入时实时触发 AI/模板生成；可预览当前**已生成/已保存**封面。右侧发布效果预览不等于实时封面生成。
- 模板生成应有加载、成功、失败及重新生成的明确状态；未生成完成不可把临时预览当已选择封面。

## 编辑页
- 仅待执行能编辑，复用新增内容字段与封面逻辑，但任务平台/账号/素材引用按现有锁定规则受限，优先只读展示。
- 编辑时顶部显示「编辑发布内容 · 任务 ID」，不是「快速发布 / 新建任务」。
- 操作「取消修改」「保存修改」；保存产生新的待执行内容版本，不触发平台上传或执行尝试。

## 编辑和新建特意保留的区别
- 新建需要选择平台/类目/账号、允许复制来的预填参数；编辑针对已创建待执行任务，仅修改允许变更的字段。
- 新建不自动执行；编辑不自动重新启动。
