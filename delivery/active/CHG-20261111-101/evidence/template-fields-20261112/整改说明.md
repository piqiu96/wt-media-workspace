# 默认资源与模板驱动封面字段 · 2026-11-12

用户本轮明确要求：默认匹配平台＋类目的账号和可用成片；模板优先；底图选填，留空使用素材默认图片；按模板决定显示主标题或主副标题。新建和编辑共用表单。

## 实际变更

- `QuickPublish.vue`：选择类目后自动带入可用同平台账号、同类目可用成片。保留手动更换及更换资源前的内容清空确认；恢复已有完整草稿或编辑既有任务不会自动覆盖已选内容。无匹配项显示空态。
- `quickPublishSelection.js`：复用既有账号可用性与成片占用规则；跳过停用、失效、零额度账号及未完成、文件不可用、同平台占用成片。不同平台占用不互相阻塞，取消仍保留占用。
- `QuickPublish.vue`：使用模板→封面模板→底图（选填）→模板文字字段→显式生成。底图留空或选择“使用素材默认图片”回退素材图片，图片库仍按可用用途筛选。已生成封面在配置变化后需要重新生成。
- `covers.js`、`model.js`：根据实际可见动态文字槽提取主／副标题字段，忽略固定文字、隐藏图层和重复槽；表单、生成、预检使用同一字段定义。生成时真正绑定主副标题文字。跨比例模板只匹配相同字段集合，缺配套比例时保留明确错误。
- `content.js`：编辑副标题会使旧封面与审核失效。
- `QuickPublish.vue`、`TaskDetail.vue`：新建、编辑、复制及快照保留副标题，详情显示模板实际需要的文字。保留旧模板存储值与旧主标题字段兼容。
- 保存/创建过程中暂停草稿自动观察写入，防止创建结束又留下同一配置的活动草稿。
