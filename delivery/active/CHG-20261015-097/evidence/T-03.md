# T-03：Cloud API 与共用页面处置入口

- 先红：新增 GET/POST 路由认证测试先返回 404；页面接线测试缺少核对入口；诊断摘要测试缺少实现。三项随后转绿。
- API：`GET/POST /compose-tasks/:task_id/uncertain-review` 使用既有会话、任务 scope 和错误名；Service 仅允许管理员读取核对依据和执行处置。OpenAPI 响应模型、请求体与 Go JSON 字段由合同测试比对；返回的是当前任务投影，Worker 可能已领取刚排队的任务。
- 页面：普通运营看到结果不明确的待管理员核对提示；管理员需分别确认旧 FFmpeg 已停止、没有已提交成片并填写 20～2000 字依据。处置成败均重读任务与尝试；管理员的核对记录再次从服务端读取。执行诊断摘要只由尝试次数、阶段、结局和错误类别生成，不渲染原始错误文本或对象存储签名地址。
- 验证：`go test ./internal/modules/production/... -count=1` PASS；`npm test -- src/modules/compose/pages/ComposeTasksPage.test.js src/modules/compose/uncertainReview.test.js` 12 项 PASS；`npm run build:cloud`、`npm run build:desktop` 退出码 0；`git diff --check` 退出码 0。
- 边界：页面构建和接线测试不等于人工浏览器签收；真库 API/页面对账和 C4 统计回归属于 T-04。Cloud 提交 `7c335b1`。
