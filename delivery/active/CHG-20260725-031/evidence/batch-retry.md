# 批量失败项重试与部分成功验证

日期：2026-07-25

## 修改事实

- 批量结果面板展示：
  - 总数；
  - 成功；
  - 失败；
  - 跳过；
  - 等待。
- 每个账号展示独立状态和消息。
- 单项成功后不会因为其他账号失败而回滚。
- 存在失败项时显示“重试失败项”入口。
- 重试只重新执行失败项，不重复执行成功项或跳过项。
- 结果不确定或调用异常不会自动循环重试，只记录为失败并等待用户精确重试。

## 验证

- `npm test`：PASS，源码测试锁定批量检查入口、失败项重试入口和 Desktop-only 边界。
- `npm run build`：PASS。

## 结论

批量检查具备部分成功、逐项失败原因和失败项精确重试的首版闭环。
