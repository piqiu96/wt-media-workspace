# T-04 独立进程与占用保护

- 红测试：`go test ./internal/modules/production/compose -run TestLock -count=1` 因 `AcquireLock` 缺失而失败。
- 实现：文件锁由进程持有；第二个进程或同进程第二次占用返回 `ErrBusy`；`cmd/compose-worker` 仅加载配置、媒体工具和运行目录，不初始化数据库或 HTTP Server。
- 验证：`go test ./cmd/compose-worker ./internal/modules/production/compose -count=1` 通过；测试覆盖跨进程拒绝、释放后恢复、缺凭据和缺工具的启动失败。
- 结果：PASS。Cloud commit `f179d6e`。
