# CHG-20261015-098 实施计划

1. 依 `environment-bring-up` 强制重启并重建所有本地运行组件，记录每个 gate 的实际输出、版本与环境限制。
2. 准备可回收的真实测试素材与近期计划，先读取策略/任务/运行批次基线，再等独立 Scheduler 自然触发；按数据库、API、对象存储和 FFprobe 对账，不借手动立即执行冒充定时。
3. 在同一已验证环境中执行故障恢复、策略停用、Cloud Web 与打包 Desktop 页面、Local Agent 下载，以及 M4 人工生产与下载回归；每一步读取实际成片或文件。
4. 扫描旧路径并逐项填写 M5 验收矩阵和 M4-H2 用户走查；发现缺陷先复现定位，再在所属仓修复、回归和独立提交。最终完成需要用户签收。
