用户已确认设计并授权修改。沿用 CHG-20261118-101，状态保持 VERIFYING；本记录替代早先执行历史默认折叠与原始反馈展开的人工接续要求。

## 实施范围

- 正式历史按尝试编号倒序列出执行记录、起止时间、实际结果及简要原因，每行以「查看执行详情」进入右侧只读抽屉。宽屏三列表格，窄容器逐条重排。
- 抽屉直接复用 ResourceOverlay / ResourceSection / ResourceDescriptions / ResourceStatusBadge。标题为公共18px/600，分区为公共16px/500与蓝色竖标；分区依次为执行结果、执行过程、可选人工核实和发布内容。没有独立重复说明、反馈代码、技术信息及空底栏。
- 挂载层移出分区布局容器，以实际业务内容区边界定位，并随窗口和侧栏尺寸变化；不修改导航实现。使用公共 X/Esc 关闭和焦点恢复机制。
- 内容只来自所选尝试的固定快照；任务后续编辑不替换历史文案或封面。真实快照没有封面名时，只在文件 ID 与任务资源一致时使用该文件名称，否则显示历史文件 ID；缺失快照明确说明，不回退当前内容。
- 过程只展示已记录阶段与结果。缺少结束时间但存在错误反馈时仍能阅读反馈；完成不等于已发布，人工核实与原执行结果分别保留。未知状态按结果待确认降级；已执行旧任务缺少历史不称为尚未执行。
- 原型 TaskDetail 直接复用正式组件，通过前端适配保留原有快照标题、封面、可见范围、分区及步骤文案，避免再维护一套历史视觉。没有改变跨仓接口或审计存储。
