# CHG-20261118-101: M6-A 正式任务与文件安全

## Change

把单任务快速发布从原型接入正式 Cloud / Desktop 共用页面：选择真实百度账号、成片和现成图片，确认内容后创建未执行任务，支持查询与待执行内容修改。创建取得同平台成片占用，以请求键防重，以修订号防止覆盖编辑，保留操作者和资源快照。

文件以可空的 `deleted_at` 记录删除开始时间，不再增加删除状态。迁移保留旧删除标记，不恢复已经开始删除的文件。

文件删除按 Engineering Spec §4.6 改为锁行确认引用、标记删除、事务外物理删除、最终结算；失败可重试，已标记文件不能再被选用或签发地址。当前任务中明确保存的 `cover_file_id` 引用与删除互斥；生产策略、批次和任务中保存的 URL 不做反查或加锁，资源不可用时在生产读取时明确失败。只交付本单元需要的数据表、提供方接口和消费页面，不提前建立批次、计划或模板设施。

实际联调发现现有抖音素材的规范长链接被错误作为短链传给详情服务，阻断同类目真实成片准备。本 CHG 只修复规范长链接使用已有视频 ID 查询协议；保留短链协议，不调整素材、生产或账号的业务规则。

执行顺序：先验证文件删除与任务防重/权限失败场景，再实现数据库和接口，最后接入共用页面并实际浏览器走查。迁移在隔离数据库验证，现有账号和成片只读选择；创建任务不授权 Agent、不产生浏览器投稿。平台公开开放仍等待 M6 真实验收。

本次用户已授权单一执行器串行推进，并允许后续已验证单元通过堆叠分支/PR 临时依赖未 Review 变更；各仓独立 PR，明确合并顺序，不自动合并，不修改长期治理规则。本单元从最新 main 开始，无未合并依赖。

## Done When

2026-11-19 用户已确认执行历史视觉并授权实施：执行记录按最新优先的紧凑列表呈现，逐条以「查看执行详情」打开右侧只读抽屉；抽屉复用 ResourceOverlay、ResourceSection、ResourceDescriptions，显示执行结果、真实执行过程、可选人工核实及「发布内容」。不显示独立重复说明、反馈代码和技术信息，不改写原始审计数据；缺少历史封面名称时显示文件 ID，不将当前内容冒充历史快照。关闭保留原列表上下文，抽屉限制在业务内容区。

实施顺序：①为列表入口、固定快照与未知结果补失败回归；②替换历史折叠结构并复用公共抽屉/分区，原型同步；③运行相关回归、前端与原型构建，核对宽窄屏及打开/关闭交互，记录实际验证与限制。本轮为 Cloud 共用前端修改，不调整 API、Agent、Desktop 原生代码或投稿行为；保留当前工作区已有导航修改。提交边界为本次执行历史呈现及相应原型/文档，不混入其他既有修改。

2026-11-19 用户反馈整改：去除发布页重复时区标注及列表高级筛选多余分隔线，保留业务时区处理；执行历史按下述已确认列表与详情抽屉呈现，区分执行结果、固定输入、阶段与回执及核实依据；发布标题从真实成片的 `material_title` 默认带入，可编辑且保留人工修改。百度标题沿用 `content.description` 对应的平台文案栏，正式 PRD 与原型同步命名，不新增同义字段或改变投稿协议。本次不覆盖既有任务/历史数据，不触发新投稿，剩余人工走查仍待完成。

2026-11-19 安装版走查缺陷修复纳入本单元：Desktop 的图片策略精确允许已配置 Cloud origin，保持文件能力路径及其有效性检查；Cloud 发布页面按既定业务时区 Asia/Shanghai 统一显示、创建日期筛选与最早执行时间输入/读回，其他页面保持原行为。按失败回归→修复→定向/前端与原生检查→新安装包验证推进；不改接口、鉴权、资源占用、已有业务数据或 Agent 投稿流程。剩余真实选择、详情与投稿由人工接续，不能据此标记 M6 完成。

- 本轮页面整改继续在本 CHG 收口：正式任务列表、快速发布/编辑、详情及资源选择/核实弹窗按固定原型与公共规范核对；复用真实 shared/ui 和公共样式，公共样式显式接入，未接入的既有页面不被隐式改版。实现与原型逐项差异及宽窄屏验证见 `evidence/visual-alignment.md`。本轮不改变接口、权限、任务状态、资源占用与执行许可；不新增 AI 文案、模板或批次能力。

补充按钮职责整改：按 PRD §6.4，执行、编辑、核实结果、安全重试从列表进入，详情仅保留返回，不重复业务动作，不保留无产品依据的“刷新进展”。共享独立页底栏跟随实际内容区边界，不能覆盖展开或收起的侧栏。旧行内容修订变化时拒绝直接执行/重试，更新列表供核对。缺少接口的终止、人工现场继续、完整核实/补录、放弃与作品关联仍归 M6-C，不以本轮样式整改声明完成。

本轮顺序：①核对规范、公共原型与真实组件，记录接入缺口；②公共样式限定作用范围并接入列表/资源选择器；③对齐快速发布、详情及核实表单，保留原业务校验和单独执行确认；④验证宽窄屏、返回/输入保留、主要操作唯一、旧页面隔离，并分别构建 Cloud/Desktop。公共变更若与正式规范冲突或大幅影响既有产品，列明影响并先由产品负责人裁定；不能自行改写原规范。

- 共用页面用真实可用账号、成片和图片创建一条 pending 任务；列表与详情可读回内容、资源和占用，任务尚未执行且无投稿副作用。
- 同键同输入返回原任务；异输入、同平台成片重复占用、越权及无效资源明确拒绝；并发创建只保留一个任务。
- 仅未领取 pending 任务可按 expected_revision 修改内容；冲突不能覆盖已有输入，资源身份不能被修改。
- 文件在正式任务引用期间无法删除；并发引用与删除不会留下不可读任务；物理删除失败保留 deleted_at 时间并能安全重试，不重新暴露已删除对象。
- 新迁移、接口/权限/并发测试、前端检查和实际浏览器表单提交有可复现证据；PR 引用本 CHG，等待 Review。M6 不标记 DONE。
