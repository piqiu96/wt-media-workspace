新增公共实现全部位于 Cloud `web/src/shared/ui/resource/`：

- `ResourceOverlay.vue`：基于现有 TDesign Dialog / Drawer；正文可滚动，标题与 Footer 留在可达区域；无 Footer 槽不生成默认按钮；忙碌时隐藏 X 并阻断关闭回调，取消由业务页同步禁用。
- `ResourceForm.vue`：顶部标签、控件与说明纵向布局，可与既有 `ResourceSection` 组合。
- `ResourceNotice.vue`：静态说明 / 影响摘要，可按需展开补充；不替代错误状态。
- `ResourceEmptyState.vue`：一处空态与恢复动作，不重复空表格和多条警告。

只接入窗口和代理两个页面。样式通过显式容器类隔离，不改全站基础按钮、Toast、Alert 或其他页面；内容生产 / 内容挖掘不自动迁移。两个业务页面的 script 与 `dc07f59` 比较，除新增展示组件 import 外完全相同；未改接口、权限、真实调度与外部副作用，没有生产代码模拟结果。
