# CHG-20261028-099：运营资源（社媒账号 / 浏览器窗口 / 代理）重构

## Change

对社媒账号、浏览器窗口和代理三个核心功能块做一次完整收敛：清理混用字段和无用状态，统一启停与第三方数据命名，压缩临时扫描模型；窗口代理改为 Desktop 发起本机执行、Cloud 创建意图并收敛结果；保留团队权限、真实检测、配额、失败重试和三角色边界。

最新原型与正式前端规范继续作为页面视觉和交互基线，但不覆盖数据/接口事实。CHG107（游戏目录改为扁平业务类目）必须先完成，CHG099 再继续社媒账号及运营资源页面。

当前现状、目标模型、文档清理和任务顺序见[plan.md](plan.md)。

## 已确认的业务裁决

1. 术语统一“比特”“系统托管 / 比特自管”；ID 独立成列，操作不超过 5 项时平铺。
2. 普通运营和高级运营只能在本人 Desktop 上操作本人资源；高级运营查看成员及管理员查看时不提供代操作本机能力。
3. 一个窗口可关联多个平台账号，每平台一个；代理配额按窗口计。
4. 代理按团队共享；服务端校验团队和角色，页面隐藏不构成权限边界。
5. 代理连接检测归 Cloud；动态地址提取使用运营本机网络。
6. 同步只处理当前运营自己的窗口；新窗口勾选后才认领，归属冲突不自动转移。
7. 不再次执行存量代理清理迁移；不把数据清理当作视觉对齐手段。
8. 打开窗口后必须先关闭再停用；停用后打开、关闭、编辑不可用。
9. 批量操作采用现场进度与结果，失败仅重试失败项。
10. 托管代理只有比特更新接口明确成功才更新正式关系；拒绝、超时、断开、中断或异常响应统一按本次失败处理，清除临时额度预留，用户直接重试，不读取后人工确认。
11. 启停统一 `enabled`；比特镜像统一 `bit_`，平台事实统一 `platform_`，检测统一 `last_check_`。
12. 不建设通用操作表、检测历史表、敏感任务表或强制审计事件表。
13. Cookie 读取改为 Desktop 同步执行并回报 Cloud；删除旧异步 Cookie 任务入口和通用 `tasks` 表。

## 最终落地范围

| 范围 | 最终要求 |
| --- | --- |
| 社媒账号 | 平台账号/检查/Cookie 字段分层，列表不读取 Cookie 大字段，启停和第三方字段命名统一 |
| 窗口列表/详情/表单 | 完整多平台关系、BitBrowser 镜像和 Cloud 运营字段分离、自适应键值、备注、同步认领、失败重试 |
| 代理列表/详情/表单 | 团队范围、连接信息与复制、来源选择、启停/到期/检测/额度分离、占用阻断、最近检测原因 |
| 选择与确认 | 候选筛选、空/无匹配/不可用区分、关联账号就近展开、风险显式说明、返回保留上下文 |
| 批量与反馈 | 真实计数、逐项原因、仅失败重试、未知先核实；导入按勾选提交并处理重复/无效行 |
| 工程边界 | Vue 唯一源码在 Cloud web；Desktop 只作为 Tauri/Agent 执行桥；Workspace 不进入运行时 |

## Done When

- CHG107 已合入，所有当前业务字段和页面统一使用 `category_id/category_ids`。
- Cloud 数据模型与命名收敛完成：三块业务只保留计划中列出的 7 张领域表，不新增通用 operation/历史/审计/敏感表。
- 社媒账号列表不读取 Cookie 大字段；窗口的比特镜像、实际代理、正式关系和临时额度预留可分别读回；代理启停、检测、额度和进行中占用一致。
- 代理写入不再由 Cloud 直接访问本机 Agent；Desktop 经 Tauri 调用 Agent，并覆盖明确成功、失败、超时/断开、旧 Agent 和直接重试。
- 同一窗口不同目标并发、两个窗口抢最后名额、失败时预留释放和同步确认额度复核均通过真实 MySQL 与隔离服务验证。
- 三块页面及三角色、Cloud/Desktop、加载/空/异常/未知/禁用/忙碌/窄容器符合最新原型和正式前端规范。
- 真实比特开关、字段修改、代理应用、Cloud 检测和目标网络验收完成；未完成项如实标注，不以 fixture、HTTP 成功或页面提示替代。
- 当前文档、ADR、OpenAPI 和 business schema 与实现一致；被取代的中间裁决和重复实现说明已清理。
- 旧 `/media-accounts/{id}/cookies/read` 异步入口与 `/cloud-agent/tasks/*` 通用任务接口退役，`tasks` 表删除；Cookie 同步读取仍保留 Profile 互斥与结果读回。

## 明确排除

不接入比特标签或窗口业务标签；不恢复窗口分配、批量任务中心或父子重试任务；不迁移动态提取归属；不新增通用层级/标签/工作流模型。审核、提交、合并、发布分别处理，不自行合并发布。
