## 已确认的业务裁决

1. 术语统一“比特”“系统托管 / 比特自管”；ID独立成列，操作≤5项平铺，超过5项才收进更多。
2. 普通运营与高级运营在本人桌面端可操作本人窗口；高级运营查看成员、网页版与管理员查看窗口时不提供代操作本机能力，不显示他人运行状态。权限仍由真实服务校验。
3. 一个窗口可关联多个平台账号，每平台一个；代理配额按窗口计，不按账号数计。
4. 代理按团队共享；普通/高级运营固定本人团队，管理员可筛团队；服务端拒绝跨团队读写。
5. 代理检测归Cloud服务端；动态提取仍按既有本人桌面能力执行。成功必须来自真实执行与必要读回，未知结果先核实，不能报固定成功。
6. 同步只处理当前运营自己的窗口；新窗口默认不认领，勾选后确认归属；已被他人持有时提示归属冲突。不恢复分配入口。
7. 存量代理清理已获此前用户裁决，后续不得因视觉对齐再次执行数据清理迁移；保留已有迁移与数据事实。
8. 已打开窗口先关闭再停用；停用后打开/关闭/编辑不可用；批量运行状态混选时阻断对应动作。
9. 批量动作采用现场“进度→结果→失败重试/待确认核实”；处理中不可普通关闭，不恢复任务中心、任务编号或整次报告。

## 最终落地范围

| 范围 | 最终要求 |
| --- | --- |
| 窗口列表/详情/表单 | 已确认行操作层级、完整多平台关系、自适应横向键值、托管值与比特实际值对比、短表单、运营备注、同步认领及异常恢复 |
| 代理列表/详情/表单 | 团队范围、连接信息及凭据复制、来源选择卡、启停/到期/检测/额度独立表达、删除占用阻断、长配置与短资料编辑 |
| 选择与确认 | 候选筛选、空资源/无匹配/不可用区分、关联账号就近展开、必要风险显式保留、返回保留上下文 |
| 批量与反馈 | 真实互斥计数、逐项原因、仅失败重试、待确认先核实；导入预览按勾选提交并处理重复/无效行 |
| 公共能力 | 已批准Token与TDesign映射、RowActions/列宽、Descriptions、ChoiceCards、Overlay/Form/Section/Notice/StatusBadge/Progress复用；列明消费者与兼容方式 |
| 工程边界 | Vue唯一源码在Cloud web；Desktop仅保留既有桥和打包职责；原型/Workspace不是运行时依赖 |

## Done When

- 用户完成最新视觉和本执行计划审核，确认项按plan写回；所有阻断差异有明确决定。
- 两页在相同视口与状态下达到最新稿的布局、比例、密度、字号、间距、操作层级和提示质量；运营备注14px/22px、24px分组/8px控件间距落实；打开为纯文字无前置图标。
- 列表/详情/新建编辑/选择确认/反馈/批量及三角色、Cloud/Desktop环境、加载/空/异常/未知/禁用/忙碌/窄容器均覆盖，不能以单张正常态截图代表完成。
- 窗口编辑经Agent写入并逐字段读回后再更新Cloud；代理实际应用、配置不一致处理、窗口停用与批量阻断保留真实语义。
- 代理团队权限、Cloud检测分类与迟到结果保护、启停/到期、配额并发、删除占用及导入勾选结果通过实际服务验证。
- Go相关检查、前端必要回归、Cloud/Desktop共用前端构建及真实比特/目标网络验收完成；保存与最终代码基线对应的最终结论，未通过项如实标注。
- 公共主题消费者兼容回归完成；最终稿、正式规范与实现一致，人工视觉review通过。审核、提交、合并、发布分别处理，不自行合并发布。
