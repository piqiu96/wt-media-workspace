# 成片资产实施边界

## 提供方与数据库

- `GET /compose-output-materials` 替代无产品入口的 archive POST，总路由数保持 36；按受权成片的 `material_id` 聚合与分页，不新增表。
- `GET /compose-outputs` 返回 `{items,total,page,page_size}`，精确过滤素材／批次，范围先授权；禁止浏览器下载全库再切页。
- 每个成片投影包含稳定名称、素材标题／作者、原任务批次／组名／平台、视频可用性和允许操作；详情保留 `{output,trace}`。制作配置从原任务快照取值，并使用任务同一脱敏规则，不能返回当前策略配置或固定地址。
- 新增资产列 `name`、`file_name`，保留旧行未知值；实际输出探测宽高随大小、Hash、时长一起提交。名称不是视频元数据，不混入 media JSON。
- 文件访问和下载入队均先核验对象，存储异常不能投影为不存在，更不能改原任务成功事实。未知负责人仅管理角色可核查。
- 下载传输的已有公开字段为 `category_name`，补齐旧 `game_name` 列改名迁移并验证原数据不丢，消除文件列表／入队 SQL 异常。
- 发布关联当前没有真实执行领域，返回不可用能力与原因，界面不构造“已安排／已发布”。

## 再次制作

沿用 POST 创建接口，增加 `source_output_id`。原成片与任务确定原素材、负责人、模板版本、唯一原组及最终参数，份数固定 1；原版本开放参数才可调整。新请求须现策略仍启用、归属一致、原负责人有效及原模板可部署，源素材可获取；源成片对象丢失可再制作。资料不足或配置不可执行时明示拒绝，不静默换新策略。命令摘要包括源成片 ID，重放返回原结果。原 source/task 关联写入批次快照，不建新的命令接口或表。

## 共用前端

默认素材聚合视图，行仅“详情”；成片列表仅业务列，窄选择列和公共批量栏。成片详情无播放器／封面，ID、状态、负责人在基本信息；视频文件蓝色可点击、信息展开，时长／分辨率／大小合并一行。适用平台只在发布区出现。局部设备下载事实不进入 Cloud 分页条件，不用本地对一页过滤后伪造全局总数。再制作带原快照进入统一创建弹窗，不允许切换策略或增删组。

## 验证

权限先聚合、跨批次同素材、分页总数、未知负责人、缺失对象、临时存储异常、元数据真实与历史配置不漂移；再制作单组一份、固定参数越权、旧模板不可执行、同键异源与重放；真实视频产出、访问与当前设备下载。合同版本与消费者同步，双端构建、真实 Web 典型／窄屏检查。原生 Desktop 完整走查继续在 CHG118 验证。
