# T-02：自动重试错误分类

- 先红：新增缺失源对象、临时引导视频下载、输出读回不一致和上下文取消用例，分别出现 `undefined: storage.ErrObjectNotFound`、`undefined: compose.ErrGuideTemporary`、以及取消后意外 `retry`；原有篡改读回用例原本期望 `retry`，改按产品基线断言 `failed`。
- 实施：MinIO 仅将 `NoSuchKey`/`NoSuchObject` 标成源对象缺失，`NoSuchBucket` 仍是设施故障；引导视频传输/HTTP 429/5xx 标成临时错误，失效链接与非公网目标维持业务错误；输出为空或上传读回大小/Hash 不一致终止，不自动重试；取消或失租引发的上下文取消不再重排。
- 期望：技术临时错误保留同一任务并按 T-01 退避；输入/输出校验失败停止；取消/失租不增加尝试。
- 实际：`go test ./internal/infra/storage ./internal/modules/production/... ./internal/jobs/... -count=1` 8 个目标包结果为 7 `ok`、1 `no test files`，退出码 0；`git diff --check` 退出码 0。
- 范围：本 Task 是分类和回归；临时对象跨尝试隔离及失败清理属于 T-03，真 Worker 故障注入属于 T-04。
