# 登录页清晰度与按钮边缘修正（2026-10-10）

- 用户走查指出桌面登录按钮最右侧边缘不平整，且左侧 Logo、标题、说明和插画发糊。
- 原因：桌面把包含所有文字的 1672×941 视觉稿按视口宽高拉伸为背景；登录按钮的 1px 透明边框会露出底色。
- Cloud `e1d50a3`：以去掉原稿文字和表单的插画底图替换整页位图；Logo、品牌标题、说明均由浏览器实时渲染。按钮主样式去掉透明边框。登录业务脚本与手机布局未改。未采用单独生成的透明插画版本，因为其边缘和轨迹与原稿有可见差异。
- 截图：[1672 设计尺寸](screenshots/login-hd-1672.png)、[1920 宽屏](screenshots/login-hd-1920.png)、[1440 桌面](screenshots/login-hd-1440.png)、[390 手机](screenshots/login-hd-390.png)。另检查 1024、800 px 浏览器视口，均无水平溢出。
- 验证：`npm run build:cloud`、`npm run build:desktop` 均成功；登录相关 Vitest 3 文件 12 项通过；`git diff --cached --check` 通过。构建仅有已有的 Vite 大 chunk 提示。
- 待验收：部署环境用真实账号检查登录及会话替换。插画仍是带柔光效果的位图，在与 1672×941 相差较大的视口会缩放；文字和 Logo 已不随底图缩放。
