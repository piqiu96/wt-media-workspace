## 页面实施基线

业务路由：`/example/operations/tools/images`、`/example/operations/tools/templates`。先启动 Cloud 原型服务，使用启动输出中的实际访问地址打开上述路由；主机和端口以本次启动结果为准。源码及业务路由是校验依据。

已验收原型：图片库、封面模板及编辑器，发布使用端沿用任务与批次原型。源码：[Cloud publishing-design](https://github.com/piqiu96/wt-media-cloud/tree/main/web/example/proto/publishing-design) 的 `ImageLibraryDetail.vue`、`CoverTemplateManager.vue`、`CoverTemplateWorkspace.vue`；编辑器另参照[专项交互](../../docs/design/cover-templates.md)。

公共前端规范：[AdminUI](../../docs/standards/frontend/AdminUI页面规范.md)、[交互](../../docs/standards/frontend/前端交互规范.md)、[视觉与组件](../../docs/standards/frontend/前端架构与视觉规范.md)。

页面布局、交互和视觉继承上述原型。涉及正式页面的 CHG 按[页面实施与验收要求](README.md#页面实施与验收基线)引用具体原型入口，验收包含实际页面与原型的一致性检查；差异先由产品负责人裁定，不另行设计一套界面。

## 用真实工具完成三平台发布

| 要回答的问题 | 本阶段交付 |
| --- | --- |
| 用户目标 | 维护可重复使用的图片和模板，在 B站、小红书、百度完成真实任务、批次和计划发布 |
| 前置能力 | M6 的文件安全保护及真实执行、M7 的批次配置已可复用；各平台有获授权的真实账号、成片及可核实的稿件入口 |
| 用户操作 | 上传/管理图片 → 创建编辑模板 → 校验并发布、启用 → 用实际标题和底图生成封面 → 确认内容 → 在三个平台分别发布 → 核对公开结果及计划进展 |
| 系统与平台动作 | Cloud 登记真实图片、保存模板草稿及发布配置并渲染真实文件；任务固定采用的文件和模板输入；Agent 按各平台要求上传、填写并自动提交，回传真实回执 |
| 同时成立才算完成 | 图片库正式可用；模板创建、编辑、发布、启停、复制及实际渲染可用；三个平台各有真实公开作品和未知结果核实证据；任务/批次/计划共同回归通过，统计与平台证据可对账 |
| 必须排除的假成功 | 编辑草稿影响正在使用的模板；保存即发布/启用；样例图冒充实际封面；比例拉伸或截断标题；停用破坏旧任务；仅一个平台成功就宣称三平台可用；以占位适配器或模拟回执验收 |

## 候选 CHG 与顺序

| 候选 | 工作内容及仓库 | 直接依赖 | 可独立验证的完成条件 |
| --- | --- | --- | --- |
| OPS-A 通用图片库 | Cloud 共用 Vue/文件服务 | M6-A | 真实上传、解码尺寸、用途/类目、选图、启停及引用查看可用；图片库与文件管理删除入口均保护引用；删除失败可安全重试，不恢复已删除对象为可用 |
| OPS-B 模板制作与实际封面 | Cloud 共用 Vue/渲染/文件服务 | OPS-A、M7-A | 草稿与发布配置分开；首次发布仍停用、更新保持启停；按实际标题生成全部所需规格，溢出阻止采用；批次和单任务都用真实产物，旧任务不随后续更新改变 |
| PLATFORM-B站 B站真实发布 | Agent 适配；Cloud 平台字段/能力及共用 Vue；Desktop 消费联验 | M7-B；百度已真实验收开放；合格现成图可先验，不强依赖 OPS-B | B站单条、多任务及异常核实通过，公开作品可查；同 Profile 跨平台不并行；回归已接通平台 |
| PLATFORM-小红书 小红书真实发布 | Agent 适配；Cloud 平台字段/能力及共用 Vue；Desktop 消费联验 | PLATFORM-B站 验收并开放；合格现成图可先验 | 小红书真实上传/自动提交/公开及未知核实通过；不得以站外链接格式代替可信结果；回归已接通平台 |
| OPS-C 三平台综合验收 | Cloud、Agent、Desktop | OPS-B、全部三平台适配、PLAN-C | 三个平台逐项验证真实任务、批次与计划；多平台/Profile 竞争、断网、停止和迟到结果通过；公开统计可核对，未通过的平台不开放 |

平台候选复用 M6/M7 的通用执行链路，按 PRD 确定的顺序开发、真实验收并开放；小红书开发依赖 B站验收开放。各平台独立验收，本阶段完成必须覆盖全部三平台。

不新增实时 AI 底图、关键帧提取、通用工作流、模板版本管理平台或效果统计系统。资源配对沿用 PRD 的 V1 范围，不增加质量等级字段、维护页或等级匹配。
