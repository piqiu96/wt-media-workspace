| 同时成立才算完成 | 图片和模板完整维护/真实使用可用；单条AI真实生成和审阅、内容确认、Desktop重启续编/Web临时填写均验证；至少一条百度真实作品公开，账号/视频/内容/时间/链接与任务、尝试、作品关联一致；所有状态操作及断网/重启/并发防重通过；公开成功统计准确；Web与安装版经用户整体验收 |
| 必须排除的假成功 | 文件选择冒充图片库；现成图冒充模板渲染；演示输出冒充AI；只有投稿号或审核中冒充公开成功；人工逐条最终提交冒充自动发布；未知直接失败/重发；取消自动释放占用；仅链接格式有效即确认公开 |

## 范围与验收重点

| 范围 | M6必须完成 |

| 图片库 | 真实上传与解码尺寸、用途/类目/比例筛选、名称维护、详情与引用、双用途、启停、删除保护；停用不破坏已确认封面和历史 |
| 封面模板 | 新建/编辑/复制、草稿与发布配置分离、发布与启停分离、全部必需规格真实渲染与溢出检查；实际标题/底图变更更新受影响成品，旧任务不随模板更新改变 |
| 快速发布内容 | 素材自带图、已有图片、模板合成三种方式；真实单条AI生成/润色、审阅采用及防旧响应覆盖；发布标题与封面标题独立、声明按事实确认；成片缩略图补真实字段与消费，不伪造 |
| 新建续编 | Desktop按环境/登录用户/模块保存一份本机草稿，重启可继续；Web仅当前应用内填写、刷新/关闭/退出清空且明确提示；创建结果未知先查询，不重复创建 |
| 状态处置 | 待执行编辑/执行/安全终止，排队及执行中按证据终止，等待人工继续原现场，未知四种核实结论，审核中补录，失败安全重试/放弃及条件复制，历史只读与作品入口 |
| 资源安全 | 同平台同成片正式占用不绕过；取消/终止保留占用，确认无发布可能且旧执行停止的明确安全放弃才释放；未知/已接收/公开持续占用；引用文件不得删除 |
| 公开结果与成功统计 | 任务、原尝试与作品可核对；补录去重且保留原证据；今日已发布按实际公开时间和业务时区统计，审核/失败/取消/放弃不计成功。单任务无计划目标分母，不新增虚构计划成功率；批次目标成功率在M7交付 |

## 实施与关闭

由一个当前CHG连续交付：收齐本地基线 → 图片与模板真实使用 → 完整内容准备与续编 → 结果/异常收尾 → 公开成功及整体验收。接口、表、按钮与技术层作为内部Task，不分别创建CHG。102～105已合并技术切片退出Active，其剩余工作由101承接；不据此宣称旧切片或完整M6已独立验收。

先发布提供方契约，再接消费方、共用Vue及Desktop锁；Cloud仍管业务事实，Agent管本机浏览器与文件，Desktop管桥接。工具的单任务使用不再依赖M7，M7仅增加批量配置和执行。

M6不包含批次调度、计划推进、B站/小红书适配、互动或效果采集。已有两条审核中稿件沿原任务核实，不以重复投稿制造通过证据。全部上述范围通过真实验证并经用户签收后开放百度完整快速发布，才标记`DONE`。
