## 单任务从内容准备到真实作品

| 要回答的问题 | 本阶段交付 |
| --- | --- |
| 用户目标 | 用真实账号发布一条真实成片，能查明投稿结果，并安全处理失败与断网 |
| 前置能力 | 账号真实 UID、所属用户和 Profile 可核实；视频与封面文件可读；必要平台字段及内容确认可用；已建立任务防重、资源占用和文件引用保护 |
| 用户操作 | 从成片或快速发布进入 → 选择账号与平台 → 准备并确认文案、现成封面和声明 → 创建任务 → 单独确认执行 → 在任务列表处理卡点、核实或补录 → 查看关联作品 |
| 系统与平台动作 | Cloud 保存任务并取得同平台成片占用；Agent 核对真实账号及文件，上传、填写并自动点击最终提交；结果先保存在本机再回传；Cloud 保存可信回执与公开依据 |
| 同时成立才算完成 | 至少一条百度（百家号）真实作品已公开，账号、视频、内容和链接匹配；任务、尝试记录与作品管理可相互核对；审核中只表示已接收；断网、重启和重复请求均未产生重复投稿；符合条件的终止、核实、补录、安全重试与放弃均经验证 |
| 必须排除的假成功 | 创建成功、HTTP 200、上传完成、投稿编号或审核中冒充公开成功；逐条人工最终提交冒充自动发布；失联即失败或重发；取消自动释放占用；补录凭链接格式判断成功 |

首条链路使用合格的素材自带图或现成图片，不以模板编辑器为前置。必须提供真实文件选择、校验与引用保护；通用图片库维护及模板制作在后续阶段完成。手工准备文案可先完成验证，AI 文案的完整使用体验安排在批次阶段，不用演示输出代替真实能力。

## 候选 CHG 与顺序

以下是拆分候选，尚无正式 CHG 编号、文件或启动授权。每项均包含所属范围的共用 Vue 页面、必要提供方契约与消费验证，不另拆三套仓库计划。

| 候选 | 工作内容及仓库 | 直接依赖 | 可独立验证的完成条件 |
| --- | --- | --- | --- |
| M6-A 正式任务与文件安全 | Cloud；选择真实账号、成片和现成图，确认内容、创建/编辑任务、占用、防重、审计；改造文件删除保护 | 现有账号、生产、文件能力 | 共用页面创建一条未执行任务；重复或并发创建不重复占用；引用文件不能从任一删除入口破坏；创建无浏览器副作用 |
| M6-B 首次自动投稿 | Cloud、Agent、Desktop；发布领取与提交前检查、真实 UID 与 Profile 互斥、本机文件校验、上传填写和自动提交、结果持久化及显示 | M6-A；先发布 Cloud/Agent 契约，再更新消费者及 Desktop 锁定版本 | 真实账号自动提交且取得匹配稿件回执；不同平台共用 Profile 也不能并行；提交边界断网不重放点击，结果不明保留待核实；仅回执不算 M6 完成 |
| M6-C 结果处置与单任务验收 | Cloud、Agent、Desktop；人工介入继续原尝试、结果核实/补录、作品查询关联、安全重试/终止/放弃、单任务续编 | M6-B | 真实公开作品可核对；模拟断网与重启后仅补报原结果；未知不能重试/释放；安全失败沿用原任务新增尝试；Desktop 续编与 Web 临时填写行为分别验证 |

共同基础设施在 M6-A/B 先完成并合并，后续批次与计划复用。M6 不提前建设批次调度、计划推进、模板编辑器、效果采集或互动功能。M6-C 验收通过并经用户确认后开放百度单任务发布，才把本阶段标记为 `DONE`。
