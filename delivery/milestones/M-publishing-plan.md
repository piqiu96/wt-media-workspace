## 从周期目标到计划结束

| 要回答的问题 | 本阶段交付 |
| --- | --- |
| 用户目标 | 按目标分批发布，系统可安全推进，运营能干预并判断最终是否达成 |
| 前置能力 | 批次真实执行及结果统计可用；目标矩阵和顺序可校验；后续批次就绪、未知任务和账号环境可查询 |
| 用户操作 | 设置平台×类目目标与拆批 → 创建计划骨架 → 逐批配置并正式创建 → 首次人工启动 → 按需暂停/恢复、确认继续或跳过 → 全部执行后核实公开结果 → 补量或填写原因结束 |
| 系统与平台动作 | 骨架不创建任务或占用；首次合法启动锁结构；按顺序授权就绪批次，Agent 自动提交；调度重启不重复推进；终止全计划时停止全部所属批次新派发，保留核实入口 |
| 同时成立才算完成 | 真实多批任务按顺序完成；失败率 10% 自动继续、超过 10% 等人工确认、零明确结果须确认跳过，任何未决任务均先处理；仅等待配置在就绪后可继续，人工暂停必须显式恢复；全批处理完及最终核实后，目标达成结束或补量/未达成结束均可验证 |
| 必须排除的假成功 | 审核中算公开目标；人工确认绕过未知；配置完成解除人工暂停；执行期间补量或改结构；单批终止误停全计划；结束后迟到结果重开计划或重放发布 |

## 候选 CHG 与顺序

| 候选 | 工作内容及仓库 | 直接依赖 | 可独立验证的完成条件 |
| --- | --- | --- | --- |
| PLAN-A 制定目标并启动首批 | Cloud 共用 Vue；Agent/Desktop 复用批次续编与执行 | M7-C | 手工/真实 AI 推荐均校验目标守恒；AI 失败可手工拆批；骨架零占用；逐批配置；失败启动不锁结构，首次合法启动只授权首个合法位置 |
| PLAN-B 自动推进与人工控制 | Cloud Scheduler/共用 Vue；Agent、Desktop 联验 | PLAN-A | 真实多批执行并复验 1/10、2/10、零分母、有未知、未配置、人工暂停、批次接管；多实例/重启/重复确认不重复派发；前序单批终止后合法后续仍可执行 |
| PLAN-C 核实、补量与最终结束 | Cloud 共用 Vue；Agent、Desktop 联验 | PLAN-B | 全部批次处理后先核实公开数；按真实缺口只追加一轮补量；目标不变；达成、未达成、整体终止均有最终结果；迟到公开只更新统计，不恢复执行 |

失败率的分子、分母和判断优先级沿用 PRD，不另设可配置阈值。计划进度、任务结果和发布成功率属于本阶段必需反馈，不依赖效果采集或数据看板。此阶段不建设互动、播放量采集、趋势排名或报表平台。
