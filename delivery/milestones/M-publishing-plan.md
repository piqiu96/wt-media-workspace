## 从周期目标到计划结束

| 要回答的问题 | 本阶段交付 |
| --- | --- |
| 用户目标 | 按目标分批发布，系统可安全推进，运营能干预并判断最终是否达成 |
| 前置能力 | 批次真实执行及结果统计可用；目标矩阵和顺序可校验；后续批次就绪、未知任务和账号环境可查询 |
| 用户操作 | 设置平台×类目目标与拆批 → 创建计划骨架 → 全部待执行批次配置并保存 → 首次人工启动并冻结计划/批次配置 → 按需暂停/恢复、确认继续或跳过 → 全部处理后核实公开结果 → 达成或填写未达成原因结束 |
| 系统与平台动作 | 骨架不创建任务或占用；首次合法启动前复查全部待执行批次配置，成功后锁计划与全部批次配置；按顺序调用同一启动器生成就绪批任务/占用/授权，Agent 自动提交；调度重启不重复推进；终止全计划时停止全部所属批次新派发，保留核实入口 |
| 同时成立才算完成 | 真实多批任务按顺序完成；失败率 10% 自动继续、超过 10% 等人工确认、零明确结果须确认跳过，任何未决任务均先处理；仅等待原资源恢复时可重检继续，人工暂停必须显式恢复；全批处理完及最终核实后，目标达成/未达成结束、无计划内追加补量及批次同名快捷操作均可验证 |
| 必须排除的假成功 | 审核中算公开目标；人工确认绕过未知；资源恢复解除人工暂停；启动后追加批次或改配置；单批终止误停全计划；结束后迟到结果重开计划或重放发布 |

## 候选 CHG 与内部顺序

| 候选 | 工作内容及仓库 | 直接依赖 | 可独立验证的完成条件 |
| --- | --- | --- | --- |
| [CHG-20261124-109](../active/CHG-20261124-109/change.md)／[review清单](../active/CHG-20261124-109/plan.md) | Cloud/Agent/Desktop；目标拆批、启动冻结、推进与批次快捷处理、核实及结束 | M7技术交付完成（`VERIFYING`，用户已指定107–109后统一整体验收） | 真实多批顺序执行、10%/未决边界、批次同名快捷操作、冻结及结束/迟到结果回归通过 |

本阶段规划一个完整的“百度计划推进与结束闭环”CHG，依赖M7技术交付完成（`VERIFYING`，用户已指定107–109后统一整体验收）后激活，内部依次完成：

1. 目标矩阵、手工/真实AI拆批、骨架及全部待执行批次配置、首次合法人工授权与冻结；目标守恒，骨架零占用，失败启动不锁结构。
2. 按顺序推进、10%边界、零分母/未决阻断、等待原资源恢复、人工暂停/恢复及单批/全计划终止；重复确认、多实例和重启不重复派发。
3. 全批处理后核实逐格公开缺口，达成或填写未达成原因结束；不在原计划追加批次或补量；目标不变，迟到结果只更新统计，不恢复执行。
4. Web与安装版整体验收，复用M6工具/任务与M7批次，不另拆前端、调度、统计CHG。

失败率的分子、分母和判断优先级沿用PRD，不另设可配置阈值。计划进度、任务结果和发布成功率随本阶段交付，不依赖效果采集；互动、播放量、趋势排名和报表平台不在范围。
