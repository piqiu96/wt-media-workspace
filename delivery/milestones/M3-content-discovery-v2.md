## 1. Milestone 目标与边界

完成外部内容进入系统的统一入口：人工主动发现与自动策略发现都沉淀为 source_content，运营在内容池筛选后转成可追踪的 material，为后续生产供给来源。

三个页面：**内容池 / 挖掘策略 / 挖掘任务**。内容池提供分享链接、关键词搜索、博主搜索三个入口。自动任务只入池，人工另行转素材。工作流仅为只读运行视图，不是编排引擎。

不做视频下载、文件存储/校验、剪辑、AI 评分、自动生产、发布、互动、数据分析；不接入抖音之外的真实渠道，不增加渠道管理后台、任意脚本或可视化调度器。

## M3-A 内容池基础能力

- 用户目标：对已入池来源统一查看、筛选、忽略/恢复和转素材。
- 前置：团队级共享、跨团队隔离和忽略规则已确认；不使用游戏关系；source_content/material 最小合同与素材只读边界明确。
- 用户操作：内容池列表 → 查看详情 → 忽略/恢复或转素材 → 素材库查看来源关联。
- 系统与外部动作：建立来源身份和状态；单条事务转换、批量独立提交、全局唯一与权限校验；本阶段不调用外部渠道。
- 同时成功：数据库与页面状态一致；并发转换只有一个 material；失败不写 material_created；素材快照可读，不标下载完成。
- 禁止假成功：手工 seed 被称为真实发现；新增未要求的手工编辑作品入口；只建表不交付页面；放宽权限来绕过模型问题。
- 验收证据：允许用标注为 fixture 的受控测试来源验证基础能力，必须在 B 再用真实外部结果复验。A 的基础通过不等于 M3 外部入口通过。
- CHG：[044](../planned/CHG-20260915-044/change.md)。

## M3-B 分享链接导入

- 用户目标：粘贴单条或批量分享链接，点击解析并入池后看到真实内容，再按需转素材。
- 前置：A 通过；供应接口、合法测试样本、云端执行环境和查询合同可用。
- 用户操作：内容池分享链接 → 输入 → 解析并入池 → 看逐条成功/重复/失败 → 列表核验 → 人工转素材。
- 系统与外部动作：清洗链接、识别渠道、解析/补全、Cloud Agent 调用真实接口；Cloud 统一入池，返回已提交事实；必要的短期技术任务不伪装成 crawl_task。
- 同时成功：标准/短链接与批量可用；失败不建残缺来源；同作品不同链接只一条；成功入池后尚无素材，人工转换后才有；供应凭据不下发前端。
- 禁止假成功：仅解析未落库；默认创建素材；只有模拟 API；不支持的平台仍显示成功；本地 Agent 误领云端发现任务。
- CHG：[045](../planned/CHG-20260915-045/change.md)。A+B 是第一道真实端到端门槛。

## M3-C 主动搜索

### M3-C1 关键词主动搜索

- 用户目标：按关键词查找作品，选择合适内容入池。
- 前置：B 通过；真实搜索、分页和筛选支持范围明确。
- 用户操作：内容池关键词搜索 → 输入/查询 → 加载结果 → 选择加入 → 内容池处理 → 素材库读回。
- 系统与外部动作：使用短期查询结果与权限凭证；跨页去重、查询隔离；确认后复用统一入池服务。
- 同时成功：未选零正式写入；新查询不被旧响应覆盖；失败保留已加载结果；跨链接/搜索仍全局唯一。
- 禁止假成功：支持范围外的筛选静默无效；入池同时建素材；技术查询 task 写成自动挖掘 crawl_task。
- CHG：[046](../planned/CHG-20260915-046/change.md)。

### M3-C2 博主主动搜索

- 用户目标：通过博主名称、账号或主页找到正确作者并选择其作品。
- 前置：C1 通过；作者定位、歧义处理、作品列表与分页的供应接口可用。
- 用户操作：输入博主标识 → 候选身份确认（有歧义时）→ 浏览作品 → 选择入池 → 人工处理。
- 系统与外部动作：渠道适配解析稳定作者 ID；读取真实作品列表；复用 C1 查询结果隔离和统一入池能力。
- 同时成功：昵称相同不混人；改昵称不改变身份；未选不入池；主动查找不会偷偷创建监控策略或业务任务。
- 禁止假成功：仅支持作者 ID 却宣称名称搜索已完成；自动把所有作品入池；把主动搜索等同作者持续监控。
- CHG：[047](../planned/CHG-20260915-047/change.md)。C1、C2 均通过才算 M3-C 完成。

## M3-D 挖掘策略配置

- 用户目标：将关键词或博主发现需求保存为统一策略，可编辑、启停并查看执行记录入口。
- 前置：C 通过；周期选择、时区、首次触发、作者首次范围、策略权限已明确。
- 用户操作：新增关键词/博主策略 → 选择抖音渠道 → 配置业务规则和周期 → 保存 → 编辑/启停 → 查看执行记录。
- 系统与外部动作：统一 discovery_strategy 与 strategy_type；引用 channel_type；业务配置和触发设置分工明确。配置保存不执行外部抓取。
- 同时成功：两种配置共用生命周期；不支持渠道不能启用；数据读回一致；历史记录不因编辑被改写；无任务时执行记录为空且含真实状态说明。
- 禁止假成功：保存启用就显示“已运行”；策略类自己启动 timer；单独维护 keyword_strategy / author_strategy；为扩展预建全部未来类型。
- CHG：[048](../planned/CHG-20260915-048/change.md)。独立验收阶段可明确显示执行尚未就绪；不能以此对外宣称自动化可用。

## M3-E 挖掘任务与自动执行

### M3-E1 关键词自动挖掘

- 用户目标：启用关键词策略后，系统按周期自动发现内容，在任务记录和内容池看到真实结果。
- 前置：D 通过；四态部分失败映射、计数口径、调度恢复与脚本安全入口已明确。
- 用户操作：确认策略周期 → 等待到期 → 查看任务开始/结束、统计/错误及只读流转状态 → 内容池核验 → 人工转素材。流转视图在本段随任务记录交付，E3 仅复验，不延后补建。
- 系统与外部动作：调度/受控脚本触发统一 Cloud 入口；权限及启用校验、周期幂等、快照、crawl_task、Cloud Agent 查询/入池回报。
- 同时成功：真实定时周期触发，任务可追踪；pending/running/success/failed 有事实依据；同策略不并行重复排队；重启/重复触发不重复入池或重复统计；无自动 material。
- 禁止假成功：只写脚本或任务列表；仅手工调用触发端点冒充定时验收；日志显示成功但内容池为空且无明确无结果原因；只靠内存锁防重。
- CHG：[049](../planned/CHG-20260915-049/change.md)。

### M3-E2 博主自动挖掘

- 用户目标：指定作者按确认的首轮和后续规则持续发现作品，进入同一内容池。
- 前置：E1 通过；首轮抓取范围、增量识别、翻页覆盖范围及真实新增样本齐备。
- 用户操作：创建作者策略 → 启用 → 检查首次任务 → 后续周期查看真实新作品 → 内容池处理。
- 系统与外部动作：稳定作者 ID 与可恢复基线/检查点；按作品 ID 判重，复用调度、任务、入池及权限服务。
- 同时成功：真实作者作品匹配；重复/置顶/同时间作品不重复；失败不推进完成基线；未扫描范围明确可见；被忽略/已转素材来源不因再次发现被重置。
- 禁止假成功：有限首页当完整历史；首次模式未决定就固化两套 UI；通过手工伪造新增证明增量通过。
- CHG：[050](../planned/CHG-20260915-050/change.md)。

### M3-E3 综合验收

- 用户目标：三个人工入口和两种自动策略在同一真实部署环境下可持续使用。
- 前置：A～E2 已独立通过；三个角色及跨组/游戏权限矩阵、版本组合与授权样本可复现。
- 用户操作：链接/关键词/博主入池 → 两种策略定时运行 → 任务查看 → 池内处理 → 素材追溯 → 只读业务流转视图核验。
- 系统与外部动作：真实接口/MySQL/Cloud Agent 验收，执行权限拒绝、重复导入、部分失败、限流及重启恢复；M2 关键路径回归。
- 同时成功：记录、列表、计数、状态与素材可对应；无凭据泄漏；未来渠道只预留不误导；用户最终确认；失败均有可恢复路径。
- 禁止假成功：静态流程图代替真实运行状态；把下载排除项报成缺陷修复；遗漏功能留在最终验收才建设；自动化 PASS 替代用户结论。
- CHG：[051](../planned/CHG-20260915-051/change.md)。E1、E2、E3 全通过才算 M3-E 和完整 M3 通过。
