# WT Media v0.1.0

首次正式版制品，使用已验收的 RC19 固定 Cloud、Agent 和 Desktop 源码重新构建，面向 Windows x64、macOS Intel 和 macOS Apple Silicon。

## 主要更新

- Cloud Linux 包使用版本自包含目录和 `wtmctl`，支持配置校验、数据库迁移、版本切换、部署验证与回退；Cloud Server 提供 Web 页面和深层路由。
- Windows Desktop 以图形界面模式启动，使用每用户数据和日志目录，保留下载目录设置并显示磁盘可用空间。
- Agent 修复 Windows 下载提交时的 `Bad file descriptor`，完成文件提交后向 Cloud 报告成功。
- Windows 安装器在覆盖安装和卸载前停止当前安装目录的 Agent。覆盖安装保留设置和设备身份；卸载时选择“删除应用数据”会清理应用私有数据，但保留用户自选目录的视频。

## 部署与验收边界

- Cloud Linux 包位于本版本 GitHub Actions Run 的 `cloud-linux-amd64` Artifact；安装前核对包内摘要并按 `wtmctl` 手册执行。发布制品不会自动部署或重启宝塔服务。
- 本次人工验收已覆盖预发布环境的部署、登录、Windows 下载与安装生命周期及 macOS 两架构走查。真实旧版本到新版本的 Cloud 数据库升级与回退尚未发生，安排在下一次升级验证；升级前需完成备份并运行部署预检。
