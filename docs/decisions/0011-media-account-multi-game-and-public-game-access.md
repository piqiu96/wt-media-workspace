# Decision 0011: 媒体账号多游戏关系与公开游戏访问

## Status

Superseded in part by Decision 0012

## Context

M2-B Milestone 已确认一个媒体账号可关联多个游戏，且可暂不关联游戏；最终 PRD 第三章仍保留“首版只归属一个游戏”。现有 Cloud 表和 API 只保存 `media_accounts.game_id`，普通运营/高级运营还按 `users.game_ids` 限制媒体账号的游戏关联。

用户已确认：当前没有线上流量，应一次性迁移旧单值关联到关系表；前端和后端同步完成多游戏管理；游戏不是私密资源，已启用游戏在媒体账号域默认可用。检查项 7/8 缺少真实受限样本，另行延期，不阻塞本次关系切换。

## Decision

1. `media_account_games` 是账号—游戏关系唯一事实源。一个账号可关联零个或多个游戏；`media_accounts.game_id` 在完成一次性迁移后删除。
2. Cloud API 的正式字段为 `game_ids`；Cloud Web 创建、编辑、列表、详情和筛选均使用完整数组。旧 `game_id` 仅保留为兼容请求/响应字段，不能成为第二事实源。
3. 已由 Decision 0012 取代：媒体账号域的非管理员游戏使用范围改由 `user_game_scopes` 约束。
4. 账号可没有游戏关系；进入可执行状态、上号完成、发布或互动预检时必须至少关联一个游戏。
5. 本决策仅覆盖媒体账号域，取代 ADR-0009 的游戏范围交集限制；账号归属、运营分组、Profile 授权及本地敏感操作边界不变。

## Consequences

- Positive：多游戏关系无单值丢失，页面可直接管理完整集合；游戏范围不再被误解为媒体账号的私密性边界。
- Negative：旧客户端若只发送 `game_id`，只能表达单元素完整替换；其他模块仍可能继续使用 `users.game_ids`，不能据此推断全系统游戏公开。
- Follow-up：CHG-20260805-032 完成多游戏迁移、范围授权、引用管理、API 与页面；CHG-20260903-034 只负责 7/8 真实受限样本校验；CHG-20260805-033 负责代理闭环与检查项 3/4。
