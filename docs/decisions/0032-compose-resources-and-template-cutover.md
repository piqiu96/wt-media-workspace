# ADR-0032：资源存储统一与当前合成模板收敛

- Status: Accepted
- Date: 2026-11-06
- Scope: Cloud 内容生产、运营文件与切片池
- Supersedes: ADR-0021 旧版本及执行代码永久保留的规则，仅针对本次明确下线的旧合成模板；四层模型及历史快照保持。

## Decision

1. 当前目录和执行实现只保留 `dynamic_pip_ending` v1，允许多条策略；未来仍以稳定code/version映射执行器，name只作显示。共用入口负责领取、租约、重试、取消、进度和提交，执行器负责素材准备计划、时间线和渲染，不引入工作流引擎或插件。
2. 旧模板数据允许退场；未落入本次旧存储清理范围的已有任务/成片及不可变快照保留读取；最新授权范围内的旧引用关联历史先备份后删除，不能借重试改变模板。下线旧执行前结束在途任务并报告未结束项。
3. 存储凭据只在Cloud；新正式对象统一wt-media及产品规定目录。位置持久化包含存储标识和完整对象键，可在已有内部对象引用字段中编码，不由新全局prefix重新解释。旧未编码引用按明确legacy配置读取，迁移先复制/校验、再CAS切换引用；原对象暂保留，不删除未知对象或覆盖冲突对象。
4. 成片ID在上传前分配，分配不等于成功成片；正式记录仍在校验完成后与任务成功事务提交。云端不保留临时前缀，使用本地隔离目录。重试/未知提交不误删已引用对象。正式路径通过数据库永久绑定内容摘要和字节数；相同内容重试有效，不同内容即使并发也被拒绝。实际S3兼容服务忽略条件PUT，因此不将其作为唯一防覆盖依据。
5. 运营文件独立管理，稳定资源链接由Cloud签发、请求时生成短期对象访问授权；bucket保持私有。删除撤销资源访问，名称修改不改变位置。
6. 抖音抓取和切片上传复用Cloud客户端/脚本；Skill编排有限候选及一次模型适用判断，不引入常驻模型任务系统或复杂检测。

## Consequences

本次按最新授权清理旧素材、成片及相关失效传输引用，验证新增完整读取链；后续迁移仍验证保留历史的完整读取。模板注册能力保留通用接口，不保留已明确退出的旧执行器作为空壳。发布/角色归属仍由既有Cloud模块负责，Agent只消费下载授权和文件事实。

2026-11-06 用户后续确认：旧数据直接删除，取消本次旧对象复制迁移。CHG125按旧存储引用核对并清理历史素材/成片及关联失效记录，保留新wt-media资产；先保存本地清理清单，不声称已删除无权限访问的远端旧对象。后续新数据的迁移工具及先核验后切换原则仍保留。
