# ADR-0031：内容生产批次、人工再次制作与受权代选材

## Status

Accepted — 2026-11-05，依据用户确认完成的内容生产产品与原型。确认产品规则不代表数据库与接口已实施。

部分替代 [ADR-0023](0023-m3-m5-team-resources-and-production-operator.md)：Decision 第 3／5／6 条、CHG-105 追加决议第 1 条中的人工选材范围，以及 CHG-098 追加决议的触发方式文案。其余团队隔离、负责人快照、本机权限、核实恢复与审计边界继续有效。旧 runs/tasks 接口的收敛为工程目标，正式提供方契约迁移前不宣称该路由已删除。

## Context

已确认原型支持一条素材按多组成片设置、各组多份生成。任务需要同次创建的整体进度；运营也需要明确区分“重试原任务”和“再次制作”。旧的同策略素材永久禁止新建，以及管理角色只能用创建者工作集的规则，无法表达这些操作。

## Decision

1. **保持一种执行任务。** 任务批次组织同次人工创建、立即执行或定时执行的实际任务，不是第二套生产任务或执行器。一条任务对应一条素材、一组成片设置中的一份产出；适用平台数量不放大任务数。零任务策略执行保留执行记录，不创建空批次。成片批次仅为按素材 ID 聚合的展示视图。
2. **区分重放、重试和新制作。** 同次提交重放不得重复创建；失败／取消任务重试保留原任务、批次与最终快照；人工明确再次制作允许建立新批次、新任务并保留原产出。立即／定时策略执行仍跳过本策略已有任务历史的素材，不能把此规则扩成所有人工创建的永久唯一限制。
3. **代办围绕任务负责人。** 普通运营为本人选材；高级运营在本团队、管理员在目标团队为合法负责人代创建时，从该负责人的工作集或同类目素材库选材。库中确认选用后写该负责人的个人关系，服务端完整授权；独立“我的素材”页、本机下载和文件操作仍属于当前用户。代办不开放他人本机资源。
4. **区分使用与任务历史。** “我的使用”按当前登录人的成功成片，“团队使用”按团队成功成片且包含本人；不随代办负责人偷偷切换，不以任务创建／失败／下载冒充已使用。普通运营不取得他人使用姓名。
5. **固定创建时配置。** 任务只允许覆盖模板显式开放的参数，组数、名称、平台、份数与顺序继承策略。未声明可调整的参数锁定。历史名称、负责人、平台及最终参数读任务快照，不读取当前策略重建。
6. **明确触发与执行口径。** 用户可见的任务来源为人工创建、立即执行、定时执行；策略执行方式仍为手动执行／定时执行。手动策略仅每次素材上限，定时策略另有每日上限，立即执行共享其定时每日额度但不移动下一计划时间。数量按受理素材计，人工新建不占策略规则执行额度。

## Consequences

- [PRD 第五章](../product/prd/详细文档/第五章_素材生产.md)是完整用户规则来源，[现有工程设计](../engineering/specs/2026-09-24-m4-m5-cloud-content-production.md)承接数据模型、幂等、权限和接口收敛；不在原型目录维护第二份技术方案。
- Cloud 需落实真实批次、组／份快照、来源枚举、授权代办与相应防重；旧运行代码及既有验收不证明新规则已交付。
- Cloud 执行、Agent 下载、Desktop 共用页面与本机隔离继续遵循 ADR-0017／ADR-0023；本决策不引入工作流、MQ、策略版本或发布领域新模型。
- 数据迁移、提供方 OpenAPI、消费者更新、实施步骤与验收进入后续 CHG，不修改已归档证据来冒充本次交付。
