# ADR-0035：投稿回执与公开作品分开保存

- 日期：2026-11-21
- 状态：Accepted
- 关联：[CHG106](../../delivery/completed/CHG-20261120-106/change.md)、[作品管理](../product/作品管理.md)

## 背景

百度投稿被接受时只有稿件回执，公开视频另有作品 ID。现有任务的 `platform_work_id` 实际保存了投稿回执；原执行结果及摘要已经用于防重，不可改写。用户确认不做旧数据兼容，且作品管理与发布管理平级。

## 决策

任务原 `platform_work_id` 列直接改名为 `platform_submission_id`，保留已发生的外部投稿身份；新增真正的 `platform_work_id`、`target_url` 与 `work_id`。原 `work_url` 改名为 `target_url`，新增只承载可信公开链接的 `work_url`。不提供双读或旧字段兼容层。原attempt报文的 `platform_work_id` 及摘要原样保留，报文里的值仍解释为原始回执，不自动当作公开作品。

Cloud提供方先更新契约与Schema，共用Vue和Agent消费同步更新。公开后由 Cloud `work` 模块按平台作品 ID去重保存业务事实，发布任务关联该记录；作品列表及成功统计共用它。人工补录和自动核验只追加后续结论，不能重写原结果或重新投稿。

## 影响

任务读取字段是一次明确的语义调整；所有当前调用方同步交付，不支持旧客户端继续把回执当作品。已知外部投稿保留，清理旧数据不能绕过投稿防重。链接合法仅是输入校验，公开结论仍要求原账号、指定稿件、内容及实际时间证据。
