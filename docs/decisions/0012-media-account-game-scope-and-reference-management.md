# Decision 0012: 媒体账号游戏范围与引用管理

## Status

Accepted

## Context

Decision 0011 已完成媒体账号多游戏关系切换，但其“已启用游戏默认公开可用”的规则绕过了用户管理中已配置的 `user_game_scopes`。同时，游戏停用和删除只检查过时的单值账号列，无法向管理员说明用户授权或媒体账号引用。

## Decision

1. `user_game_scopes` 是非管理员在媒体账号域可使用游戏的事实源；`media_account_games` 仍是账号—游戏关系的唯一事实源。
2. 普通运营、高级运营只能创建、更新、筛选和执行本人范围内且已启用的游戏；管理员为非管理员归属账号代管时同样按目标用户范围校验。管理员自身账号不受范围限制。
3. 游戏列表返回用户授权数和媒体账号引用数；管理员可按游戏查询只读关联详情。任一引用存在时，停用和删除均被前后端阻止，并返回明确的冲突错误。
4. 缩小非管理员游戏范围前，若其媒体账号仍引用将移除的游戏，则拒绝修改；不自动删除账号关系。

## Consequences

- Decision 0011 的多游戏关系、空关系和 `game_ids` 正式契约继续有效。
- 本决策取代 Decision 0011 第 3 条的“媒体账号域全部已启用游戏公开可用”规则。
- 历史越界关系不静默清理；管理员需借助关联详情处理。开发验收中的 `game1` 测试数据可在确认无账号组筛选引用后一次性移除关系和游戏记录。
