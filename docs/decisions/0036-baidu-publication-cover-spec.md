# ADR-0036：百度发布逐规格封面

- 状态：Accepted
- 日期：2026-11-22
- 关联：CHG-20261120-106，发布PRD §6.5.3

## 背景

原账号真实编辑器要求16:9横版及3:4竖版，单张不超过5M。旧实现仅固定一张图片并重复上传，无法保证模板实际排版或图片比例。用户已要求完成全部封面与快速发布遗留项，并明确无需旧数据兼容。

## 决策

新建、编辑、新执行均要求两张经实际解码元数据核对的图片，分别冻结文件、模板来源及摘要。主封面字段保持横版语义；新增portrait_cover_file_id、portrait_cover_render及对应执行摘要、短期授权和准备证据。不得拉伸、自动裁切或用另一比例代替；作品继续使用横版封面。

Cloud提供契约并核对权限、规格、不可变来源与引用保护；Agent下载验证两份文件并分别上传至对应控件。Cloud-Agent版本推进至2026.11.22.2，新Agent拒绝低于该版本的Cloud，按四仓发布组合部署，不为缺失竖版图的旧输入生成兜底图。

## 影响

旧任务与作品可只读查看、原结果可核实，不自动补图或改写原attempt。旧待执行输入若缺竖图，必须重新准备并确认后执行。没有新增业务状态、动作、独立服务或后台任务；管理员禁用Agent规则另行讨论。
