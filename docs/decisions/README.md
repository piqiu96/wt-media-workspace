# Architecture Decisions

This directory holds accepted architecture choices, technical trade-offs, and durable repository governance decisions.

## Rules

- File names use a four-digit sequence: `NNNN-short-title.md`.
- Use [the decision template](0000-decision-template.md) for a new record.
- An accepted decision is not rewritten to hide a reversal. Add a new decision that supersedes it and link both records.
- A discussion or proposal is not a decision until it is recorded here or in another stable fact source.
- This index does not summarize each ADR; read the record named by the CHG or reference.
