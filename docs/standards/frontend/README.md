# 前端规范

本目录存放 Web / Desktop 共用前端的规范，分两层：基础规范定义系统怎么搭，细则规范定义页面怎么组织、反馈怎么给。

| 层级 | 文档 | 回答的问题 |
|---|---|---|
| 基础 | [前端架构与视觉规范](前端架构与视觉规范.md) | 用什么技术、什么组件、什么 Token、放在哪一层实现？ |
| 基础 | [前端交互规范](前端交互规范.md) | 用户执行动作后发生什么，系统怎么反馈？ |
| 细则 | [AdminUI 页面规范](AdminUI页面规范.md) | 后台页面怎么组织信息和操作？ |
| 细则 | [用户反馈规范](用户反馈规范.md) | 反馈用哪个组件、什么时候消失？ |

## 一件事只有一个地方给最终答案

按问题所属领域找事实源，不按优先级覆盖：

- **页面信息架构**（区域构成、字段顺序、ID 展示、操作位置与数量、Tabs、SummaryMetrics 是否展示、Drawer 结构与宽度）→ [AdminUI 页面规范](AdminUI页面规范.md)；
- **行为与反馈**（点击、权限显隐、打开与关闭、提交、确认、Loading、异步结果）→ [前端交互规范](前端交互规范.md)；
- **实现与视觉基础**（TDesign、Token、shared/ui、样式层级、Cloud / Desktop 边界、AI 修改约束）→ [前端架构与视觉规范](前端架构与视觉规范.md)。

其他规范只引用事实源，不重复定义同一问题。跨规范冲突的核对顺序、例外与 review 流程见 [AdminUI 页面规范](AdminUI页面规范.md) §0。

视觉稿只表达目标结构、信息关系与视觉方向，不覆盖规范。现有页面整改按 PATCH 处理，差异清单与范围冻结见[前端架构与视觉规范](前端架构与视觉规范.md) §8.1。
