# Reference Material

This directory holds citable explanatory material. It reduces repeated description; it does not independently decide product or interface facts.

## Index

- [Business state models](state-models/README.md): state transitions and semantics for individual business objects.

## Boundary

- A status or interface fact still belongs to `docs/product/`, an accepted decision, or the provider's contract/schema.
- When a state model conflicts with a product baseline or contract, the baseline or contract wins; record the conflict instead of editing the reference silently.
