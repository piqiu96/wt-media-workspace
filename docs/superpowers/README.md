# Legacy Plans and Specs

This directory mixes old implementation plans and design specs. Contents are not current fact and are not loaded by default. The directory name does not make every file historical: judge each file by its content.

## How to use it

- Read a file only when a task explicitly references it as useful method or context.
- A method that is still effective belongs in `docs/product/`, `docs/engineering/`, `docs/contracts/`, `docs/decisions/`, or `docs/standards/`; promote it and stop treating this copy as the source.
- Do not treat old conclusions, paths, or commands as current; verify them against the stable fact sources first.
- Do not rewrite historical text. Files fully absorbed by current facts, or without independent traceability value, are deleted rather than kept as a second copy.

Current facts live in [the documentation index](../README.md). Execution state lives in [the Ledger](../../delivery/LEDGER.md).
