# Historical Plans and Specs

This directory is a read-only historical collection of implementation plans and design specs. It is not current fact and is not loaded by default.

## How to use it

- Read a file only when a task explicitly names it as historical context.
- Do not treat its conclusions, paths, or commands as current; verify them against the stable fact sources first.
- Do not rewrite the text. If a historical plan is superseded, the replacement belongs in `docs/product/`, `docs/engineering/`, `docs/contracts/`, `docs/decisions/`, or `delivery/`.

Current facts live in [the documentation index](../README.md). Execution state lives in [the Ledger](../../delivery/LEDGER.md).
