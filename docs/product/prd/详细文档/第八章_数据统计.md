# 第八章：数据统计

## 8.1 模块概述

### 8.1.1 模块定位

数据统计模块用于汇总内容发现、素材生产、发布、互动、账号及运行环境数据，为普通运营、高级运营和技术提供工作完成情况、流程转化、平台效果及异常积压的统一查看入口。

首版以内部运营管理为主，平台作品效果分析为辅，重点回答：

- 当前还有哪些内容、素材、任务和成片尚未处理；
- 各游戏、平台、账号和用户实际完成了多少业务结果；
- 内容从进入系统到最终发布的转化是否正常；
- 发布和互动执行是否稳定；
- 哪些账号、Browser Profile 和代理存在异常；
- 云端自动生产是否真正形成了可使用、可发布的成片；
- 当前活动周期内作品播放量和点赞量是否持续增长。

### 8.1.2 数据来源

统计数据以各业务模块的正式记录为事实来源：

```text
内容发现：
crawl_task、source_content

素材生产：
material、material_usage、compose_pool_item、task、
composite_output、production_rule、
composite_output_pool、composite_output_claim

发布管理：
publication、实际执行 task

互动管理：
tracked_object、interaction_task、
实际执行 task / 执行结果

用户与账号：
user、media_account、browser_profile、proxy_resource
```

统计模块只负责查询、汇总、展示和导出，不单独维护可由用户直接修改的统计数字。

### 8.1.3 首版建设范围

首版支持：

- 运营工作统计；
- 内容发现与素材生产统计；
- 发布统计；
- 互动统计；
- 账号与运行环境统计；
- 播放量、点赞量及点赞率；
- 趋势、排行、漏斗、积压和异常展示；
- 统计汇总下钻；
- 明细查询；
- 当前筛选结果 Excel 导出。

### 8.1.4 明确不建设

首版不建设：

- 自由拖拽式 BI；
- 自定义统计公式；
- 综合绩效评分；
- 账号综合风险评分；
- 内容爆款评分；
- AI经营分析；
- 收益预测；
- 粉丝画像及粉丝增长归因；
- 转发量统计；
- 粉丝变化统计；
- 跨模块自由拼接报表；
- 直接修改统计汇总数字。

## 8.2 统计口径与基础规则

### 8.2.1 时间口径

不同指标按照实际业务发生时间统计：

| 指标 | 统计时间 |
|---|---|
| 新增外部内容 | `source_content` 创建时间 |
| 新增素材 | `material` 创建时间 |
| 合成成功 | 成片生成完成时间 |
| 发布成功 | 实际发布时间；缺失时采用确认成功时间 |
| 发布失败、取消（`cancelled`） | 最终状态变更时间 |
| 互动成功 | 实际执行完成时间 |
| 账号检查 | 检查完成时间 |
| 播放量、点赞量 | 数据采集时间 |

快捷时间范围固定为：

- 今日；
- 昨日；
- 近3日；
- 近7日；
- 自定义时间。

所有自然日统计统一使用系统配置时区，不由用户单独配置。

### 8.2.2 历史归属口径

历史统计按业务发生时保存的用户、游戏、平台和账号等快照计算，不随后续主数据变化而改写。

发布、互动、生产等关键业务记录应保留当时有效的：

```text
user_id
game_id
platform
media_account_id
```

账号后续修改游戏、名称或其他信息，不影响已经发生的历史统计。

### 8.2.3 工作量口径

工作量按照实际完成业务动作的用户统计，不按账号当前归属或页面点击次数推算。

不计入工作量的行为包括：

- 打开页面；
- 查看详情；
- 修改筛选条件；
- 重复点击按钮；
- 批量添加标签；
- 仅创建后立即删除、未形成业务结果的无效记录。

云端自动生产计入系统产出和对应游戏业务产量，不计入任何用户的人工工作量。

### 8.2.4 任务与执行次数

任务数量和执行尝试次数必须分开。

例如一条任务执行三次，前两次失败、第三次成功：

| 指标 | 数量 |
|---|---:|
| 任务数 | 1 |
| 执行次数 | 3 |
| 重试次数 | 2 |
| 最终成功任务数 | 1 |
| 失败尝试次数 | 2 |
| 最终失败任务数 | 0 |

### 8.2.5 成功率与取消率

`cancelled` 不进入成功率分母，单独统计取消数量和取消率。

```text
成功率 =
成功数量 ÷（成功数量 + 失败数量 + 部分成功数量）
```

```text
取消率 =
取消数量 ÷ 已结束任务总数
```

排队中和执行中的任务不进入最终成功率分母。

### 8.2.6 部分成功

部分成功任务不计入成功任务数，但其中已经完成的具体动作仍计入成功动作数量。

例如一个互动任务中8个动作成功、2个动作失败：

- 任务状态：部分成功；
- 成功任务数：不增加；
- 部分成功任务数：增加1；
- 成功动作数：增加8；
- 失败动作数：增加2。

### 8.2.7 人工补录

人工补录进入正式统计，但必须标记数据来源。

建议来源包括：

```text
system_assisted   系统辅助执行
manual            人工操作
manual_supplement 人工补录
cloud_auto        云端自动生产
```

人工补录的平台效果数据必须明确标记为人工数据。

### 8.2.8 去重口径

各统计按业务主对象去重：

| 统计内容 | 唯一统计对象 |
|---|---|
| 外部内容 | `source_content` |
| 素材 | `material` |
| 成片 | `composite_output` |
| 发布 | `publication` |
| 互动任务 | `interaction_task` |
| 社媒账号 | `media_account` |

重试记录只增加执行次数，不增加任务数量。

同一成片发布到两个账号时，统计为两条 `publication`。

### 8.2.9 播放量与点赞量

平台效果数据采用日级快照，核心指标为：

- 累计播放量；
- 累计点赞量；
- 时间段播放增量；
- 时间段点赞增量；
- 点赞率。

```text
点赞率 = 点赞量 ÷ 播放量
```

评论量和收藏量在平台能够稳定获取时作为辅助指标，不作为首版强依赖。

排行榜默认按照所选时间段的播放量、点赞量增量排序，不按照历史累计值排序。

### 8.2.10 数据修正

不允许直接修改汇总统计数字。

允许：

- 修正业务记录状态；
- 补录作品链接；
- 修正真实发布时间；
- 补录播放量和点赞量；
- 标记异常数据；
- 重新计算统计结果。

所有修正保留操作日志。

## 8.3 运营工作统计

### 8.3.1 内容发现工作

统计：

- 手工链接导入数量；
- 关键词搜索任务数；
- 关键词定时任务数；
- 作者监控任务数；
- 新增 `source_content` 数量；
- 转为 `material` 的数量；
- 忽略内容数量；
- 抓取失败任务数量。

自动任务产生的内容计入系统产出，但不计入个人工作量。

### 8.3.2 素材处理工作

统计：

- 新增素材数；
- 领取素材数；
- 实际使用素材数；
- 暂停素材数；
- 退役素材数；
- 强制中断数量；
- 重复风险处理数量。

同一素材可以分别产生创建和使用两个环节的工作量。

### 8.3.3 合成与成片工作

统计：

- 创建合成任务数；
- 合成成功数；
- 合成失败数；
- 重试次数；
- 本地成片产出数；
- 云端自动生产成片数；
- 云端成片领取数；
- 成片用于发布数量。

云端自动生产不计入个人合成工作量。

### 8.3.4 发布工作

以 `publication` 为唯一统计对象，统计：

- 创建发布记录数；
- 发布成功数；
- 发布失败数；
- 取消数；
- 执行次数；
- 重试次数；
- 人工补录数；
- 成功补充作品链接数。

批量发布按实际 `publication` 条数统计，不按批次数作为核心工作量。

### 8.3.5 互动工作

互动统计基于：

```text
interaction_task
实际执行 task / 执行结果
```

统计：

- 创建互动任务数；
- 完成任务数；
- 部分成功任务数；
- 失败任务数；
- 点赞成功次数；
- 评论成功次数；
- 收藏成功次数；
- 各动作失败次数；
- 重试次数。

### 8.3.6 账号维护工作

账号维护单独展示，统计：

- CK导入成功账号数；
- 接码登录成功账号数；
- 人工验证码登录成功账号数；
- 新识别账号数；
- 单个检查次数；
- 批量检查账号数；
- 去重检查账号数；
- 发现登录异常账号数；
- 登录修复成功账号数；
- Profile创建成功数；
- 代理绑定成功数。

账号检查同时展示检查总次数和去重账号数。

### 8.3.7 批量操作

批量操作按实际处理对象数量统计：

| 操作 | 统计方式 |
|---|---|
| 批量导入40个CK | 按成功、失败账号数统计 |
| 批量创建40个Profile | 按实际创建结果统计 |
| 批量检查40个账号 | 按实际完成检查账号数统计 |
| 批量发布20条作品 | 按20条 `publication` 统计 |
| 批量添加标签 | 不计入核心工作量 |

### 8.3.8 用户工作明细与排行

支持按时间、用户、游戏、平台、工作类型、来源和状态筛选，并下钻到业务明细。

用户排行只提供客观指标：

- 内容处理数量；
- 素材处理数量；
- 合成成功数量；
- 发布成功数量；
- 互动成功动作数量；
- 账号维护数量；
- 各环节成功率；
- 平均处理时长；
- 失败数量。

不提供综合绩效分数。

## 8.4 内容发现与素材生产统计

### 8.4.1 内容发现统计

内容发现统计对象为：

```text
crawl_task
→ source_content
→ material
```

系统不存在 `crawl_result`。

临时搜索结果未进入 `source_content` 的，不计入正式内容统计。

统计：

- 链接导入次数；
- 关键词搜索任务数；
- 关键词定时任务数；
- 作者监控任务数；
- `crawl_task` 成功、失败数；
- 抓取总量；
- 去重后新增 `source_content` 数量；
- 重复内容数量；
- 转为 `material` 数量；
- 忽略内容数量。

### 8.4.2 内容来源质量

按以下来源区分：

- 链接导入；
- 关键词手动搜索；
- 关键词定时监控；
- 作者定时监控。

统计：

- 新增内容量；
- 素材转化量；
- 素材转化率；
- 重复内容量；
- 忽略内容量。

重点统计关键词和作者的素材转化率，用于判断来源质量。

### 8.4.3 `source_content` 状态

按照以下状态统计：

- `pending`：待处理；
- `materialized`：已转素材；
- `ignored`：已忽略。

展示：

- 当前待处理数量；
- 所选时间新增数量；
- 转素材数量；
- 忽略数量；
- 平均待处理时长。

### 8.4.4 素材供给与使用

统计：

- 新增素材数；
- 当前可用素材数；
- 暂停素材数；
- 退役素材数；
- 未使用素材数；
- 已使用去重素材数；
- `material_usage` 总数；
- 单素材平均使用次数；
- 重复风险提示数。

去重使用素材数和素材使用次数必须分别展示。

### 8.4.5 合成任务

基于 `compose_pool_item` 和实际 `task` 统计：

- 新增任务数；
- 待执行数；
- 执行中数；
- 合成成功数；
- 合成失败数；
- 中断数；
- 重试次数；
- 平均合成时长；
- 失败原因。

### 8.4.6 成片产出

基于 `composite_output` 统计：

- 成片产出数；
- 本地成片数；
- 云端自动生产成片数；
- 人工触发成片数；
- 可用成片数；
- 已发布使用成片数；
- 未使用成片数；
- 重复风险成片数。

### 8.4.7 云端自动生产

基于 `production_rule` 和云端执行结果统计：

- 启用规则数；
- 规则执行次数；
- 自动筛选素材数；
- 自动合成成功数；
- 自动合成失败数；
- 自动产出成片数；
- 进入审核数；
- 重复过量拦截数。

### 8.4.8 云端成片池

基于：

```text
composite_output_pool
composite_output_claim
```

统计：

- 新增入池成片数；
- 当前可领取数；
- 已领取数；
- 已下载数；
- 已发布数；
- 领取后未发布数；
- 7日未领取清理数；
- 领取率；
- 发布使用率。

```text
领取率 = 已领取成片数 ÷ 可领取成片数
```

```text
发布使用率 = 已发布成片数 ÷ 已领取成片数
```

云端成片池可见范围通过现有 `policy` JSON 控制，可按游戏、平台、内容类型和指定用户限制：

- 普通运营：查看符合自身策略范围的数据；
- 高级运营：查看负责游戏范围；
- 技术：查看全部数据。

领取成功后通过 `composite_output_claim` 独占锁定。

### 8.4.9 生产漏斗

提供简单生产发布漏斗：

```text
source_content
→ material
→ material_usage
→ composite_output
→ publication
→ 发布成功
```

每层展示数量、上一层转化率和当前积压量。

### 8.4.10 流程积压

统计：

- 待处理 `source_content`；
- 长时间未使用素材；
- 待执行合成任务；
- 合成失败待处理任务；
- 未发布成片；
- 云端已领取未发布成片。

积压时长分段：

- 1日以内；
- 1—3日；
- 3—7日；
- 超过7日。

## 8.5 发布统计

### 8.5.1 统一对象

发布统计统一以 `publication` 为唯一业务对象。

包括：

- 单条辅助发布；
- 批量辅助发布；
- 外部人工发布后的补录。

一次批量发布20条内容，统计为20条 `publication`。

### 8.5.2 核心指标

统计：

- 创建发布记录数；
- 发布成功数；
- 发布失败数；
- 发布取消数；
- 排队中数；
- 执行中数；
- 待补链接数；
- 人工补录数；
- 重试次数；
- 发布成功率；
- 取消率。

只有 `publication.status = published` 计入发布成功。`pending_backfill` 不计入发布成功，单独统计为“待补链接数”。

### 8.5.3 来源与方式

发布来源分为：

- 系统辅助发布；
- 人工补录。

单条发布和批量发布属于操作方式，不属于不同业务来源。

统计单条和批量发布数量、批次数、平均批次条数和成功率，但发布总量仍按 `publication` 条数计算。

### 8.5.4 重试

系统不存在 `publication_attempt`。

重试统计通过：

- `publication` 上的重试次数；
- 实际执行 `task` 结果。

统计：

- 有过重试的发布记录数；
- 重试总次数；
- 重试后成功数；
- 重试后仍失败数。

### 8.5.5 失败原因

按以下类型汇总：

- 比特浏览器账号不匹配；
- Profile不存在或失效；
- 账号未登录；
- 账号需要验证；
- 代理异常；
- 页面元素未找到；
- 文件异常；
- 标题、封面填写失败；
- 提交失败；
- 作品链接回填失败；
- 账号受限；
- 人工取消；
- 其他未知异常。

### 8.5.6 账号发布统计

按账号统计：

- 发布成功数；
- 发布失败数；
- 发布取消数；
- 最近发布时间；
- 近3日发布数；
- 近7日发布数；
- 播放量增量；
- 点赞量增量；
- 点赞率。

未绑定 Profile 但存在补录记录的账号仍进入发布统计。

### 8.5.7 成片使用

统计：

- 去重使用成片数；
- 已进入发布配置成片数；
- 发布成功使用成片数；
- 未发布成片数；
- 同一成片发布次数；
- 同一成片涉及账号数；
- 重复风险提示数；
- 成片到发布转化率。

### 8.5.8 作品效果

统计：

- 累计播放量；
- 累计点赞量；
- 时间段播放增量；
- 时间段点赞增量；
- 点赞率；
- 评论量，可选；
- 收藏量，可选；
- 最近采集时间。

排行榜默认按所选时间段增量排序。

## 8.6 互动统计

### 8.6.1 统计范围

首版只统计：

- 点赞；
- 评论；
- 收藏。

不统计：

- 关注；
- 转发；
- 私信；
- 主动搜索互动作品。

统计对象：

```text
tracked_object
interaction_task
实际执行 task / 执行结果
```

系统不存在 `interaction_item`。

### 8.6.2 批量操作与任务

第七章不建设独立 `interaction_batch` 对象。批量创建只是一次操作过程，统计可从操作日志和本次创建的 `interaction_task` 数量汇总。

统计：

- 批量创建操作次数；
- 批量创建任务数；
- 每次批量创建平均任务数。

以 `interaction_task` 为核心，统计：

- 创建任务数；
- 待执行数；
- 执行中数；
- 完成任务数；
- 部分成功数；
- 失败数；
- 取消数；
- 重试次数；
- 平均执行时长。

### 8.6.3 动作结果

分别统计：

- 点赞计划、成功、失败次数；
- 评论计划、成功、失败次数；
- 收藏计划、成功、失败次数；
- 已完成状态命中次数。

“已经点赞”或“已经收藏”视为目标状态已满足：

- 不算失败；
- 不计为本次新增成功动作；
- 单独统计“已完成状态命中”。

### 8.6.4 互动对象

按 `tracked_object` 统计：

- 去重互动对象数；
- 我方作品数；
- 他人作品或落地链接数；
- 每个对象的点赞、评论、收藏次数；
- 涉及账号数；
- 最近互动时间。

### 8.6.5 账号互动

按账号统计：

- 参与任务数；
- 点赞成功数；
- 评论成功数；
- 收藏成功数；
- 失败动作数；
- 重试次数；
- 最近互动时间；
- 近3日互动动作数；
- 近7日互动动作数；
- 连续失败次数；
- 验证触发次数；
- 账号受限次数；
- 互动成功率。

不建设综合风险评分。

### 8.6.6 评论来源

评论统计区分：

- 公共模板；
- 个人模板；
- DeepSeek生成；
- 人工填写。

只统计实际成功发布的评论来源，不统计仅生成、选择但未提交的评论。

同时统计：

- 评论失败数；
- 重复评论提示数；
- 同一评论内容使用次数。

### 8.6.7 互动失败原因

包括：

- 比特账号不匹配；
- Profile失效；
- 账号未登录；
- 需要验证；
- 代理异常；
- 目标作品不存在；
- 目标链接无法访问；
- 评论内容提交失败；
- 页面元素未找到；
- 账号受限；
- 操作超时；
- 人工取消；
- 其他未知异常。

## 8.9 数据更新、权限与验收要求

### 8.9.1 数据更新

业务过程数据在状态变化后及时更新。

平台效果数据采用定时采集与人工补录：

- 发布后前7日：每日采集一次；
- 超过7日：停止自动采集，按需手动更新。

本地环境数据在以下时机更新：

- 用户主动同步；
- 进入对应页面；
- 执行本地任务前；
- 批量账号检查。

### 8.9.2 统计实现

首版不建设独立数据仓库。

采用：

- 业务表直接查询；
- 简单日级汇总表。

原始业务表始终是唯一事实来源，汇总表仅用于提升性能。

### 8.9.3 平台效果快照

播放量和点赞量采用日级快照，至少关联：

- `publication_id`；
- 采集日期；
- 累计播放量；
- 累计点赞量；
- 评论量，可选；
- 收藏量，可选；
- 数据来源；
- 采集时间。

同一作品同一天多次采集时，只保留当天最后一次有效结果。

如果累计值小于上一次结果，不直接覆盖，标记为异常数据。

### 8.9.4 权限

- 普通运营：查看自己的工作、账号和符合策略范围的数据；
- 高级运营：查看负责游戏范围；
- 技术：查看全部数据；
- 导出权限与查看权限一致。

技术的云端权限不能绕过本地比特浏览器环境读取实时数据。

### 8.9.5 异常处理

原则：

1. 展示数据更新时间；
2. 缺失或过期数据明确标记；
3. 不使用默认值冒充真实数据；
4. 汇总数字可下钻核对；
5. 支持重新计算；
6. 修正原业务记录，不直接改统计总数。

### 8.9.6 数据保留

业务记录和统计明细长期保留。

高频执行日志后续可以按容量清理，但不得影响：

- 最终业务结果；
- 重试次数；
- 失败原因；
- 操作追溯；
- 历史统计。

### 8.9.7 核心验收要求

1. 所有统计数字可追溯到正式业务记录。
2. 不允许直接修改统计汇总数字。
3. 历史用户、游戏、平台和账号口径不随后续主数据变化而改写。
4. 任务数量和执行尝试次数分别统计。
5. `cancelled` 不进入成功率分母，单独统计取消数量和取消率。
6. 部分成功任务不算成功任务，但成功动作正常计数。
7. 人工补录进入统计并标记来源。
8. 云端自动生产不计入个人工作量。
9. 平台效果支持播放量、点赞量和点赞率。
10. 播放量、点赞量支持日级快照和时间段增量。
11. 快捷时间范围包含今日、昨日、近3日、近7日和自定义时间。
12. 所有核心汇总指标支持下钻到明细。
13. Excel导出范围与当前用户权限一致。
14. 账号登录状态以最近一次实际检查结果为准。
15. Profile和代理超过24小时未同步时提示数据可能过期。
16. 系统中不得引用已删除的 `crawl_result`、`interaction_item` 和 `publication_attempt`。
17. 不建设综合绩效评分和复杂 BI。
18. 汇总数据和明细数据保持一致。
19. 平台效果数据仅自动采集发布后7日。
20. 首版不建设独立数据仓库。

# 附录A：指标用途与必要性

## A.1 指标分层

| 层级 | 定位 | 展示位置 |
|---|---|---|
| 核心指标 | 每天需要查看，直接影响当前工作安排 | 统计首页 |
| 诊断指标 | 核心指标异常后，用于定位具体原因 | 各模块统计页 |
| 明细指标 | 用于追踪、审计和核对单条记录 | 明细列表 |

指标体系总量合适，但首页必须精简。批次数、重试次数、同步次数和执行次数应主要用于诊断和明细。

## A.2 普通运营决策重点

普通运营主要判断：

```text
今天做什么
哪里失败
哪个账号不能用
还有什么没处理
```

核心指标及用途：

| 指标 | 看什么问题 | 后续操作 |
|---|---|---|
| 待处理内容数 | 是否存在内容积压 | 转素材或忽略 |
| 新增素材数 | 素材供给是否充足 | 增加搜索、监控或导入 |
| 待合成任务数 | 是否卡在生产环节 | 执行合成 |
| 合成失败数 | 合成流程是否异常 | 查看原因并重试 |
| 可发布成片数 | 是否具备发布库存 | 创建发布任务 |
| 发布成功、失败数 | 发布目标及异常情况 | 继续发布或排障 |
| 待补链接数 | 发布记录是否完整 | 补作品链接 |
| 互动成功动作数 | 互动计划是否完成 | 继续任务或处理失败 |
| 登录异常账号数 | 哪些账号不可执行 | 上号、验证或检查 |
| Profile、代理异常数 | 本地环境是否正常 | 同步、修复或确认Diff |
| 近3日播放、点赞增量 | 当前活动内容是否增长 | 优先复用高效果内容 |

## A.3 高级运营决策重点

高级运营主要判断：

```text
供给够不够
生产是否有效
发布是否稳定
内容效果是否增长
人员和资源如何调整
```

核心指标及用途：

| 指标 | 看什么问题 | 后续操作 |
|---|---|---|
| 新增内容量 | 内容供给是否充足 | 调整关键词和作者 |
| 素材转化率 | 来源质量是否合格 | 停用低转化来源 |
| 可用素材库存 | 是否断供或积压 | 调整获取和生产节奏 |
| 合成成功率 | 生产是否稳定 | 调整策略、模板 |
| 成片产出数 | 产量是否满足发布需求 | 增减生产任务 |
| 云端成片发布使用率 | 自动生产是否有价值 | 优化或停用规则 |
| 发布成功率 | 发布流程是否稳定 | 处理账号、环境和流程问题 |
| 播放增量、点赞率 | 内容效果是否增长 | 调整选题、素材和账号 |
| 互动成功率 | 互动执行是否合理 | 调整频率和账号 |
| 账号及环境异常数 | 可执行资源是否充足 | 安排上号、换代理和同步 |
| 流程积压数 | 哪个环节堵塞 | 调整人员和任务 |
| 用户客观工作排行 | 工作量是否失衡 | 重新分配工作 |

## A.4 必须作为首页核心指标

- 待处理内容数；
- 新增素材数；
- 待合成任务数；
- 合成成功、失败数；
- 可发布成片数；
- 发布成功、失败数；
- 待补链接数；
- 互动成功动作数；
- 登录异常账号数；
- Profile和代理异常数；
- 播放量、点赞量增量；
- 流程积压数。

## A.5 必须建设但放模块页

- 关键词、作者素材转化率；
- 合成成功率；
- 云端成片发布使用率；
- 发布成功率；
- 点赞率；
- 评论来源；
- 账号近3日、近7日互动次数；
- 代理平台配额；
- 用户客观工作排行；
- 失败原因排行；
- 生产发布漏斗；
- 内容全流程平均耗时。

```text
内容全流程平均耗时 =
发布成功时间 - source_content进入系统时间
```

该指标用于发现内容处理、合成和发布环节的整体延迟，不放首页。

## A.6 降级为诊断或明细的指标

模块诊断指标：

- 链接导入次数；
- 关键词任务执行次数；
- 作者任务执行次数；
- 批量操作批次数；
- 每批平均任务数；
- 单条和批量发布比例；
- Profile同步次数；
- CK导入次数；
- 生产规则执行次数；
- 平均合成时长；
- 平均处理时长。

明细或审计指标：

- 每次重试记录；
- 每次同步字段变化；
- 每次账号检查记录；
- 每次代理检测记录；
- 用户操作日志；
- 同一天平台效果多次采集过程。

## A.7 不建设的指标

- 综合绩效分；
- 账号综合风险分；
- 内容爆款评分；
- AI经营建议评分；
- 粉丝增长归因；
- 转发量；
- 收益预测；
- 自定义BI公式；
- 跨模块自由拖拽报表。

## A.8 最终产品原则

```text
首页看结果和异常
→ 模块页看转化和原因
→ 明细页看具体记录
```

当前指标总量足够，不继续扩张。后续重点控制展示层级，而不是继续堆叠首页指标。
