# 公开官网与桌面安装包下载

## 范围

未登录访客可在 Cloud `/home` 了解产品并下载桌面安装包。`/` 与全部业务路由继续要求登录；独立 `/login` 页面保持可用。Desktop 不提供 `/home`。

## 页面结构

- 单页顺序固定为 Header → Hero → 产品 → 下载 → 定价 → 联系 → Footer。
- Header 使用共享品牌标识，导航固定为「产品、下载、定价、联系」，初始高亮产品；导航在滚动中保持可见，点击与上下滚动均可到达对应区域并指示当前位置。
- 公开页不展示登录入口、头像或登录引导；不虚构价格、发布数量或管理员联系方式。
- 桌面最大内容宽度 1280px；窄屏按单列重排，导航与下载入口保持可用，不产生横向溢出。

## 视觉与品牌

- Cloud 公开页与 Desktop 登录页使用同一份品牌资产、现有品牌渐变和 `--td-brand-color`；页面使用真实文字与组件，不把整张设计图铺成页面。
- 登录页左侧为品牌视觉、右侧为表单卡；窄屏改单列。用户名、密码、会话替换、角色限制与版本显示沿用现有行为。

## 下载

- 只提供三个平台：Windows x64、macOS Intel、macOS Apple 芯片，顺序固定。
- 页面从同源静态路径读取 `desktop-downloads.json`，仅在结构和 URL 合法时显示下载入口；加载失败时明确提示暂不可下载，并保留上一份可用清单。
- 清单只指向已公开正式版的真实 GitHub Release 资产；RC、Draft 与浮动 `latest` 不进入清单。
- 清单由正式版构建期按产品 Tag 生成并随 Cloud 包部署，部署前必须确认对应 Release 已公开；运行时不依赖 GitHub API。

## 失败行为

- 清单缺失、结构错误或 URL 非法时，不渲染可用下载按钮。
- 不把 GitHub API 或 Release 回读等同于终端用户网络可达或安装成功。
- 公开页任何位置都不引导未登录访客进入业务页。

## 边界

本文件拥有用户可见的页面与下载要求。视觉实现细节由 Cloud Web 代码与 `docs/standards/frontend/前端架构与视觉规范.md` 承接；发布、清单生成与部署顺序由 `docs/devops/服务部署.md` 与 ADR-0020 承接。
