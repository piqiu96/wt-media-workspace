# WT Media Governance Documents

This tree contains current governance baselines and durable governance records.

## Directories

- `product`: current effective product facts.
- `engineering`: current effective engineering facts.
- `contracts`: human-readable Cloud, Agent, and Desktop contract governance.
- `decisions`: durable decisions and reasons.

Temporary implementation plans, progress, handoffs, and verification notes belong under `../delivery/active/<change-id>/change.md`, not under `docs`.

Root `../docs` is legacy and must not be used as the source of truth for new code implementation.
