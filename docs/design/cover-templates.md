## 2. 编辑页与预览布局

独立编辑页由左侧图层、中央画布、右侧当前对象属性组成。两侧面板独立滚动，画布居中；顶部工具栏仅放图层折叠、撤销／重做和缩放。全局操作位于 Footer：返回、预览与校验、保存草稿。为 Footer 预留实际高度，不能盖住画布或最后一个属性。

预览与校验在编辑页内切换，展示实际渲染图片和问题列表。问题可定位图层并展开相关设置；普通返回保留选中对象与缩放。当前样例通过与发布检查的范围分别提示，导出的样例明确标为预览用途。

保存状态在 Footer 左侧反馈，未修改时保存禁用，修改后恢复主按钮；保存中防重复，失败保留编辑现场。离开未保存内容的选择与业务结果见 PRD 6.7.2，刷新或关闭使用浏览器原生提醒。

## 3. 编辑器图层、画布和属性交互

| 对象／动作 | V1 行为 |
| --- | --- |
| 动态主标题 | 最多一个；不能复制；可删除／隐藏并保存草稿，发布时须存在且可见；属性明确“封面标题”，样例不进入业务内容 |
| 固定文字／装饰 | 可新增、复制、重命名、删除；装饰支持颜色／透明度；删除可撤销 |
| 图层 | 紧凑列表，区分动态字段、固定文字和装饰；列表和画布选中同步；图标控制显隐、锁定和顺序；锁定仍可选中但只读；背景固定底层。已有主标题时不重复展示添加入口，删除后可补回 |
| 背景 | 选中后右侧显示“背景与画布”：纯色、固定图片或业务底图预览；固定图片选择现有底图或通过 TDesign 通用上传控件选择，失败保留原图；业务底图样例仅用于展示，正式输入来自生成环节。内置底图不含烘焙文字，品牌文字按需作为可编辑固定图层 |
| 文字属性 | 已支持字体、字号、颜色、对齐、换行、最大行数、最小字号、行高字距、描边、位置与区域尺寸；先换行、再缩字，到下限仍溢出报错；调整区域不隐式改变字号；“最多字数”独立限制内容长度，0 表示不限，不能靠缩字绕过 |
| 画布 | 画布在左右面板之间居中，适应时保留比例，100% 可双向滚动；可用高度扣除实际 Footer 和提示。拖动移动、控制点调整区域；固定文字双击进入内容编辑；方向键移动 1px，Shift 移动 10px；Ctrl／Cmd+Z 撤销、加 Shift 重做 |
| 属性切换 | 按选中对象切换，文字分内容、样式、位置尺寸；排版规则、文字效果和图层名称可折叠。绑定字段只读；不设置独立“模板设置”模式；未选中时提示选择图层或背景 |
| 安全区 | 保留文字边缘保护，默认 24px；在“背景与画布 → 画布设置”低频调整。辅助线默认显示，仅影响编辑视图，关闭不绕过校验，预览／导出不含辅助线 |

## 4. 专项走查

在 1440×900 和 1280×800 下检查画布、面板与 Footer；键盘移动、撤销重做、缩放和图层选中应可观察。校验能区分字数上限与区域不足，并定位具体设置；预览和导出不包含编辑辅助线。

当前编辑与预览复用本地 SVG → PNG 能力，界面明确标注本地原型预览；它不能证明正式渲染服务已通过验证。字体、文件加载或渲染失败应保留当前内容并允许重试。背景对比度仍由人工预览核对，不声称已有自动检测。
