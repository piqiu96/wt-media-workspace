## 创建与保存后的反馈及去向（2026-11-17 规划）

本节记录本轮交互规划，不表示原型已实施或已验收；正式产品规则仍归各模块 PRD。审查依据为当前 Cloud 原型工作稿的提交分支、列表过滤分页和容器调用，尚未进行浏览器逐场景验证。

### 已确认：快速发布

- 发布任务列表、任务详情、快速发布、单条内容编辑、批次列表／详情／配置／内容编辑、计划列表与详情的容器保持现状。
- 快速发布创建任务并保存成功后，回发布任务列表，只提示一次「任务已创建，待执行」，不自动打开详情，不增加成功弹窗或结果页。从成片管理单选带入的快速发布采用同样行为。
- 任务列表按主键 ID 倒序；不再按创建时间设计排序。排序作用于过滤后的完整集合，再分页；不修改原始数据数组顺序。
- 创建后回第一页，恢复默认筛选，清除搜索、日期、状态、平台、类目及批次／计划关联筛选，使新任务首屏可见；保留每页条数，短暂高亮本次创建行，用户主动点击名称查看详情。
- 仅快速发布创建成功使用该去向；编辑保存保留原返回逻辑，批次创建成功弹窗不受共用回调修改影响。
- 保存失败保留输入和现场，不提示成功、不跳列表；重试核对同一创建结果，防重复生成。创建成功不代表已执行或已发布。

## 维护规则

1. 本目录只保存每个业务模块一份当前工作稿，不按页面/轮次无限拆文件。
2. 每项结论标记为正式事实、用户确认、AI 建议或待确认；确认状态不得靠推测升级。
3. 产品逻辑先于交互细化；交互细化先于视觉实施。
4. 每个页面或有意义的讨论里程碑结束时，合并重复决策、清理已淘汰方案和无效过程说明。
5. 原型已实施不等于设计已验收；人工验收前不得标记 ACCEPTED。
6. 只有原型通过人工评审后，才把稳定业务规则回写现有 PRD；决策确认阶段仅更新本目录工作稿。正式规范与交付记录按原有归属承接，不创建平行正式文档。
7. 完成沉淀后移除重复规则与中间结论；若保留文件，仅作当前入口导航。Git 历史承担追溯，不额外归档逐轮稿。

本主题不是第二套 PRD、设计系统、评审系统或任务看板。
