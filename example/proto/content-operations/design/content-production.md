## 2. 模块定位与主链路

内容生产负责把团队素材转化为可追溯的成片资产。它不负责发布账号分配、发布排期或评论互动。

核心链路：

`团队素材 material → 个人工作集 material_usage（人工选材关系）→ 合成策略 compose_strategy（生产规则）→ 合成任务 compose_task（一次生产行为）→ 成片 composite_output（成功资产）`

自动策略可以直接从团队素材库选候选素材，不要求为策略创建者或负责人建立个人素材关系。人工任务从创建者当前有效的“我的素材”候选中选择；从素材库快捷选用时可在同一创建流程加入并带回。

## 3. 核心对象职责（正式 PRD 摘要）

| 对象 | 职责 | 不应混淆为 |
|---|---|---|
| `material` | 正式生产输入、来源快照和源视频准备事实 | 视频文件已下载 |
| `material_usage` | 某个用户的个人工作集关系 | 素材本身的生产状态 |
| `compose_strategy` | 可复用制作规则、团队/类目/负责人范围、执行方式 | 一次生产任务 |
| `compose_task` | 一次生产行为、创建人/负责人、快照、执行与恢复 | 一批成片或一个通用 Agent task |
| `composite_output` | 一条成功生成的成片资产 | 发布记录 |
| `file_transfer_task` | 原素材或成片的一次文件传输 | 是否加入个人工作集 |

发布事实属于后续发布模块的 `publication`，不能用下载状态或合成状态冒充发布。

## 4. 页面职责边界（当前基线）

| 页面 | 核心职责 | 不负责 |
|---|---|---|
| 素材库 | 发现、判断团队素材，查看来源/表现/团队使用，加入个人工作集 | 本机下载、创建合成任务 |
| 我的素材 | 管理当前用户工作集、查看个人使用与文件、下载原视频、移出/恢复 | 通用合成任务创建入口 |
| 合成策略 | 维护可复用生产规则、执行方式、选材条件和策略运行记录 | 人工逐条选材创建的唯一入口 |
| 新建合成任务 | 选择负责人（按角色）、策略、素材和本次参数，创建独立任务 | 修改策略默认配置 |
| 合成任务 | 追踪独立生产任务、执行阶段、失败恢复和结果 | 发布排期 |
| 成片管理 | 管理成功生成的成片资产、来源和后续可用性 | 生产任务执行状态的替代品 |

以上职责以正式 PRD 和当前已确认的产品方向为基线；若评审稿建议改变职责，先标记为待确认，不以原型现状自行裁定。

## 6. 正式 PRD 与当前原型的差异核查

以下是需要在内容生产模块整体梳理中继续核对的重点，不在本稿中擅自裁定：

- 当前 `materials.js` 仍将素材库和我的素材共用部分列表结构；正式 PRD 对两页职责、字段和下载入口有不同要求。
- 当前演示逻辑包含“已发布”个人使用筛选；正式 PRD §5.3.6 明确 M6 发布事实查询未交付前不得在素材库冒充展示。
- 当前素材库筛选/展示中仍出现源视频状态；正式 PRD §5.3.1、§5.3.7 规定列表不展示文件状态，也不提供文件状态筛选。
- 当前原型部分演示提示把选用和视频转存绑定；正式 PRD §5.3.5 规定素材入库不预下载，个人下载和合成前准备是不同触发。
- 当前内容生产 PRD 已有明确对象关系、角色、任务防重、状态和异常规则；后续设计必须先核对这些事实，不可用演示数据替代真实语义。

这些差异是审计发现，不代表本轮已经修改原型或正式 PRD。

## 7. 内容生产模块下一步产品逻辑审核

按以下顺序完成，不提前进入按钮和视觉细节：

1. **素材库 / 我的素材**：团队素材与个人关系、加入/移出/恢复、文件准备与个人下载边界、个人使用归属。
2. **合成策略**：策略归属、负责人、类目、模板参数、执行方式、选材规则、策略运行与任务关系。
3. **新建合成任务**：创建人/负责人、策略匹配、候选素材、参数快照、批量创建、防重规则。
4. **合成任务**：任务状态、执行阶段、取消、重试、部分成功、未知结果和追溯。
5. **成片管理**：成片资产、来源任务、版本/用途、文件下载、与发布模块的交接。
6. **跨页面闭环**：人工生产、策略执行、失败恢复、成片交付和后续发布入口。

每项结论都标注：正式事实 / 用户确认 / AI 建议 / 待确认；D1 业务问题集中提问，避免零碎打断。
