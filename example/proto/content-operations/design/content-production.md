## 2. 模块定位与主链路

内容生产负责把团队素材转化为可追溯的成片资产。它不负责发布账号分配、发布排期或评论互动。

核心链路：

`团队素材 material → 个人工作集 material_usage（人工选材关系）→ 合成策略 compose_strategy（生产规则）→ 合成任务 compose_task（一次生产行为）→ 成片 composite_output（成功资产）`

自动策略可以直接从团队素材库选候选素材，不要求为策略创建者或负责人建立个人素材关系。人工任务从创建者当前有效的“我的素材”候选中选择；从素材库快捷选用时可在同一创建流程加入并带回。

## 3. 核心对象职责（正式 PRD 摘要）

| 对象 | 职责 | 不应混淆为 |
|---|---|---|
| `material` | 正式生产输入、来源快照和源视频准备事实 | 视频文件已下载 |
| `material_usage` | 某个用户的个人工作集关系 | 素材本身的生产状态 |
| `compose_strategy` | 可复用制作规则、团队/类目/负责人范围、执行方式 | 一次生产任务 |
| `compose_task` | 一次生产行为、创建人/负责人、快照、执行与恢复 | 一批成片或一个通用 Agent task |
| `composite_output` | 一条成功生成的成片资产 | 发布记录 |
| `file_transfer_task` | 原素材或成片的一次文件传输 | 是否加入个人工作集 |

发布事实属于后续发布模块的 `publication`，不能用下载状态或合成状态冒充发布。

## 4. 页面职责边界（当前基线）

| 页面 | 核心职责 | 不负责 |
|---|---|---|
| 素材库 | 发现、判断团队素材，查看来源/表现/团队使用，加入个人工作集 | 本机下载、创建合成任务 |
| 我的素材 | 管理当前用户工作集、查看个人使用与文件、下载原视频、移出/恢复 | 通用合成任务创建入口 |
| 合成策略 | 维护可复用生产规则、执行方式、选材条件和策略运行记录 | 人工逐条选材创建的唯一入口 |
| 新建合成任务 | 选择负责人（按角色）、策略、素材和本次参数，创建独立任务 | 修改策略默认配置 |
| 合成任务 | 追踪独立生产任务、执行阶段、失败恢复和结果 | 发布排期 |
| 成片管理 | 管理成功生成的成片资产、来源和后续可用性 | 生产任务执行状态的替代品 |

以上职责以正式 PRD 和当前已确认的产品方向为基线；若评审稿建议改变职责，先标记为待确认，不以原型现状自行裁定。

### 6.4 推荐业务闭环

人工：素材库发现 → 加入个人工作集（或在创建器内原位加入）→ 任务创建器选负责人/类目/策略/素材 → 确认本次参数和任务数 → 逐素材创建 compose_task → Cloud 准备源文件并合成 → 成功后创建 composite_output → 成片管理查看/下载/带入发布。

自动：策略的团队/类目/负责人/条件/计划 → Scheduler 选择团队素材 → 创建 compose_task → Cloud 准备并合成 → composite_output。

人工候选属于创建者本人有效 material_usage；管理角色代创建仍从创建者工作集取材，任务/成片归指定负责人。自动策略直接从团队素材库取材，不依赖个人工作集。

# 9. M4 完整页面设计规格（供 Codex 实施）

> 本章是当前内容生产模块的可执行设计基线。业务规则以本工作稿的已确认决策及第 6 章对照结论为准；跨页面公共布局、控件和反馈引用 frontend 规范，不在此重复定义公共组件。此规格指导原型实施；真实 API/契约能力仍须按实施仓库验证。

## 9.1 全局页面原则

- 定位为企业级运营后台，不采用 C 端卡片瀑布流、营销式大标题、大面积渐变、装饰性指标或空洞 Dashboard。
- 使用现有 AdminUI 的 PageHeader、FilterPanel、DataTable、SelectionToolbar、Pagination；信息密度以实际列表为中心。
- 列表负责快速比较和操作；Drawer 负责单对象详情/长配置；Dialog 负责简短确认、摘要和人员明细；复杂创建流程使用 Drawer 内分区，不新增向导框架。
- 内容生产列表默认每页 20 条；若项目组件已有统一默认则沿用统一值。筛选和排序变化回第一页；打开/关闭详情或选择器保留筛选、分页、滚动和父 Drawer 输入。
- 默认排序：素材库/我的素材按发布时间倒序；策略按更新时间倒序；任务按创建时间倒序；成片按生成时间倒序。时间缺失排在末尾，不当作 0。
- 搜索覆盖用户实际可用标识：素材 ID、平台作品 ID、标题、作者；策略 ID/名称；任务 ID/名称、素材标题；成片 ID/名称、来源素材。
- 缺失值统一显示“—”；未知与 0 不等价；时间展示本地时区，数据更新时间单独表达，不伪装为实时。
- 筛选/排序跨页面保留；显式重置才清空。切换菜单后恢复该页面最近查询条件。
- 不提供手动刷新按钮。按 PRD 自动重读；抽屉、Dialog、表单、选中行和批量操作期间暂停自动刷新，刷新失败保留上次成功数据。
- 不可执行入口不渲染；只读用户仍可看允许查看的详情。服务端授权不可由前端筛选替代。
- 状态色沿用现有语义 Token；同一事实只出现一个主状态标签，解释文字用中性辅助文本。

## 9.2 素材库

### 页面目标
让运营在列表中快速回答：内容来自哪里、什么时候发布、表现如何、自己是否已加入/制作、团队是否已成功产出，以及是否值得加入个人工作集。

### 列表字段顺序
选择列 → 素材 ID → 平台 → 平台作品 ID → 素材信息 → 类目 → 发布时间 → 内容表现 → 加入状态 → 我的使用 → 团队使用情况 → 入库时间 → 操作人 → 操作。

| 字段 | 展示内容 | 交互/说明 |
|---|---|---|
| 素材 ID | 内部素材 ID 原值 | 独立列、复制；不加 # 前缀 |
| 平台 | 中文平台名/平台图标 | 独立列；不显示存储代码 |
| 平台作品 ID | 平台原始作品 ID | 独立列、复制；无 ID 显示 — |
| 素材信息 | 小封面 + 标题 + 作者 | 标题打开详情；不把平台作品 ID 塞进此列 |
| 类目 | 类目名称 | 普通文本 |
| 发布时间 | 平台发布时间 | 可排序；缺失值末尾 |
| 内容表现 | 横向紧凑展示浏览/播放、点赞、收藏 | 千分位；每项缺失单独显示 —；数据更新时间为辅助信息 |
| 加入状态 | 已加入/未加入 | 当前查看者自己的 material_usage；移出后为未加入 |
| 我的使用 | 未使用/已合成 | 只按当前负责人成功 composite_output；失败/取消/排队均未使用；M6 发布状态不展示 |
| 团队使用情况 | 成片 N · 使用 M 人；无成功产出显示 — | 点击摘要打开人员明细 Dialog；普通运营只看数量，高级运营/管理员按权限看人员及各人成片数 |
| 入库时间 | material 入库时间 | 不等于发布时间、数据更新时间 |
| 操作人 | material.created_by | 显示昵称，无昵称回退用户名；目录失效显示 —；普通运营也可见 |
| 操作 | 详情、加入/已加入 | 不提供下载、创建任务、发布动作 |

### 筛选与排序
- 高频：综合搜索、类目、加入状态、我的使用、发布时间范围。
- 高级：平台、团队使用情况、入库时间范围、操作人；日期范围使用单个范围控件。
- 类目选项按 PRD §5.3.3：普通/高级运营初始选中本人负责且启用的类目，可切换团队其他启用类目；管理员先选团队，默认该团队全部启用类目。
- 默认发布时间倒序；支持发布时间、浏览/播放量、点赞量、收藏量排序。升降序使用一个明确排序控件/表头状态，不出现两个视觉重量相同的升降序按钮。
- 筛选条件跨页面保留；筛选变化回第一页；重置恢复角色默认类目及默认排序。

### 单条与批量加入
- 单条：未加入显示“加入我的素材”；已加入显示“已加入”只读状态。
- 批量：勾选后才显示 SelectionToolbar，显示已选数量与“加入我的素材”；默认只对当前筛选结果中已选项执行，不默认全选所有分页。
- 点击批量加入直接执行，不再弹二次确认。完成后展示新增、恢复、已加入跳过、不可加入/失败；逐项原因可展开。部分成功不得显示全部成功。
- 幂等：重复请求不得生成第二条有效 material_usage；已移出关系恢复原关系。
- 加入仅建立个人工作集关系；不创建合成任务，不触发本机下载。人工明确提交“加入/使用所选”时可触发云端源视频准备；准备失败不回滚加入关系，显示准备失败及恢复原因。

### 素材详情 Drawer
标题“素材详情”；右上角 X 关闭；不重复提供列表已有加入按钮，不设置重复 Footer 关闭按钮。

内容顺序：
1. 素材内容：封面/视频预览（云端文件可用才播放）；标题、作者、平台；平台作品落地页可打开完整平台 URL。
2. 基本信息：素材 ID（可复制）、平台作品 ID（可复制）、类目、作者、发布时间、入库时间、操作人、来源快照。平台作品链接只出现一次。
3. 内容表现：浏览/播放、点赞、收藏及数据更新时间；缺失显示 —，不展示伪造 0。
4. 使用情况：加入状态、我的使用、团队成功成片数、使用人数；点击摘要打开人员明细 Dialog，按角色脱敏。
5. 视频文件：云端文件状态、文件大小/时长/格式（有真实数据才展示）、云端可打开的视频链接（真实存在且有权限才提供）。此区不展示平台作品链接；不展示本机已下载状态。
6. 来源链接：仅当前面未展示平台作品链接时才补充，禁止重复。特殊审核场景允许打开平台作品新窗口，返回不丢 Drawer。

视频状态只展示运营可理解的云端文件准备状态（未准备/准备中/已就绪/准备失败）；平台来源是否可访问是独立事实，必要时以辅助说明表达，不将平台来源状态、云端文件状态、transfer task 状态做三个并列 Badge。内部状态仍按 PRD 独立保存。

## 9.3 我的素材

### 页面目标
管理当前用户自己的有效工作集与已移出关系；个人下载是此页能力，生产资格由工作集关系决定，合成任务自行准备云端源文件。

### 列表字段
选择列 → 素材 ID → 素材信息（封面/标题/作者）→ 平台 → 类目 → 发布时间 → 内容表现（点赞/收藏优先，浏览/播放辅助）→ 加入时间 → 最近生产状态 → 云端文件状态 → 本地下载状态 → 操作。

- 默认仅“当前素材”（有效 material_usage）；“已移出”独立筛选，可切换全部。
- 加入时间取 material_usage 创建/恢复事实，不能与素材入库时间混淆。
- 最近生产状态来自当前负责人最近 compose_task：待合成、等待素材准备、处理中、已生成、失败、已取消；不是 material_usage 自身状态。
- 云端文件状态和本地下载状态分开；本机下载完成不等于云端可用于生产，云端 ready 不等于本人已下载。
- 行操作：详情、下载原视频、移出/恢复。不可下载时说明原因；下载只对当前用户有效 material_usage 开放。
- 不提供“新建合成任务”按钮；唯一主入口仍是合成任务。

### 筛选
综合搜索、类目、关系状态（当前/已移出）、最近生产状态、云端文件状态、本地下载状态、加入时间范围；默认发布时间倒序。筛选跨页面保留。

### 操作
- 移出：确认 Dialog 说明“从个人工作集移除；不删除历史任务/成片，不影响已进入发布流程的文件”；确认后仅将关系标记 removed。
- 恢复：直接恢复原关系，提示成功；不创建重复关系。
- 下载原视频：仅从我的素材发起；云端对象存在则签发下载；不存在且有源页地址则先准备再下载；无源页地址则提示不可下载。进度/速度/剩余时间只来自真实传输；失败允许重试。
- 详情 Drawer：素材内容、基本信息、内容表现、个人使用/关联任务、视频文件与本地下载信息；不提供创建任务入口。历史任务/成片只作为追溯链接，不展开大段历史流水。

## 9.4 合成策略列表与详情

### 列表字段
策略 ID → 策略名称 → 合成模板/模板版本 → 所属类目 → 所属团队 → 运营负责人 → 执行计划 → 状态（一个 Switch）→ 操作。

- 策略 ID 独立展示、可复制。
- 类目/团队为归属分类，默认普通文本。
- 执行计划显示“仅手动执行 / 每 30 分钟 / 每天 09:00（时区）”；不展示动态下次执行时间列。
- 状态 Switch 只控制策略 enabled/disabled；执行方式 manual/scheduled 是另一事实，不做第二个“自动执行”开关。
- 普通运营只查看/使用分配给自己的启用策略；高级运营管理本团队；管理员先选目标团队。
- 操作：详情、编辑、复制、立即执行；权限不符隐藏动作。复制生成新策略，可重新选类目/模板；编辑不允许改创建后不可变的团队/类目/模板，需更换时复制新策略。

### 筛选
策略搜索（ID/名称）、类目、负责人、执行方式、状态、更新时间范围。普通运营不显示无权限负责人筛选。管理员先选团队。

### 立即执行
- 直接按已保存策略的执行条件、默认参数、单次/每日上限和负责人执行，不弹参数编辑窗、不要求二次确认。
- 点击后行内 Loading 并禁用重复点击；其他行可继续浏览。
- 完成后 Toast 显示运行已完成，并提供候选数、创建数、跳过数、失败数；可进入本次运行/任务列表。
- 零创建也生成真实运行记录并给出原因分类；不得用前端模拟数量宣称真实执行。
- 运行记录 Tab：触发方式、时间范围筛选；显示候选/选入/创建/跳过/失败和逐项原因；策略运行完成不等于成片完成。

### 策略详情 Drawer
只读详情，X 关闭；不重复编辑按钮（操作入口在列表行）。Tab：概览 / 运行记录。
- 概览：策略 ID、名称、团队、类目、负责人、模板/版本、成片设置摘要、执行方式/计划/时区、单次/每日上限、选材条件优先级。
- 运行记录：真实运行时间、触发方式、候选数、创建/跳过/失败数、跳过原因和关联任务；无历史记录使用空态，不虚构运行。
- 配置摘要与运行结果分离；“策略启用”不等于“正在运行”，运行完成不等于任务成功。

## 9.5 新增/编辑/复制合成策略 Drawer

使用长配置 Drawer，按 AdminUI 表单分区，常规路径从上至下：

1. 基本信息：策略名称（必填）；所属类目（单选）；团队由角色上下文决定，管理员选择目标团队；负责人（单选）。编辑时团队/类目/模板只读。
2. 合成模板：选择可用模板及固定版本；模板 schema 决定后续参数字段。切换模板会清除不兼容参数，已有输入先确认。
3. 默认成片设置：一个或多个配置组。每组字段：成片设置名称（必填）、适用平台（多选或通用）、每条素材份数（1–20）、模板 schema 参数。支持新增、复制、删除、排序；至少保留一组。配置顺序决定任务展开顺序。
4. 执行设置：手动/定时；仅定时显示计划类型（间隔/每天固定时间）、时间/间隔、时区；单次素材上限、每日素材上限。
5. 选材条件：优先级规则组；每组为选入(match)或排除(filter)、全部/任一条件、白名单字段/比较符/值；支持增加、删除、排序。显示规则摘要；无真实查询时不承诺候选预览数量。
6. 保存前摘要：类目、负责人、模板、配置组数、每组份数、预计每素材任务数、执行方式和上限。保存只创建/更新策略，不立即执行；定时策略启用后等待下一计划窗口。

校验：名称必填；类目/负责人/模板有效；负责人属于团队且负责该类目；模板版本可用；每组名称非空、份数整数 1–20、平台范围有效、模板参数符合 schema；规则字段/运算符在白名单；上限为合法正整数。失败就近显示并保留输入。策略编辑改变未来默认值，不改已有任务快照。

启停：列表 Switch 先确认本次配置变化，显示对象和影响；确认后 Loading，失败恢复原值；停用不取消已有任务和成片。普通运营只读状态文本。



## 9.6 新建合成任务 Drawer

### 创建顺序

管理角色：负责人 → 类目 → 策略 → 选材 → 本次成片设置 → 提交摘要。普通运营负责人固定本人，默认类目按本人负责类目，直接选择匹配策略。

### 字段与默认值

1. 任务名称：必填，用于识别本次提交的一组任务；不作为新业务对象名称。默认建议“类目 · 日期 · 主题”，用户可修改。
2. 负责人：普通运营固定本人；高级运营选择本团队有效运营；管理员先选团队再选该团队有效运营。
3. 类目：单选，先选类目再筛策略与素材；不允许一次任务跨类目。
4. 合成策略：只列启用、类目匹配、负责人匹配的策略；选择后读取策略保存的成片设置作为本次默认值。
5. 选材来源：选择器提供“我的素材 / 素材库”两个 Tab。我的素材只列当前创建者有效关系；素材库允许当前创建者原位加入并选用。选择器确认“使用所选”后将库素材加入当前创建者工作集并带回，不创建任务。
6. 素材：显示素材 ID、封面/标题、平台、发布时间、点赞/收藏、云端文件准备状态、个人加入状态和该策略使用记录。搜索素材标题/ID/平台作品 ID；按类目、使用情况、发布时间/点赞排序。筛选排序变化不清空已选素材；跨页保留选择。
7. 已使用素材：若该策略在该素材上已有任务，展示既有任务状态和生成版本；提供“查看任务”和“继续生成”明确动作。不能静默重复创建。
8. 本次成片设置：按策略配置组逐组展示名称、平台、份数和模板参数；默认折叠参数详情，只突出配置摘要和任务数量。普通运营只能覆盖模板 schema 明确允许覆盖的参数；管理角色也不通过任务表单修改策略默认值。
9. 任务数量预览：素材数 × 各成片设置份数求和；按配置组显示每组任务数、总任务数、云端源视频待准备数。预计任务数不等于成功成片数。
10. 提交摘要：任务名称、负责人、类目、策略、素材数、成片设置摘要、预计任务数、待准备素材数；按钮“创建任务并加入队列”。

### 选择器交互

- 勾选只改变临时选择，不产生加入、下载或创建任务副作用。
- “使用所选”是明确提交点：库中未加入素材在此时创建/恢复 material_usage 并带回父 Drawer；若采用已确认的提前准备方向，则在此时启动云端源文件准备。
- 取消/关闭选择器仅丢弃本次临时勾选，不影响父表单已选素材；已明确提交加入的关系不因后续取消创建任务而回滚。
- 来源已失效且无法恢复的素材不可选，原因贴近该行；云端未准备、准备中或准备失败但仍有有效源链接的素材可选，任务提交后等待/准备文件。
- 更换类目、负责人或策略会影响当前选择：若已选素材或本次参数存在，先确认将清空哪些内容；取消则原值完整保留。
- 选择器内不提供“创建任务”按钮；主 Drawer 只有一个提交动作。

### 重复生成与重试（本版推荐决策）

- 同一策略+素材已存在成功任务：默认提示“该素材已按此策略生成过”；运营可选择“继续生成”，创建新的 compose_task 和新的 composite_output，不覆盖旧任务/旧成片。
- 已存在失败/取消任务：优先提供“重试原任务”（沿用原任务 ID 和策略快照）；若运营明确要改变参数或版本，选择“调整后新建”，创建新的任务。
- 已有 pending/running 任务：不允许重复创建；提供查看进行中任务。
- 同一次请求重复提交：request_key 幂等返回已有结果，不创建重复任务。
- 自动策略仍按正式调度防重规则处理，不因人工允许明确继续生成而放开自动重复调度。
- 该规则是对现有 PRD 严格防重的产品建议，实施前同步第五章防重定义和服务端唯一性约束；不得仅以前端按钮绕过后端冲突。

### 提交与结果

- 创建请求按素材/成片设置逐条生成独立 compose_task；一个失败不回滚其他任务。
- 提交中按钮 Loading，防重复点击；失败保留所有表单输入和选择。
- 成功后显示已创建、被跳过、失败数量；跳转合成任务并定位本次提交分组。
- “任务已提交/已进入队列”不能显示“成片已完成”。
- 已加入个人工作集和已启动的源视频准备不因创建任务失败而回滚；反馈说明各自结果。

## 9.7 合成任务列表与详情

### 列表视图

默认视图为“本次制作”，另提供“全部任务”精确查找视图；两者是同一 compose_task 数据的不同视图，不创建批次业务对象。

本次制作聚合规则：
- 人工提交：使用持久化 submission_group_id 关联同一次提交创建的任务。
- 策略执行：使用真实 strategy run_key 关联本次运行创建的任务。
- 历史无关联键的任务独立显示，不按相同标题或相近时间猜测合并。
- 分组仅用于汇总阅读；进入明细仍是一条任务一条素材/一次执行。

本次制作列表字段：任务名称 → 创建时间 → 触发方式 → 负责人 → 素材数 → 创建任务数 → 成功数 → 失败数 → 处理中数 → 操作。
操作：查看任务、继续处理（仅有失败/待核对时）；不在分组行提供可能误作用到整组的单任务重试按钮。

全部任务字段：任务 ID → 任务名称 → 素材摘要 → 合成策略 → 触发方式 → 负责人 → 状态 → 阶段/进度（有真实进度时）→ 创建时间 → 完成时间 → 操作。
筛选：任务 ID/名称/素材搜索、负责人、策略、触发方式、状态、创建时间范围。普通运营不展示负责人筛选；管理角色按团队范围选择负责人。

### 任务详情 Drawer

按当前状态决定信息权重：
1. 当前任务状态、执行阶段、失败原因（失败时紧随状态突出显示）。
2. 关联素材、合成策略和负责人/创建人。
3. 本次实际使用的成片设置与参数快照。
4. 执行记录：按真实 attempt 展示步骤名、开始/结束时间、耗时、白名单成果读数、失败原因；历史无记录显示“该次执行没有步骤记录”，不拿任务摘要伪装日志。
5. 生成结果：成功成片列表、成片 ID、生成时间和详情入口；不在关联信息区重复展示成片。
6. 恢复动作：失败且可重试显示“重试”；已取消显示“重新排队/重试”；execution_uncertain 进入人工核对；不可重试明确说明原因和下一步。

取消规则沿用 PRD §5.6.6：pending 可取消；running 发出真实取消并等待 Worker 确认；success 不可取消；failed 按资格重试；execution_uncertain 不可普通重试；cancelled 可重试。不能只改数据库状态就反馈取消成功。

## 9.8 成片管理

### 页面目标
运营找到实际生成的文件、区分版本、判断适用平台、预览/下载和追溯生产来源；需要发布时把具体文件带入发布模块。

### 默认视图与字段

默认“全部成片”平铺具体 composite_output；辅助视图“按素材查看”用于追溯同源版本，不将素材组当作发布选择对象。

字段：选择列 → 成片 ID → 成片名称/预览 → 来源素材 → 成片设置名称 → 适用平台 → 负责人 → 生成方式（人工创建/策略自动）→ 文件状态/下载状态（分开）→ 生成时间 → 操作。

- 成片 ID 独立展示，复制完整 ID。
- 成片名称/下载文件名：素材标题 · 成片设置名称 · 成片 ID；ID 使用实际 composite_output 完整 ID，不另造编号。
- 来源素材、任务、策略为追溯关系；不把创建人或下载人当负责人。
- 适用平台是成片用途，不等于已发布；发布状态只能从真实 publication 查询。
- 下载状态来自 file_transfer_task；成片资产状态不与下载状态混为一列。
- 默认排序生成时间倒序；筛选负责人、类目、来源、生成方式、文件可用状态和生成时间。

### 操作

- 预览：真实预览地址可用才播放；暂不可用保留详情并解释，不打开 404。
- 下载：创建真实 file_transfer_task；本地文件校验落盘后才反馈下载完成。
- 详情：视频预览和文件信息 → 成片 ID/名称/负责人/生成时间 → 来源素材/策略/任务 → 实际参数快照 → 平台用途。
- 按素材查看：按 material ID 精确聚合；不得按标题或相近时间猜测合并；每个版本仍显示独立成片 ID。
- 用所选成片发布：仅把已选具体 composite_output ID 带入第六章发布任务唯一创建流程；不在成片页复制账号选择、文案编辑或排期表单。没有真实发布能力时入口按项目交付状态隐藏或提示未开放。
- 转交未安排平台用途：转交的是某成片某平台未安排用途，不改变生产负责人、不复制成片、不改变历史发布事实。接收人必须有对应账号使用权限；已安排/已发布用途不可转交。

## 9.9 跨页面状态与对象边界

| 事实 | 唯一来源 | 展示位置 | 不得混淆 |
|---|---|---|---|
| 素材是否加入我的素材 | 当前用户 material_usage | 素材库、我的素材、创建器 | 不代表已制作 |
| 我的使用/已合成 | 当前负责人成功 composite_output | 素材库、我的素材 | 不代表已发布 |
| 团队使用 | 团队范围成功 composite_output 与负责人计数 | 素材库 | 不包含发布次数，不限制个人使用 |
| 云端源视频准备 | material.video_status / 文件事实 | 素材详情、我的素材、创建器 | 不代表本机已下载 |
| 本机下载 | 当前用户 file_transfer_task | 我的素材、下载中心 | 不代表云端源文件已就绪 |
| 策略启用 | compose_strategy.enabled | 策略列表/详情 | 不等于当前正在执行 |
| 策略执行方式 | compose_strategy.execution_mode | 策略列表/详情 | 不等于策略启用状态 |
| 任务执行状态 | compose_task.status + phase | 任务列表/详情 | 不等于成片成功 |
| 成片存在 | composite_output | 成片管理 | 不等于已下载/已发布 |
| 发布状态 | publication（第六章） | 发布模块；后续可投影 | 不得从成片或下载状态推断 |



## 9.10 视觉样式与 Common 复用约束

- 沿用前端规范 V2.0 的冷灰白、克制品牌蓝、清楚字号层级、轻边框和中性反馈；不推翻基础视觉规范。
- 以 example/common 的资源列表、详情、表单、选择确认、反馈空态、批量结果为参考；复制必要结构和模式，不复制整个公共示例目录。
- 业务页面继续使用项目实际 TDesign Vue Next 与 shared/ui 组件；example/common 的原生 HTML/CSS/JS 只是视觉交互参考，不作为运行时依赖。
- 表格高密度、窄列可横向滚动；关键 ID、发布时间、内容表现、状态和操作不能因响应式压缩而隐藏。
- 内容表现采用紧凑横向排列；避免把浏览、点赞、收藏拆成三张统计卡。
- 详情以分区标题和紧凑描述列表呈现；不堆叠大面积卡片，不重复显示同一字段。
- Drawer/Dialog 宽度按 AdminUI 规范依据内容选择；长配置 Drawer，简短人员明细/确认 Dialog；不自创另一套尺寸体系。
- 所有状态使用文字+语义色，不只靠颜色；避免将多个底层状态堆成彩色 Badge。
- 批量结果使用公共批量结果模式：成功/失败/跳过/待处理分开计数，逐项原因可展开；不使用大面积绿色成功卡。
- Common 缺少真正跨模块复用的模式时才提出扩展；不得为一个页面的业务特例改造公共组件。
- 若发现 common 参考与正式 frontend 规范冲突，先按事实源职责核对，提出最小规范修正；不直接复制冲突样式。

## 9.11 验收场景（Codex 必须逐项验证）

1. 素材库普通运营/高级运营/管理员的类目默认值和权限范围正确。
2. 素材 ID、平台作品 ID 独立显示并可复制；标题、作者、类目、发布时间和表现数据顺序正确。
3. 缺失指标显示 —，不当作 0；发布时间、入库时间、数据更新时间互不替代。
4. 加入、我的使用、团队使用互不混淆；团队成功成片数不含发布次数；普通运营响应不包含使用人姓名。
5. 批量加入直接执行；新增/恢复/跳过/失败数量准确；部分成功不误报全部成功。
6. 素材详情中平台作品链接不出现在视频文件区；云端视频链接可打开才展示；平台来源状态与云端文件状态语义清楚。
7. 我的素材默认只看有效关系；移出/恢复不删除任务/成片；下载原视频必须有当前用户有效关系。
8. 未下载源视频仍可创建合成任务；任务等待准备；本机下载不成为合成前置条件。
9. 策略类目、负责人、模板匹配；普通运营不能编辑/启停；管理角色只能在授权团队范围操作。
10. 策略启停失败恢复原值；立即执行无参数弹窗、防重复点击，运行统计真实且零候选可解释。
11. 新建任务类目单选；从素材库使用所选后加入工作集并带回；取消选择器保留父表单；已提交加入不因取消任务而回滚。
12. 本次成片设置修改不污染策略默认值；后续策略编辑不改变已创建任务快照。
13. 预计任务数按素材数×配置组份数准确计算；实际成功数只按 composite_output 统计。
14. 同策略同素材重复生成提示；用户明确继续才创建新任务；请求重放幂等；pending/running 不可重复创建；失败重试保留原任务 ID。
15. 本次制作聚合只使用真实 submission_group_id/run_key；无键历史任务独立显示。
16. 任务详情按真实 attempt 展示执行记录；没有日志明确显示无记录；失败原因和重试资格一致。
17. 成片默认平铺具体文件；按素材聚合仅辅助；成片发布入口带入具体文件进入统一发布创建。
18. 成片下载只有真实本地完整性校验通过才提示完成；发布状态不从下载或成片状态推断。
19. Drawer/Dialog 关闭后恢复筛选、分页、滚动和父表单输入；筛选排序跨页面保留。
20. 1280px 典型运营宽度下首屏可比较关键列；更窄时关键列可滚动访问，不发生按钮重叠、字段裁切或整页缩放。
21. 所有页面复用 Common/实际 shared/ui 模式；无重复公共组件、无新视觉体系、无未经批准的全局规范变更。

## 9.12 Codex 实施边界

- 先读取仓库 instructions、正式第五章 PRD、本工作稿第 6/9 章、frontend 四份规范、example/common/README 和当前内容生产原型。
