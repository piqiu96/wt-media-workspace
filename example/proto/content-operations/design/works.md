# 作品管理产品与交互设计

更新日期：2026-11-04。当前为原型基线与评审范围梳理，完整优化方案尚待讨论；本次仅建立工作稿，未修改业务原型。

## 1. 本稿用途与边界

按用户要求，与[发布管理](publishing.md)、[互动管理](interaction.md)分别维护。内容生产继续沿用[原工作稿](content-production.md)。共同工作方式见[设计索引](README.md)。

本轮以当前可执行原型和用户明确反馈为设计基线，PRD 作为输入。方案建议、用户确认、原型实施和人工体验验收分别表达；稳定结论在原型通过后回写原有产品文档，不另建正式 PRD。

作品管理围绕“发布后的内容如何继续运营”组织，覆盖作品列表与详情、外部作品添加、个人关注、表现观察、爆款复刻与关联结果。发布配置及执行由发布模块承接；主动互动和评论处理由互动模块承接；素材、合成任务和成片仍由内容生产承接。

## 2. 当前原型基线

以下是源码和现有说明中的做法，不自动代表产品规则已批准或体验已通过。

| 范围 | 当前做法与证据 | 后续评审关注 |
| --- | --- | --- |
| 作品列表 | [作品模块](../works.js)合并已发布任务对应作品与外部添加作品；可按搜索、平台、关注、来源和发布时间筛选 | 自有发布与外部观察的默认范围、信息层级是否清楚 |
| 关注 | 关注标记按当前演示使用者保存 | 保留个人工作集语义，核对取消关注与作品记录的关系 |
| 表现观察 | 展示播放、增长、点赞、收藏、评论与分享；增长范围可切换近 24 小时／近 7 天 | 指标来源、更新时间、区间可比性、缺失与采集失败需要清楚表达；当前数字与增长计算为演示 |
| 添加外部作品 | 先解析链接，再补标题、平台与作者；当前只识别链接并带入已有本地信息，不请求真实平台页面 | 平台识别、重复作品、解析失败及资料缺失的恢复路径 |
| 作品详情 | 展示作品身份、链接、来源、关联成片与表现数据 | 从详情能否理解作品来源，并继续正确的运营动作 |
| 后续动作 | 列表提供详情、发起互动、爆款复刻；复刻由[复刻模块](../replication.js)承接 | 动作目的、来源带入、创建后的结果与返回路径 |

[逐页评审](../review.html#page-works)及[评审源码](../review-pages.js)保留问题线索，但其中旧 Tab 描述不直接当作当前页面事实。最新入口以[当前原型](../index.html#works)和实际生效源码为准。

## 3. 继续沿用的已有记录

以下来自[原型说明的既有确认记录](../README.md#2026-11-03-已确认方向)，本次拆文件不重新打开这些决定，也不升级为整模块已验收：

- 爆款复刻从作品列表行内发起；选定作品即确定素材，系统已发布作品复刻沿用最初源素材。
- 策略优先自动匹配，无匹配时才人工指定。
- 复刻通过“确认素材 → 合成配置 → 发布安排 → 互动配置 → 确认创建”五步形成完整流程，并在同一流程查看进度。
- 素材、合成任务、成片、发布任务及互动产物仍由各自模块管理；复刻流程保留关联关系。
- 复刻创建时统一确认，后续可暂停、继续及调整尚未开始的安排；人工辅助发布仍需运营在平台提交。

## 4. 本轮评审重点

以下为 AI 建议的评审重点，尚未形成完整优化方案：

1. **先看懂作品，再决定动作。** 列表与详情需要区分系统发布、外部观察和当前可执行操作；不从外部链接推断已经具备可制作的源素材。
2. **表现数据支持判断。** 核对指标与观测区间、更新时间、排序和缺失值，避免用演示增长认定真实爆款。增长判定及跨平台比较口径有实质取舍时集中 review。
3. **关注形成个人工作集。** 关注、取消、查询与跨页返回形成连续路径，并检查切换使用者后的范围。
4. **复刻从来源到结果可追溯。** 结合已有五步流程，检查无素材、无匹配策略、发布冲突、暂停及阶段失败；各阶段恢复沿用对应记录。
5. **与互动入口衔接清楚。** 从作品发起主动互动带入目标；查看或回复收到的评论应进入对应评论范围，不把两个目的混成同一动作。

常规字段、布局和交互细节由 AI 结合现有规范收敛；涉及作品身份、指标口径、权限或复刻核心流程变化的事项集中提交用户评审。

## 5. 跨模块衔接与体验验证

- 发布模块负责确认发布结果，本稿维护发布后作品的展示与运营路径；结果未明确的发布继续由发布模块核对，避免重复发布。
- 作品发起互动及互动返回作品的路径，与[互动设计](interaction.md)相互核对；互动结果不覆盖作品原有发布事实。
- 复刻流程引用[内容生产设计](content-production.md)与[发布设计](publishing.md)，不在本稿复制各模块内部表单与执行规则。
- 后续原型检查覆盖自有／外部作品、关注、表现缺失、复刻创建与恢复、跨模块返回及筛选上下文。检查标准随方案收敛补齐；本次未执行浏览器体验验证。
