## 接续评审入口

先阅读本说明中的已确认方向，再走查 `index.html` 与 `review.html#page-compose-create`。完整工作台是当前可操作稿，`compose-design.html` 是独立设计参考；其他页面尚按原定顺序等待细评，不能视为全部通过。

重点核对本次任务参数与策略默认值的隔离、类目／负责人联动、素材选用与转存时点、成片 ID 命名和异常恢复。浏览器中的演示任务及人工评审意见不会随 Git 提交转移；需要交接人工意见时使用评审页 JSON 导出／导入。历史报告和折叠粗评仅作背景，已确认规则与当前页面优先。

## 2026-11-03 已确认方向

1. 发布任务提供直接发布；发布计划独立提供排期入口；成片的发布动作带入已选文件。
2. 入库先保存信息与封面，人工选用或自动策略选中时尽早转存视频；不依赖失效后再补存，不固定假设七天有效。
3. 爆款复刻从作品列表行内发起；选定作品即确定素材。先自动匹配策略，无匹配时才人工指定。通过确认素材、合成配置、发布安排、互动配置、确认创建五步建立完整流程，并在同一流程查看进度；合成任务、成片、发布任务和互动产物仍由各自模块管理。
4. 人工合成从“合成任务”新增，先选择一个类目，再选择同类目策略和素材；不允许混合类目，也不在我的素材增加通用创建入口。选择器可从我的素材或素材库选用，从库选用自动加入我的素材。系统已发布作品复刻沿用最初源素材，按策略重新合成。
5. 复刻在创建时统一确认，后续按配置推进；可暂停、继续及调整尚未开始的安排。人工辅助发布仍需运营在平台提交。
6. 同账号同时间的排期冲突在预览中提示，由运营调整。运营峰值管理 300 多个账号、当前手工约 200 条视频／日；评论按账号标签筛选后按需处理。

已确认补充：合成模板定义参数字段，策略提供高级运营配置的默认值；普通运营可调整每组成片设置的本次参数，作用于本次所选素材，不回写策略。配置名称统一为“成片设置名称”。最终显示名称与下载文件名采用“素材标题 · 成片设置名称 · 成片 ID”，直接使用成片记录自身的完整 ID，不增加第二套编号。尚未生成成片时只预览命名规则，示例 ID 不代表实际产出。

联动验证：独立参数复制检查通过，任务调整不改写策略；下一次创建重新带入策略默认值；后续编辑策略不改变已有任务。浏览器使用“联动核对 · 本次参数独立”创建 2 条演示任务，其中一条模拟完成；任务保存插入位置 15 秒、份数 2，原策略保持原值。成片显示及文件名直接使用成片自身完整 ID。任务详情与策略详情均按模板展示实际参数，策略的选材条件和执行计划未调整。参数隔离不等于平台效果相同，运营微调后的效果仍需观测真实数据。

本提案已完成浏览器检查：跨页／跨来源保留选择、来源去重、选用后加入及转存、取消选择器保留父表单、取消任务保留已加入素材、更换类目确认、份数即时计算、非法份数与空名称阻止提交、无策略和失败重试状态。三份相关脚本语法及两个入口资源引用检查通过。原型图已导出用于本轮对话确认，不作为人工通过证据。

## 演示边界

工作台右上角“规模演示”可一次载入 320 个账号、240 条成片、200 条发布任务和 80 条评论。包含多平台、运营分组标签及部分不可用账号，便于验证跨页选择、200 条排期和连续评论处理。重复载入不重复添加，原有数据和人工评审不重置。

所有数字、账号、视频和结果均为本地演示，无真实合成、视频上传、发布、评论发送或数据采集。新外链仅识别平台并匹配本地记录，不会伪造外部网络解析。转存及平台通道能力为体验示例，真实文件、有效期及平台支持范围后续在正式软件验证。

原型的人工提交关联键只用于演示，不表示后端已有统一人工批次字段；成片聚合沿用来源素材 ID，不按名称或相近时间猜测合并。

## 官方开关资源

`assets/ui-controls.entry.js` 使用应用现有 Vue 3.5.18、TDesign Vue Next 1.20.3 的 Switch 及官方主题样式。`assets/vendor/` 保留离线 bundle 和两项许可证，没有通过 CDN 加载依赖。可以用 Cloud Web 现有 esbuild 重新生成（先按 `config/repository-map.yaml` 找到 Cloud）：

```js
const path = require('node:path');
const modules = path.resolve('../wt-media-cloud/web/node_modules');
require(path.join(modules, 'esbuild')).buildSync({
  entryPoints: ['example/proto/content-operations/assets/ui-controls.entry.js'],
  bundle: true, minify: true, format: 'iife',
  outfile: 'example/proto/content-operations/assets/vendor/ui-controls.js',
  nodePaths: [modules], define: {'process.env.NODE_ENV': '"production"'}
});
```
