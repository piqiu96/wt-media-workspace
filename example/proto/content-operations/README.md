## 接续评审入口

先阅读本说明中的已确认方向，再走查 `index.html` 与 `review.html#page-compose-create`。完整工作台是当前可操作稿，`compose-design.html` 是独立设计参考；其他页面尚按原定顺序等待细评，不能视为全部通过。

重点核对本次任务参数与策略默认值的隔离、类目／负责人联动、素材选用与转存时点、成片 ID 命名和异常恢复。浏览器中的演示任务及人工评审意见不会随 Git 提交转移；需要交接人工意见时使用评审页 JSON 导出／导入。历史报告和折叠粗评仅作背景，已确认规则与当前页面优先。

## 2026-11-03 已确认方向

1. 发布任务提供直接发布；发布计划独立提供排期入口；成片的发布动作带入已选文件。
2. 入库先保存信息与封面。按本轮素材库建议修正：素材库“加入我的素材”只保存个人关系；创建合成任务的选择器确认选用、策略选中及我的素材主动下载时按各自流程准备视频。
3. 爆款复刻从作品列表行内发起；选定作品即确定素材。先自动匹配策略，无匹配时才人工指定。通过确认素材、合成配置、发布安排、互动配置、确认创建五步建立完整流程，并在同一流程查看进度；合成任务、成片、发布任务和互动产物仍由各自模块管理。
4. 人工合成从“合成任务”新增，先选择一个类目，再选择同类目策略和素材；不允许混合类目，也不在我的素材增加通用创建入口。选择器可从我的素材或素材库选用，从库选用自动加入我的素材。系统已发布作品复刻沿用最初源素材，按策略重新合成。
5. 复刻在创建时统一确认，后续按配置推进；可暂停、继续及调整尚未开始的安排。人工辅助发布仍需运营在平台提交。
6. 同账号同时间的排期冲突在预览中提示，由运营调整。运营峰值管理 300 多个账号、当前手工约 200 条视频／日；评论按账号标签筛选后按需处理。

## 素材库局部优化（2026-11-03，待体验确认）

按用户提供的素材库优化建议，仅替换素材库列表及其详情，保留工作台公共骨架；`production/library.js` 复用已有组件与个人素材存储，原 `materials.js` 继续服务我的素材及合成选择器。评审说明见 `review.html#page-materials`，人工结论及历史意见不自动修改。

列表按素材 ID、平台、平台作品 ID、素材信息、类目、发布时间、内容表现、加入状态、我的使用、使用情况、入库时间、操作人、操作的顺序排列。宽表可横向滚动，选择框、素材 ID 及操作列固定。三个表现指标横向展示，更新时间独立；缺失数据为 `—`，缺失排序始终置后。演示素材的平台、作品 ID、创建人及指标更新时间只补齐匹配已知种子标题和 ID 的本地样例，未知素材不猜测字段。创建人离开目录时展示 `—`。

平台及类目支持多选。角色默认“我的使用＝未使用”，普通及高级运营默认负责类目，管理员默认全部启用类目；演示负责类目为陈小雨的剪辑教程及林予安的拍摄技巧。查询、排序、分页及已选项保存在原 `C.ui.filters.materials` 按用户划分的上下文，离开再返回保持，刷新页面按现有原型机制复位。此原型仅演示内容运营一组，不增加团队管理能力。

素材库加入直接维护个人关系，绕过合成流程的转存辅助函数：已加入跳过、已移出恢复、不重复建立关系；结果分新增、恢复、跳过、失败，重试仅失败项。任务、成片和源视频状态不因加入改变。详情按基本信息、内容表现、使用情况、视频文件分区；普通运营使用情况弹窗不展示姓名，高级运营及管理员可看人员计数明细。此处是本地展示权限演示，真实数据访问仍需服务端约束。

定向检查覆盖关系幂等、混合结果、关系恢复、加入不改变视频／任务／成片、默认筛选及用户隔离、缺失值排序、创建人目录缺失、成功成片统计与我的素材回退原页面。浏览器体验检查记录以本轮对话为准。

## 素材库第二轮定向修正与验证（2026-11-03，历史）

详情顶部为小封面、标题、作者，不重复 ID；基本信息补齐 8 项。内容表现仍为三个横向指标加更新时间，缺失为 `—`，零值正常显示，采集失败保留上次取得的数据并明确提示。详情为只读 Drawer，没有底部 Footer、重复加入、下载或视频准备动作。

## 素材库第三轮定向修正与验证（2026-11-03，当前）

保留现有筛选区、13 列宽表、只读 Drawer 和居中 Dialog。素材详情依次为素材内容、基本信息、内容表现、使用情况、视频文件。平台作品链接只在基本信息出现，来源有效性作为其辅助文字；视频文件只展示云端文件状态，可访问时才增加打开入口。视频准备、云端对象存在、地址核验和有效期保持独立事实；可用的云端文件优先显示可用，即使平台来源失效或准备任务状态异常。未接入文件核验的旧 `ready` 样例显示待核验。

排序仅在当前字段显示一个方向箭头并蓝色强调，其他字段使用中性“排序”提示。点击当前字段切换方向，切换字段默认降序，缺失值仍置后；默认发布时间倒序。

高级筛选各用一个官方 TDesign `DateRangePicker` 选择完整范围。允许同日范围、清空，选择后点击查询统一应用；不完整范围不能提交。沿用 `from/to` 与 `enteredFrom/enteredTo` 的既有筛选上下文，重置恢复角色默认值，操作人仅管理角色可见。适配入口为 `assets/library-date-range.entry.js`，只挂载素材库的两个宿主，不改变公共控件行为。

使用情况汇总与明细从同一组授权团队成功成片聚合，每位负责人独立一行，人员 ID／姓名可对应同一目录记录时合并；不使用任务数或发布次数计算成片数。未知或失效的负责人显示信息不可用和原始关联标识，不编造姓名；完全未记录负责人时保留成片数量，单列归属缺失并说明不计入使用人数。普通运营不输出明细 HTML；高级运营和管理员可看授权团队明细。列表区域最高 320px，可滚动，零记录展示空态。
